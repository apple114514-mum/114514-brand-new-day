# 学术写作（thesis-writing）

写的是**能被导师和审稿人挑不出硬伤**的中文科研文本，不是漂亮话。

## 一、先确认载体与场景

| 载体 | 适用 | 输出方式 |
|---|---|---|
| Word (.docx) | 开题报告、中期检查、实验室报告 | python-docx 或 pandoc |
| LaTeX | 学位论文、期刊投稿 | .tex + 编译说明 |
| Markdown | 内部草稿、快速迭代 | .md |

场景决定结构，先问清是「开题／中期／学位论文章节／期刊论文／组会进展」，不要一套模板套所有。

## 二、结构模板

**开题报告**：研究背景与意义 → 国内外研究现状（分主题综述，不是文献罗列）→ 存在的问题 → 研究内容与目标 → 技术路线（配流程图）→ 可行性分析 → 创新点 → 进度安排 → 参考文献

**期刊论文（热工水力类）**：引言（工程背景 + 研究缺口）→ 实验/数值方法（可复现到别人能照做）→ 结果与讨论（现象描述 → 机理解释 → 与文献对比）→ 结论（量化、可检验）→ 符号表 → 参考文献

**学位论文章节**：引言 → 模型/方法 → 验证（对比实验或文献数据）→ 结果分析 → 本章小结

## 三、写作硬规则

- 一段一个论点，首句是结论，后面才是支撑
- 所有数字带单位；无量纲量给定义式（Nu、Re 用哪个特征长度必须写清）
- 区分三类陈述：**文献结论**（加引用）、**本文结果**（有数据）、**作者推断**（标「推测/可能」）
- 不用「效果很好」「显著提高」这类空话，换成「误差由 X% 降到 Y%」
- 术语全文统一（如「自然循环」不要一会儿写「自然对流」）
- 首次出现的缩写给全称

## 四、图表与公式

- 图：图注在图下方，格式「图 3-1 不同加热功率下的质量流量变化」；编号按章（3-1、3-2）
- 表：表题在表上方，三线表，单位写在表头
- 公式：右侧编号 (3-1)，正文引用「式(3-1)」；符号表统一在正文首次出现处定义
- 参考文献：GB/T 7714 格式；期刊文章 `作者. 题名[J]. 刊名, 年, 卷(期): 起止页.`

## 五、交付前自检

- [ ] 每个结论都有数据或引用支撑，没有悬空判断
- [ ] 图表编号连续，正文都引用了，没有「孤儿图」
- [ ] 单位和符号全文一致，符号表与正文对应
- [ ] 参考文献格式统一，DOI 或页码完整
- [ ] 数字精度合理（温度不要写 300.123456 ℃）
- [ ] 段落之间是承接关系，不是并列堆砌

## 六、不要做的事

- 不编造文献、数据、实验条件
- 不把综述写成文献清单（要有比较和判断）
- 不擅自改变用户给的结论强度（把「可能」写成「证明」）
- 不为了凑字数注水
