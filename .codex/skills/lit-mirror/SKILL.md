# lit-mirror —— 文献镜像与证据落地

> 本仓库适配（2026-11-03）：当前云环境可直接读取、渲染 PDF。带页码文本用于检索与交接，关键公式、表头和图仍须回到 PDF 核对。`mirror_check.py` 已增加页码存在性与 PDF/文本页数检查；退出码 0 只证明文件和页码结构完整，**不证明引文内容属实**。L1 是原文直读，L2 是有来源的计算，L3 是标定反解，L4 是情景假设；“grade ≥ L2”不是可执行的等级筛选规则。

## 这个技能解决什么

不能联网的链路有两个死结：**看不到全文**，以及**看到了也没法核**。
前者靠镜像解决（联网侧把 PDF 抓进工作区），后者靠**页码锚 + 定级**解决。
两件事都不需要模型有网络，只需要工作区里有文件。

不要用「联网检索」的思路去补它。补不上。要做的是**把不可联网的推理侧从"检索者"改成"读者"**。

## 铁律

1. **一条引用 = 一个文件 + 一处页码。** 没有镜像文件的断言，正文必须写「未核」，不许写「据文献」。
2. **纯文本是读者的唯一入口。** PDF 抓下来不够，必须抽成 `文献文本/<key>.txt`，页首带 `[[p12]]` 锚。
3. **二手转述不得升为 L1。** 手册汇编、综述转述、AI 摘要，一律 L2 或以下；只有原文页表是 L1。
4. **「未找到」≠「不存在」。** 原文没给，就写「原文未列」；不要推断成「该量不存在」。
5. **跑审计脚本，退出码是唯一判据。** 别把「读过了」当「核过了」。

## 目录约定

```
文献原文/<key>.pdf        # 原样保存，不改名、不裁剪
文献文本/<key>.txt        # pdf2txt.py 生成，带 [[pN]] 页码锚
证据卡/<key>.md           # 每篇一张，按模板填
claims.csv                # 断言 | 证据指针 | 定级 | 缺口
```

`<key>` 统一用 `第一作者姓氏+年份+关键词`，例：`zhao2020_pair_cfd`。同一篇换过版本时加后缀 `_v2`。

## 工作流

### ① 取件（只有联网侧能做）

开一张取件单，逐条写清要哪张表、哪个式子、哪个页码区间。**不要写「找一下 XX 的文献」**——那会拿回一堆摘要。
模板见 `templates/取件单.md`。取回后原样存进 `文献原文/`，文件名即 `<key>.pdf`。

判断值不值得付一次全文费的三条：① 有没有**逐段/逐构件**数据；② 有没有**多个功率点**；③ 有没有**测量方法与不确定度**。三条都没有，付费也白花。

### ② 抽文本

```
python scripts/pdf2txt.py 文献原文/zhao2020_pair_cfd.pdf
```

输出 `文献文本/zhao2020_pair_cfd.txt`，页首 `[[p1]]`、`[[p2]]`……
扫描件抽不出字时脚本会报 `EMPTY_PAGE`，此时只能人工核对图像页，**不许凭印象补**。

### ③ 写证据卡

照 `templates/证据卡.md` 填。核心是**每条数字后面跟 `[[pN]] 表M` 或 `[[pN]] 式(K)`**。
一张卡只回答一个问题：这篇能给我哪个量、在什么条件下、有多准。

### ④ 汇总成 claims.csv

```
claim,evidence,grade,gap
K_R=1.088839 由表1/3/5 复算,"zhao2020 [[p4]] 表5",L2,需要成对压差
```

`grade` 只用四档：

| 档 | 含义 | 判定 |
|---|---|---|
| L1 | 原文直读 | 有页码 + 表号/式号 |
| L2 | 由声明了适用域的关联式算出 | 关联式出处 + 适用域 |
| L3 | 由一次实测/标定反解 | 有依据，但**不是独立验证** |
| L4 | 情景假设 | 输入是自选的 |

**L3 不得当 L1 用。** 单点标定反解出来的参数，再说它是「原文给的」就是造假。

### ⑤ 审计

```
python scripts/mirror_check.py .
```

检查四件事：每条 claim 的证据指针是否有对应文件；每个 `.pdf` 是否有同名 `.txt`；
每个 `.txt` 是否有页码锚；claims 里 grade 是否只用四档。
退出码 0 才算过。缺件会列成清单——**缺件清单就是下一张取件单**，这是这个技能真正的输出。

## 交接给不能联网的链路

给它三样，不要给第四样：

1. `文献文本/*.txt` 全文（带页码锚，它可以自己引）
2. `claims.csv` 当前状态（哪些 L1、哪些空着）
3. 一句话边界：「你只能引用 `claims.csv` 里 grade ≥ L2 的条目，其余写未核」

**不要给它 PDF。** 它读不了，还会假装读过。

## 反模式（见过太多次）

- 让不能联网的模型「回忆一下这篇文献」——它会编，而且编得很像。
- 把 DOI 当成证据。DOI 只证明文章存在，不证明里面那个数是对的。
- 拿综述里的数字当原始数据。综述转述时的四舍五入和口径变化，足以让判据翻号。
- 一篇文献只写一段摘要，不写页码。三个月后你自己也核不回去。
- 缺件清单越积越长却不分工——**清单必须每次都变成取件单**，否则它只是安慰剂。
