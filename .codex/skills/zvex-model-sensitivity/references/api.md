# 共享调用说明 · 模型敏感性分析专家（zvex-model-sensitivity）

> 本技能为**纯方法论专家**（engine: none）：分析在用户会话环境内完成，不挂付费引擎、无外部服务依赖、无场景参数。调用即对话。若会话中为批量重计算或报告渲染**协同调用了其他带计费的 zvex 工具**，那些工具按次计费，金额以账单为准（见下方「结算约定」）。

## 调用方式

- **入口**：对话内直接使用。用户描述模型（形态、因子清单、取值范围、单次评估成本）或贴上已有采样数据（输入-输出配对），说明分析问题即可触发。
- **两段式工作法**：
  - 第一段（体检与诊断）：给「走哪条分支、方法建议什么、预算够不够」的方向性判断，反问至多三个关键参数——模型形态与成本、输入取值与分布、分析目标与预算——答完再开跑；
  - 第二段（完整交付）：按「三形态分流与退化检测 → 取值范围与分布核对 → 样本成本预算 → 四步解耦工作流（定义取值范围 → 样本方案 → 用户侧评估 → 指数解读） → 规格段与局限段 → 报告组装」推进，底稿沉淀到工作目录。
- **建议准备的材料**（有多少给多少，缺了如实说，分析自动降级）：
  1. 模型形态：自有函数 / 外部程序 / 电子表格 / 黑盒模拟器；单次评估耗时、能否一批参数进一批输出出；
  2. 因子清单：每个输入因子的名称、取值范围或不确定度；已知分布形态（均匀/正态/对数正态等）与因子间相关性；可捆组的同组件变量；
  3. 分析目标：关键因子排序 / 砍变量降维 / 交互定位 / 分时段分位置主导切换；输出是什么量、报告给谁看；
  4. 样本预算：单次评估成本可接受的模型运行次数上限；或已有的输入-输出配对采样数据。
- **数据不出会话**：模型与数据全程留在用户环境，不外传。

## 交付物（报告六件套）

| 固定模板骨架（确定性产出） | 转译层必须补齐（从用户材料提取） |
|---|---|
| 报告章节结构与顺序（摘要→规格→指数表→图→建议动作→局限） | 每条结论的指数与置信区间，全部来自用户模型产出或用户数据 |
| 规格段字段清单（因子/取值范围/分布假设/分组/样本方案与样本量/方法/置信水平/随机种子） | 每个字段的实际取值与用户确认过的口径约定 |
| 指数表模板（一阶/总阶/二阶，带置信区间，按总阶排序） | 逐行指数值，依用户模型在样本方案上的真实评估结果计算 |
| 图表规范（指数条形图带区间、分时段曲线、采样覆盖抽检） | 图表数据序列与分 bin 方式，依用户的模型与时间/空间参数定 |
| 建议动作清单（固定降维/优先精算交互对/加样本计划） | 逐条动作及其依据，依本份指数结果给出 |
| 局限段清单（分布假设敏感性/样本量限制/相关性未建模/方差类指标失真） | 本份设定真实触发的局限项，没触发的注明「不适用」 |

**交付前自检**：换一份不同模型、不同取值范围的设定，本报告的每条结论必须随之变化——若不变，说明在套模板，返工。

## 幂等与判重

- 同一个模型设定 + 同一组口径（因子/分布/样本方案/随机种子），重复分析结论一致；规格段留痕使每份交付可复算。
- 补充样本或修正分布假设后重跑，按更新后的口径交付并在规格段记录变更；历史版本可回放。
- 中断重开会话，凭规格段续跑，无需重问口径。

## 结算约定（仅适用于会话中协同调用的带计费 zvex 工具，用户视角）

1. **先看清再动手**：协同工具首次调用返回的概要与说明先转述给用户，讲清完整交付包含什么；
2. **按次计费**：协同工具按次计费，金额以账单为准；返回账单（内含 `pay_url` 收银台直链）时把链接**原样**发给用户，点开可选支付宝或微信支付；
3. **好了查单**：完成后引导用户**等 1 分钟左右**回一句「好了」，用**完全相同的参数**重调即得完整结果——核销有短暂延迟，别把延迟当失败；**无需任何凭证**，不引导用户去找或粘贴支付凭证（凭证路径是凭证型宿主专用，普通对话宿主走「好了」自动查单）；
4. **判重**：同一问题（相同情境+目标+模式）重复查询不重复扣费；补充数据或口径说明不产生新账单；不确定订单状态就用相同参数传 `action=check_order` 查单，不靠换参数试探；
5. **付费墙纪律**：出账单后**禁止换参数重试**——每换一组参数就是一笔新账单；确需调整因子清单、样本量、方法档位等参数，先向用户说明会重新出账并征得同意；
6. **积分直扣**：如已持有 zvex_api_key 凭证，调用时传入 `zvex_api_key` 直接扣积分（积分直扣，以实际扣减为准），无需逐单支付。

## 边界与免责

- 分析交付敏感性证据与量化归因，**改模型与建模决策权在用户**；本技能不替用户改模型、不认定模型本身正确；
- 方差分解默认输入相互独立；输入相关时换 Shapley 分账或如实降级结论，不做隐藏前提的硬算；
- 输出恒定时方差类方法失效，检出即退回，不静默输出指数；
- 指数结论受样本量与分布假设约束，交付必附局限段；用户模型与数据留在会话内，不外传；交付物不含用户数据之外的任何虚构数字。
