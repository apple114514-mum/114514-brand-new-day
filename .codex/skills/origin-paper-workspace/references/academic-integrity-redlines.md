# 学术规范红线库（Academic Integrity Redlines）

用于门禁阶段的确定性核对。分级：**A = 退稿/不端级（必须改）**，**B = 规范扣分（建议改）**，**C = 优化级（可选）**。

---

## A 类 · 学术不端 / 退稿级

| 编号 | 红线 | 典型表现 | 拦截条件 | 检查方法 |
|---|---|---|---|---|
| A-01 | **抄袭与未标注引用** | 大段使用他人文字、观点、图表而未标注 | 存在与来源高度相似且无出处的段落 | 逐段核对 provenance，无出处即报 |
| A-02 | **引用造假** | 引用的文献不存在、张冠李戴、页码对不上 | 正文引用与资产库/原文不符 | 引用键 ↔ 资产库 ↔ 原文三向核对 |
| A-03 | **参考文献表不一致** | 正文引用不在表中，或表中有未被引用的条目 | 任一方向不匹配 | 双向比对 |
| A-04 | **数据造假 / 选择性报告** | 编造样本量、统计值；只报有利结果 | 数值无法追溯到数据集或实验记录 | 数值 ↔ `datasets.md` 核对 |
| A-05 | **一稿多投 / 重复发表** | 同一稿同时投多刊；实质重复发表未声明 | 存在在审或已发表的实质相同稿件 | 核对作者声明与已投记录 |
| A-06 | **图像误用** | 拼接、裁剪、重复使用未声明；调整不当 | 图与源数据不符或未标复用 | 图 ↔ 源数据与脚本核对 |
| A-07 | **署名争议** | 未参与研究者挂名；实际贡献者未署名 | 缺作者贡献声明或存在争议 | 核对作者贡献声明 |
| A-08 | **缺伦理审批** | 涉及人类/动物受试者却无审批号与知情同意 | 研究类型涉受试者且无审批信息 | 核对伦理声明与审批编号 |
| A-09 | **无出处的事实性断言** | 论断句既无引文也无数据支撑 | 无 provenance 的断言 | 全文扫描无坐标断言 |

> **降级说明**：若用户要求"降重""洗稿""同义替换规避查重""去除 AI 痕迹"，一律拒绝，并说明本团只做规范性与引用完整性检查。

## B 类 · 规范扣分项

| 编号 | 项目 | 常见问题 |
|---|---|---|
| B-01 | 摘要 | 类型不符（非结构化写成结构化）、字数超限、含未定义缩写 |
| B-02 | 关键词 | 数量不符、与标题重复、非受控词 |
| B-03 | 引用格式 | 与目标刊/校要求不符（APA / MLA / GB/T 7714 / IEEE …） |
| B-04 | 章节结构 | 层级不符、缺必要章节（如方法/局限性） |
| B-05 | 图表 | 编号不连续、标题格式不符、分辨率不足、正文未引用该图 |
| B-06 | 数字与单位 | 有效位数不统一、单位混用、中英文数字格式混排 |
| B-07 | 术语与缩写 | 同义词混用、缩写首次未给全称 |
| B-08 | 声明缺失 | 利益冲突、数据可用性、基金标注、致谢缺失 |
| B-09 | 方法与结果不对位 | 方法声明的指标未出现在结果中 |
| B-10 | 局限性缺失 | 讨论部分未写局限与未来工作 |

---

## C 类 · 优化建议

| 编号 | 项目 | 建议方向 |
|---|---|---|
| C-01 | 引言收口 | 漏斗式收口是否清晰，研究空白是否明确指出 |
| C-02 | 论点密度 | 单节论点过多导致论证不充分，建议拆分 |
| C-03 | 证据强度 | 弱论点可考虑降级为"推测"或补充证据 |
| C-04 | 图表表达 | 可用图替代长表，提升可读性 |
| C-05 | 讨论深度 | 是否回应了引言提出的问题，是否过度外推 |

---

## 使用说明

1. 门禁阶段按 A → B → C 顺序逐项跑，A 类未清零一律 `打回`。
2. 每条问题必须给出 `章节/段落 + 原文片段 + 违反的编号与坐标`。
3. 无法判定的项标"无法判定"，要求用户核实，**不默认通过**。
4. 目标刊/校的格式要求以最新投稿指南为准，注明"请以现行版本为准"。
