# 敏感性分析

## 一、技能说明与适用对象

通过单因素与多因素情景测算，量化关键变量变动对投资回报、利润或现金流的影响，识别关键驱动因素与盈亏临界点，输出敏感性分析底稿。解决"这个结论靠不靠谱""哪个变量最要命""跌到多少会亏"这类决策者最关心的问题。

**适用对象**：财务分析（FP&A）、投资分析人员、财务经理，在投资决策、预算编制或经营测算需要检验结论稳健性时使用。
**方法条数**：4 条专属方法，逐条给出定义、操作步骤、在本技能中的应用与注意事项。
**产出用途**：生成单因素敏感性表、多因素情景矩阵、临界点测算表与关键驱动因素排序。

## 二、触发场景

- **敏感性分析**：用户以该表述提出诉求时进入本技能。
- **敏感度分析**：用户以该表述提出诉求时进入本技能。
- **情景分析**：用户以该表述提出诉求时进入本技能。
- **单因素变动测算**：用户以该表述提出诉求时进入本技能。
- **兜底判定**：诉求涉及"如果销量降10%会怎样""哪个因素最敏感""跌到什么程度会亏""这个测算靠谱吗"等表述时进入本技能。
- **相邻技能边界**：本技能解决结论的稳健性检验，若诉求是"这个项目要不要投"应转`investment-feasibility`，若诉求是"重估全年预测"应转`rolling-forecast`，若诉求是"已发生差异的归因"应转`budget-variance-analysis`。

## 三、核心理论框架（四层对齐）

### 战略层（商业逻辑）

**对齐理论**：决策的价值在于理解不确定性而非消除它

任何财务测算都建立在假设之上，假设必然有偏差。敏感性分析的目的不是证明测算准确，而是回答：**假设错了多少，结论才会变**。一个在销量下降30%时仍能盈利的项目，与一个销量下降8%就亏损的项目，风险性质完全不同。前者可以大胆推进，后者需要配套风险对冲。

### 洞察层（心理层面）

**对齐理论**：锚定效应与"基准情景即真相"

做测算的人容易把基准情景当作预期事实，把敏感性分析当成走过场的附录。更危险的是反向偏差——先有结论再调假设，用敏感性分析"验证"想做的事可行。破解方式是**先设定判定标准再测算**：在什么条件下这个决策应该被否决，把这些条件写下来，然后用测算去检验。

### 战术层（执行方法论）

**对齐理论**：单因素—多因素—临界点三层递进

先用单因素分析（OFAT）识别哪些变量敏感；再用情景分析（乐观/基准/悲观）与双因素矩阵考察变量联动；最后测算临界点（盈亏平衡点），给出"跌到多少会亏"的明确答案。三层递进既避免了只看单因素的片面，也避免了直接做复杂模拟的高成本。

### 落地层（企业知识库接入）

- **22_预算与费用库**：读取预算数据与实际执行数据，为变动幅度设定提供依据。

知识库未接入时：基于技能内置规则输出分析模板与变动幅度建议，并对受影响结论标注「⚠️ 未接入22_预算与费用库，历史波动数据需人工填入，变动幅度建议按行业经验设定」。

## 四、核心方法（本技能专属）

### 1. 变量识别与变动幅度设定

**定义**：识别影响测算结果的关键变量，并为每个变量设定合理的变动幅度区间。

**操作步骤**：

1. **拆解测算模型**，列出所有输入变量：
   - 收入侧：销量、单价、客户数、复购率、市场份额
   - 成本侧：单位变动成本、材料价格、人工成本、制造费用
   - 费用侧：固定费用、营销投入、管理费用
   - 投资侧：初始投资额、建设期、残值
   - 财务侧：折现率、税率、融资成本、营运资金占用
2. **筛选关键变量**（不是每个变量都要做敏感性分析）：
   - 对结果影响权重大的
   - 不确定性高的（预测难度大、外部依赖强）
   - 可被管理行动影响的（如定价、采购谈判）
   - 一般筛选5-8个变量，过多会稀释焦点
3. **设定变动幅度**（三种依据，按优先级）：
   - 历史波动：该变量过去3-5年的实际波动区间
   - 行业经验：同类项目/同行的典型波动幅度
   - 情景设定：乐观/悲观对应的管理判断
   - 常用幅度：±5%、±10%、±20%，重大不确定项可放宽至±30%
4. **记录设定依据**：每个变量的变动幅度必须写明来源，不能"感觉差不多"

**在本技能中的应用**：作为分析的设计环节，输出变量清单（含变动幅度与设定依据）。

**注意事项**：变动幅度过窄（如±3%）会让分析失去意义，过宽（如±50%）则缺乏现实参考；对外部依赖强的变量（如大宗商品价格、汇率）应设定更宽的区间。

### 2. 单因素敏感性分析（OFAT）

**定义**：在保持其他变量不变的条件下，逐一变动单个变量，测算其对目标指标的影响。

**操作步骤**：

1. **选定目标指标**（通常选一个，最多两个）：
   - 投资类：净现值NPV、内部收益率IRR、投资回收期
   - 经营类：净利润、毛利率、经营现金流
2. **逐一变动每个关键变量**，保持其他变量为基准值：
   - 例如销量分别取 -20%、-10%、0、+10%、+20%，其余不变
3. **计算各情形下的目标指标值**
4. **计算敏感系数**（衡量敏感程度的可比指标）：
   - 敏感系数 = 目标指标变动率 ÷ 变量变动率
   - 例：销量+10%导致NPV+35%，敏感系数 = 3.5
5. **排序识别关键驱动因素**：按敏感系数绝对值排序，绝对值最大的即为最敏感变量
6. **绘制敏感性表或龙卷风图**：横向展示各变量对结果的影响幅度

**在本技能中的应用**：作为分析的核心，输出单因素敏感性表与关键驱动因素排序。

**注意事项**：OFAT假设变量独立变动，但现实中变量往往联动（降价通常伴随销量上升），因此单因素结果不能直接叠加；敏感系数为负表示该变量与结果反向变动（如成本上升利润下降）。

### 3. 情景分析与双因素矩阵

**定义**：考察多个变量同时变动的联合影响，通过情景设定或双因素矩阵呈现。

**操作步骤**：

1. **构建情景**（通常3个，可扩展）：
   - **乐观情景**：多个有利因素同时发生（销量+15%、单价+5%、成本-5%）
   - **基准情景**：最可能的假设组合
   - **悲观情景**：多个不利因素同时发生（销量-15%、单价-8%、成本+8%）
2. **确保情景内部逻辑一致**（关键）：
   - 经济上行时：销量与单价通常同向，成本也可能上升
   - 降价促销时：销量上升但单价与毛利率下降
   - 不能把"销量大增 + 单价大涨 + 成本大降"这种不现实的组合当作乐观情景
3. **编制双因素矩阵**（两个最敏感变量的交叉测算）：
   - 例如"销量 × 单价"矩阵，5×5共25个组合的NPV
   - 或"售价 × 材料成本"对毛利率的影响矩阵
4. **标注可行域与不可行域**：在矩阵中标出NPV<0或IRR<折现率的区域
5. **输出情景对比表**：三情景下的目标指标、与基准的差异、触发条件说明

**在本技能中的应用**：作为分析的深化环节，输出情景对比表与双因素矩阵。

**注意事项**：情景不是"最好/最坏"，而是"如果……会怎样"的连贯叙事；悲观情景应设定为有一定发生概率的情形（如10%-20%），而非极端灾难情形，否则会误导决策。

### 4. 临界点与盈亏平衡测算

**定义**：计算使目标指标达到临界值（如NPV=0、利润=0）时，单个变量需要变动到的数值。

**操作步骤**：

1. **确定临界条件**：NPV = 0（或IRR = 折现率、净利润 = 0）
2. **单变量求解**，计算各变量的临界值：
   - 销量临界值：销量降至多少时NPV=0
   - 单价临界值：单价降至多少时NPV=0
   - 成本临界值：单位成本升至多少时NPV=0
   - 投资额临界值：初始投资超支多少时NPV=0
3. **计算安全边际**：
   - 安全边际 = (基准值 - 临界值) ÷ 基准值 × 100%
   - 例：基准销量10,000件，临界销量7,500件，安全边际 = 25%
4. **判定风险等级**（建议标准）：
   - 安全边际 > 30%：风险较低，结论稳健
   - 安全边际 15%-30%：风险中等，需关注关键变量
   - 安全边际 < 15%：风险较高，需配套对冲措施或重新设计
5. **识别最脆弱变量**：安全边际最小的变量，即为最需监控的变量
6. **输出临界点表**：变量、基准值、临界值、允许变动幅度、安全边际、风险等级

**在本技能中的应用**：作为分析的落点，输出临界点测算表与安全边际评估。

**注意事项**：临界点测算假设其他变量不变，实际中多个变量可能同时恶化，因此安全边际应保守解读；对安全边际过低的方案，应提出具体的风险对冲措施（如锁价协议、保底销量合同）而非简单否决。

## 五、输入要求

**必需输入**：
- 测算模型或基础数据（收入、成本、投资额、期间、折现率等）
- 目标指标（NPV / IRR / 净利润 / 毛利率等）
- 待分析的关键变量（或由技能协助识别）

**可选输入**：
- 各变量的历史波动区间（用于设定变动幅度）
- 变量间的联动关系（如降价与销量的弹性）
- 风险判定标准（企业内部的安全边际要求）
- 行业基准数据

**输入示例**：
```
项目：新建生产线，投资期1年，运营期8年
基准假设：初始投资1,200万元
         年销量10,000件，单价3,000元，单位变动成本1,800元
         年固定成本300万元，折现率10%，所得税率25%
         直线折旧，残值率5%
目标指标：NPV、IRR
待分析变量：销量、单价、单位变动成本、初始投资额
```

4. 临界点测算表（含安全边际与风险等级）

## 七、写作风格指南

**语气**：客观、量化、不下"可行/不可行"的结论（只呈现风险与条件）

**术语**：使用财务建模标准术语（NPV、IRR、敏感系数、安全边际、盈亏平衡点、龙卷风图），首次出现时加注解释

**长度**：分析报告控制在5-8页，矩阵与明细表单独成册

**可视化**：多用龙卷风图（敏感系数排序）、双因素矩阵与临界点表，少用大段文字

## 八、错误处理与边界情况

**常见错误**：
1. **变量选得太多**：稀释焦点 → 聚焦5-8个关键变量
2. **变动幅度凭感觉**：分析缺乏依据 → 必须有历史、行业或管理判断依据
3. **情景内部矛盾**：不现实的组合 → 确保变量联动关系合理
4. **只看单因素忽略联动**：低估风险 → 补充情景分析与双因素矩阵
5. **用敏感性分析"验证"预设结论**：本末倒置 → 先设定否决条件再测算

**边界情况**：
- **变量高度相关**（如销量与变动成本）：单因素分析失真 → 用情景分析处理联动
- **存在非线性关系**（如阶梯定价、规模效应）：等幅度变动不等于等幅度影响 → 加密测算点
- **存在实物期权**（如可延期、可扩张）：NPV低估灵活性 → 提示决策者考虑期权价值
- **概率可估计时**：敏感性分析不给出概率 → 若需期望值应另做概率加权或蒙特卡洛模拟

## 九、性能优化建议

**加速技巧**：
1. **模板复用**：固化敏感性分析模板（变量表、单因素表、情景表、临界点表）
2. **工具支撑**：用Excel数据表（Data Table）或建模工具自动跑矩阵
3. **聚焦关键变量**：只对敏感系数Top3做情景与临界点深度分析
4. **沉淀历史区间**：记录各变量的历史波动区间，作为下期变动幅度设定的依据

**资源节约**：
- 初步筛选阶段只做单因素分析，进入决策阶段再补情景与临界点
- 小额决策可用简化版（三情景 + 关键变量临界点）

## 十一、能力边界与注意事项

**仅用于**：企业财务与投资测算的敏感性检验、关键驱动因素识别与临界点测算。

**不适用于**：
- 投资项目的可行性结论 —— 应转`investment-feasibility`
- 概率化的风险评估与蒙特卡洛模拟 —— 需专业建模工具与方法
- 全年预测的重估与更新 —— 应转`rolling-forecast`
- 已发生差异的归因分析 —— 应转`budget-variance-analysis`

**重要提示**：敏感性分析呈现的是"假设变动对结果的影响"，不包含各情形的发生概率，不能替代风险决策本身；测算结论用于重大投资或融资决策时，应结合企业风险承受能力与战略考量综合判断。
