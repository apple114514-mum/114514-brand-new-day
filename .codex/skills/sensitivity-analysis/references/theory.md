# 敏感性分析 · 理论参考

## 战略层：决策的价值在于理解不确定性而非消除它

任何财务测算都建立在假设之上，假设必然有偏差。敏感性分析的目的不是证明测算准确，而是回答：假设错了多少，结论才会变。一个在销量下降30%时仍能盈利的项目，与一个销量下降8%就亏损的项目，风险性质完全不同。

## 洞察层：锚定效应与"基准情景即真相"

做测算的人容易把基准情景当作预期事实，把敏感性分析当成走过场的附录。更危险的是反向偏差——先有结论再调假设。破解方式是先设定判定标准再测算：在什么条件下这个决策应该被否决，把这些条件写下来，然后用测算去检验。

## 战术层：单因素—多因素—临界点三层递进

先用单因素分析（OFAT）识别哪些变量敏感，计算敏感系数（目标指标变动率除以变量变动率）；再用情景分析与双因素矩阵考察变量联动，注意情景内部逻辑一致；最后测算临界点，给出"跌到多少会亏"的明确答案与安全边际。

## 落地层：临界点转化为预警线与预案

临界点的价值在于可操作化：将临界值直接设为预警线（如单价跌破某值触发预案），并明确预案触发条件。安全边际大于30%风险较低，15%-30%中等，小于15%需配套对冲措施。敏感性分析不含发生概率，不能替代风险决策本身。
