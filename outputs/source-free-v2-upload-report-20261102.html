一、复核意见的裁决

复核意见裁决处置

摩擦项漏 L/D：应为 K_R=(1−w)+w(λ/d)f_R 成立 K_f∝f·L/D，故 K_f,M/K_f,P=(λ/d)(f_R)。赵恰好 λ=d，所以旧式在赵上"看不出错"；KYLIN 上错 2–20 pp。

二、通式：两处修正与推导

集总动量（Boussinesq，β=1.1944/ρ，故 ρ²β ∝ ρ）配绝热能量闭合：

ρ g β ΔT H = K m²/(2ρA²)      ⇒      m² = 2ρ ΔT H A²/K
ΔT = Q/(m c_p)

取 r=m_P/m_M, A_R=A_P/A_M, H_R=H_P/H_M, Q_R=Q_P/Q_M,
   ρ_R=ρ_M/ρ_P, c_p,R=c_p,M/c_p,P, K_R=K_M/K_P:

  r² = A_R² H_R (ΔT_P/ΔT_M) K_R/ρ_R
  ΔT_P/ΔT_M = Q_R c_p,R / r            ← v1 把这一行写在了分母

  r³ = A_R² H_R Q_R K_R c_p,R / ρ_R                  …… (*)

令 R_id=(A_R²H_RQ_R)^(1/3)、x=r/R_id，得 v2 通式（v1 在括号里的方向写反）：

x³ = K_R · c_p,R / ρ_R                    ← v2
x³ = K_R / (ρ_R · c_p,R)                   ← v1（错）

K_R = w·(λ/d)·f_R + (1−w)(1+δ)             ← v2
   其中 λ=L_M/L_P, d=D_M/D_P, f_R=(r d μ_R)^n, δ=(K_l,M−K_l,P)/K_l,P
K_R = 1 + w(f_R−1)                          ← v1（隐含 λ/d=1 且 δ=0）

⇒ x³(ρ_R/c_p,R) = (1−w)(1+δ) + w(λ/d)(x·R_id·d·μ_R)^n
为什么 λ/d=1 是个"巧合陷阱"。赵的理想圆管几何是 λ=d=0.5，所以漏掉 λ/d 在赵上恰好看不出来；而 KYLIN 全相似恰恰是 λ=0.5, d=0.6156，λ/d=0.812。一个只在"直径与长度同比缩"时成立的式子，被误当成了通式 —— 这就是它能在赵上复现、却在 KYLIN 上翻车的全部原因。

5.1 机制：不是热路，是"局部损失不随长度缩"

均匀直径、ρ/c_p≈1：r³ = H_R[(1−w) + w·λ·r^n] = 2[(1−w) + 0.5w·r^0.25]

w=1（纯分布摩擦）：r³ = r^0.25  ⇒  r=1   降高度恰好保流量（经典结论）
w=0（纯局部阻力）：r³ = 2        ⇒  r=1.26  流量按 √H 掉 21%
归因改写。降高度时 f·L/D 随 L 缩小，而局部阻力系数 k 不随长度缩。所以偏差的主体是 (1−w) 这一项 —— 即 δ 项在"几何相似但长度不同比"时的必然表现。热损不是成因，见下节反例。
