三、新结果：上界对 δ 的依赖有闭式

复核只指出"δ=0.35 反例"，但顺着它做下去可以得到完整的界。记 A=1+δ、B=(R_id·d)ⁿ、x̄=B^{1/(3−n)}，断言：

x ≤ max{ A^(1/3), x̄ }        对所有 w ∈ [0,1]、所有 δ > −1

证明只用两条不等式——M≤1 与 μ_R≤1（下端另加 (λ/d)f≥1）：

  1. x≥1 时 T_M≥T_P；μ=m₀·exp(754.1/T) 随 T 递减，故 μ_R≤1，于是 f=(R_id·x·d·μ_R)ⁿ ≤ B·xⁿ。
  2. 由 F=0 且 M≤1：x³ = M[(1−w)A + w(λ/d)f] ≤ (1−w)A + w·B·xⁿ。
  3. 反设 x>max{A^{1/3}, x̄}：则 x³>A 且 x^{3−n}>B，故 B·xⁿ<x³，右端 <(1−w)x³+wx³=x³，与第 2 步矛盾。
  4. x<1 时 D_m=x−1<0≤max{A^{1/3},x̄}−1（因 x̄>1）。∎

下端要多一条前提 (λ/d)f ≥ 1（本案例 [A] 已验：1.250–1.397）。在此前提下 G ≥ (1−w)(1+δ)+w·1 ≥ min{1+δ,1}：δ≤0 时 F_w<0 ⇒ D 递增 ⇒ 最小在 w=0，而那里 x³=M(x)(1+δ)≥(1+δ)；δ≥0 时 G≥1，若 x<1 则 x³≥M(x)>1 矛盾，故 x≥1、D≥0。合起来：

min{0, (1+δ)^(1/3) − 1}  ≤  D_m  ≤  max{(1+δ)^(1/3), (R_id·d)^(n/(3−n))} − 1

这条界没有用到 F_x>0、没有用到单调性、没有用任何数值根，所以它对 δ 全区间成立，不受"δ 只是情景"的限制。这是本轮唯一实质新增的东西——把"δ 未知"从一个缺陷变成了一个显式函数。

六、KYLIN：宽箱跨零不等于变号

v4 用整个 x∈[0.9,1.2] 判 F_w 的号，区间跨零就宣布"非单调"。这只能说明判不出号。正确做法是先证根落在很窄的管子里：

对所有 w ∈ [0,1]：
  F(0.99998, w) ∈ [−5.989e−05, −3.317e−05]   < 0
  F(1.00001, w) ∈ [ 3.011e−05,  5.038e−05]   > 0
  F_x 于管内    ∈ [ 2.7757 ,  3.0098 ]       > 0
⇒ 每个 w 的根唯一落在 [0.99998, 1.00001]

管内判号：
  (λ/d)f − 1 ∈ [−2.776, −1.865]×10⁻⁵（赵物性）
             [−3.054, −1.659]×10⁻⁵（Xu 物性）   恒负
⇒ F_w = −c_p,R[(λ/d)f−1] > 0 ⇒ dx/dw = −F_w/F_x < 0
⇒ D(w) 严格递减，端点即极值

「KYLIN 非单调、只能 21 点扫描」撤回。这也顺带解释了为什么该案例两端都给 0：w=0 由 M(1)=1，w=1 由 (λ/d)(r·d)ⁿ=1——设计映射本身就把它放在相似点上。
