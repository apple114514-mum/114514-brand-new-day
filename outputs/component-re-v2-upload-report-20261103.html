一句话结论。复核的五条全部成立，我逐条认账并复算到位。其中一条比复核说的还要严重： ReR ≥ 0.6418 不只是「w=0 的端点」，在 Zhao 自己的 w = 0.291472 上，阈值其实是 0.9735；而 ReR = 0.3461 处的包络允许 δ 到 23.64%，3% 带在同一个 w 上只允许 0.54%——包络比数据所容许的宽 43.9 倍。所以它从来不是判据。 本轮真正新增的是一张逐构件 Ki(Re) 表，用一条已核的实测关联式 （K = 427.5 Re−0.77 + 0.9）把「m ≤ 0.2」直接证伪在 Re < 2×104——而缩比台架恰恰往那边走。

二、v1 被推翻的三处

v1 的写法为什么错本轮的替代
A2：局部损失系数的 Re 指数不超过壁面摩擦的 0.2，所以 f 的标度是局阻 Re 依赖的上包络 把壁面剪切的 0.2 挪给了分离与二次流，两者没有共同标度。§三用一条已核实测关联式直接给出反例：斜接弯头在 Re=500 处局部指数 0.615，三倍于 0.2。 把 m 从常数改成函数 mi(Re)，逐构件给来源与适用区间（§三），并给出违反窗口（§四）。
ReR ≥ 0.6418 是「相似性能否保证 3%」的设计要求 三个独立问题：① 0.6418 是 w=0 端点，真值 0.9735；② 用的是包络不是实际值，两者差 43.9 倍；③ 符号写成了 1.03−5，照它算得 0.8626。 取消「保证」这个提法。改为两条：(a) 判定式 δenv ≤ δallow(w)（充分、几乎永不成立）；(b) 参数化 (δ, w) 可行域（§六）。
三个案例共用 Zhao 的 K+、f+、w+(δ) K+ 形式上是案例量，但数值上两案只差 9.0×10−7（M 都贴近 1）——所以这一项不是错误来源。真正搬错的是 f+：Zhao 的 c f+ = 1.305130，KYLIN 的 c f+ = 1.005668，差 30%。v1 用 1.305 算 KYLIN 得 w+ = −0.71（负值，判「带空」）；用 KYLIN 自己的 1.006 得 +16.36（整段覆盖）。符号都翻了。 整张表撤回。按案例重算两个（§七），第三个（降高度）明确不重算并说明理由。

  • 只给 δenv 的论文结论，读者无法复核——α 未声明，这个数对任何装置都成立，因此不含该装置的信息；
  • 只给 δmix 的结论，依赖图纸——α 就是逐段阻力，正是拿不到的那一样东西；
  • 可写的形式是两个都给，并明写「α 未知时 δ 落在 [δmix, δenv]」。

这也解释了 v1 那句「δ 已经不需要留白了」错在哪。 留白的不是 δ 的数，是 α 的数；δ 只是 α 的函数。 把未知量从 δ 搬到 mmax 并没有消灭未知量—— 它只是让未知量换了个名字，并且顺手把「未知」包装成了「有界」。

六、把 Re 联立进去：自洽解与它暴露的问题

复核第 2 条要求「设计阶段把 Re 与未知流量联立」。模型内的关系可以显式写出：

Re = 4 ṁ / (π D μ)   =>   ReR = (ṁM/ṁP) / (d · μR) = 1 / (rm · d · μR)
rm = x · Rid        =>   ReR(x) = 1 / (x · Rid · d · μR(T(x)))

自洽解随 w 落在 +7.6% ~ +8.5%，全部不在 3% 内。 原因不是数值，是把两件不同性质的东西放进了同一个方程：

  • δenv 是上界——对任何 α 都成立，因此必然宽松；
  • 3% 带要的是实际值——由 α 决定。

把上界当实际值回代，得到的是一个「最坏情形自洽解」，它当然不在 3% 内。 这不是模型坏了，是用法越界。正确的用法只有两种：

  1. 判定式：δenv(ReR) ≤ δallow(w) —— 充分条件，但对 Zhao 这种 ReR = 0.346 的台架，它永远不成立（差 43.9 倍）；
  2. 参数化：把 δ 当自变量扫，报 (δ, w) 可行域， 不宣称任何单个案例「保证 ≤ 3%」。

论文里能写的，是第 2 条；不能写的，是把第 1 条当成「通过/不通过」的判据—— 因为它在 w = 0 端点通过、在真实 w 上不通过， 而「w 取多少」本身还要由同一组未知量决定。

八、可写 / 不可写

可以写

  1. 条件命题（前提全部明写、不含物理断言）：若各构件同一参考速度、权重归一、 Ki 随 Re 单调不增、且该 Re 窗口内 Ki,M/Ki,P ≤ r−mmax， 则 0 ≤ δ ≤ r−mmax − 1。
  2. mmax 是声明输入，不是物理常数。逐构件表给出取值与来源等级： 斜接弯头 0.62@Re=500 … 0.07@Re=6×104（L1，已核 PDF）； 圆角弯头 0.12~0.15（L2，矩形风管表，仅旁证）； 普通弯头 0.32@103–104（二手汇编）；突扩 0（L2）； 阀门由开度主导，全开 0.15 / 半开 4.5，差 20 倍（二手 Crane）。
  3. 包络与混合值必须同时给：δ ∈ [δmix, δenv]， 间隙 = (1−α)[r−mmax − r−mrest]。
  4. 「Re 包络不构成 3% 保证」有定量形式：ReR=0.3461 允许 δ 到 23.6%，而 w=0.2915 只允许 0.54%，宽 43.9 倍。
  5. 反例：A2 在 ReM ≤ 3×103（斜接弯头）被违反， 最坏格超包络 1.73 倍（ReP=6×104, ReM=500）。

不能写

  1. 「δ 的物理参数域已经建立」——域没有建立，只有一个以 mmax 为参数的族。
  2. 「ReR ≥ 0.6418 保证 3%」——那是 w=0 端点，且用的是包络而非实际值。
  3. 「A2 是分离损失的一般性质」——被 B1 的实测关联式否定。
  4. 「三个案例的 3% 带分别为 …」——K+ 形式上是案例量，但真正的错在 f+；v1 那张表作废。
  5. 「US = 1.9~3.2 W/K 是 L2」——hout、导热率、保温厚度、环境温度全是自取值，L4 情景。
  6. 「某个 δ 值」——没有 α 就没有 δ 的数，能给的只有区间端点。

一句话收尾。v1 把「δ 未知」换成了「ReR 必须多大」， 方向是对的，但换来的不是判据——是一个把未知量从 δ 搬到 mmax 的等价改写。 本轮把 mmax 挖开，发现它在缩比台架所在的 Re 段上反而更大（0.2 → 0.6）， 于是这个改写不但没消灭未知量，还把方向搞反了。 真正的关口仍然是 α（逐段阻力），而它的入口是成对压差或图纸，不是文献检索。
