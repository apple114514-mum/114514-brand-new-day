固定缩比设计与前向计算：阀门配平水平，斜率决定失真

2026-11-08 · 第十七轮 · 9 节 / 7 表 · 脚本 design_v17.py（158 行日志，%% 残留 0 处）
接续 component-resistance-design-v16（提交 7103d91）与 prior-distortion-method-position（9543cef）
本轮把「声明 → 前向 → 摄动 → 情景 → 求界」这条链第一次跑在一台具体的台架上，而不是赵 2020 的成对算例上
一句话结论。你给的三个数复算全对（K_ref 6.34 / 2.23、孔径 9.41 / 11.15 mm、Re 12095）， 但设计目标 KM = 22.8 不是选出来的，是被 uR = √LR 逼出来的： uR2 = HR/KR，所以 KR = 1 恒成立，阀门只能照抄原型 K。 真正的结论在后面：阀门只配平「水平」，失真全部来自 K(m) 的「斜率」。 两种摩擦闭合给出符号相反的失真（−1.94% 与 +1.32%）， 而 3% 判据等价于 9.6% 的 K 预算；未配平的设计态角点已达 5.70%， 所以「配平」不是优化步骤，是判据成立的前提。

一、先认三处错，其中一处是我上一轮的

1. 「阻力没法设置」说错了。你指出的对。上一轮我把「理论表与实物阀位/粗糙度无对应」写成了「阻力无法设定」， 这是把辨识问题当成了设计问题。阻力完全可以按纯流体逐构件设计，未知的只是建成后阀位与表面状态落在哪。 正确表述是：可设计，不可反推。

2. 「杨若楠阻力表」是我记串了。我库里杨若楠 2020 的 Table 2 是物性表（引用 X26 式(15)–(18)）， 从来不是阻力表。阻力表的署名确实是 Yue 等 2017 Table 2，你核得对。这条混用是我造成的，已从溯源表口径里删掉。

3. 我自己的环隙 Re 公式错了。第一次跑这个脚本时我用 Re = 4qm/(πDhμ)， 得 22588，与 Yue 的 9520 差 2.37 倍。错因是那个式子只对满圆截面成立；环形通道要用湿周： 

Re_HS = 4 q_m /( P_wetted * mu ),  P_wetted = pi*(d_o + d_i) = pi*0.076
      = 5 / (0.2388 * 2.2019e-3) = 9511     <- Yue 表 2 给 9520

差 0.1%，这才是 Yue 那个 9520 的来路。这条错误值得记下来：环形通道的 Re 用 Dh 代入圆管式会系统性偏大 2.4 倍， 而它的后果是 fHS 被低估 30%（0.0439 应为 0.0339）——正好是 K_HS 重建那一段的差别。

必须声明的一件事：这台模型是几何畸变的。 dR = 0.616 而 LR = 0.5，所以 AR = 0.3795 ≠ LR2 = 0.25。 模型「偏胖」。这不是缺陷，但它意味着「理想比」不能再由几何自动给出，只能显式声明—— 恰好是本文第 4 条贡献（口径分账）在这台台架上的具体形态。 若强行取等比，dR 应为 0.5，管径 13 mm，Re 降到 7800，Blasius 与突缩式都还在域内， 但 L/D 不变而流通面积再小 35%，压降与泵功都会跳一档。两种都能做，必须选一种并写明。

三、KR = 1 不是设计选择，是相似律的推论

稳态自然循环:  u^3 = 2 g β H Q /(K ρ c_p A)
两边取比:      u_R^2 = H_R / K_R
要求 u_R 与 sqrt(L_R) 相符 (Xu FR26 标准方案):
               K_R = H_R / L_R = 0.5/0.5 = 1

所以「阀门把总 K 配到 22.8」这件事没有第二个答案。你在 v16 里取 KP,target = 22.8 是对的， 但把它写成「选定的设计目标」会被审稿人问一句「为什么是这个数」。正确写法是：由 uR = √LR 推出 KR = 1，故模型总阻力必须等于原型。

顺带把模型的三个一致性也核了：qm/AR = 0.707065 对 √LR = 0.707107，差 0.006%。 Xu 那套 LR=0.5 / dR=0.616 / qm,R=0.268 是自洽的。

我特地把 NEA 第 935 页（印刷页，PDF 第 936 页）重新渲染出来逐字核过表 15.3.5 / 15.3.6——四式是 0.5(1−β)、0.5(1−β)3/4、 0.5−0.7β+0.2β2、 Vennard 含缩脉 (1/βc−1)2， 突扩是 Borda-Carnot (1−β)2，Re 门槛 3.3e3 / 1e4。 第 4 式算出来 0.3286、第 1 式 0.3274，两者几乎相同（因为含缩脉的解与取 0.5 的近似在同一量级）—— 所以你那个 [(1−β)2+0.5(1−β)]/β2 是稳的，不必担心「把相邻两突变冒充孔板」那层顾虑在数值上的后果。

这一节真正有用的信息是相对量级，不是绝对值。 配方公式换来换去，孔径只动 0.18 mm；换摩擦闭合，孔径动 1.74 mm（18.5%）。 所以设计文档里要写死的不是「用第几条突缩式」，而是管材的表面状态。 把 9.41 或 11.15 写成「节流件尺寸」是错的，应写成「在 某表面状态 下为 9.41，另一种下为 11.14」。

六、前向计算：D = (KM/KP)−1/3 − 1

两侧都用同一组守恒方程正算，不做任何反解。口径 εQ 两侧同取 0，所以这个 D 是纯损失比项。 拿赵案验一下：(1.088839)−1/3−1 = −2.79%， 正好是第十五轮记的「εQ=0 反事实」那一支，而不是 +2.88%。 两个数不能混用，差 5.7 pp 就是口径账。

6.1 失真的全部机制在一行里

对象dlnK/dlnqm说明
原型 KP（Yue 五点）−0.04468 表观斜率很平，因为 KHS+KEV 5.1 是常数项在稀释
模型 A（光滑管）−0.13275差 −8.81%
模型 B（等效粗糙）−0.01957差 +2.51%
核心结论。阀门是一个常数，它只能把曲线上下平移，改不了斜率。 所以在设计点配平之后，D(qm) 的全部来源就是 KM 与 KP 斜率之差，而这个差只由摩擦指数的差决定。 原型表观指数是 0.045（被常数项稀释过的），光滑管是 0.25，等效粗糙管是 0.05。 想把 D 做到恒零，需要模型摩擦指数正好等于 0.045；而两条实测式给的是 0.13–0.30（朱锋杰 0.30、Zhang 0.13）。 ⇒ 在一台几何正常的台架上，D 的符号是选出来的，不是测出来的。 这条与第十六轮「n 与 δ 秩亏」是同一件事的两面：换摩擦律等于换一个 δ，也等于换一个失真符号。

七、摄动：设计点只有一条 −1/3 律

D = (KM/KP)−1/3−1 是恒等式，不是线性化， 所以 dD/dlnKM = −1/3 精确成立：

输入声明扰动ΔK ΔD（设计点）进入方式
dM 内径+0.5%+0.052−0.08% 经 f·L/D，与 L 同通道
LM 管长+10%+1.036−1.51% 同上
KHS+20%+0.520−0.76%直接加
KEV+50%+1.250−1.83%直接加

这张表要说两件事。第一，dM 与 LM 在设计点不可分辨——两者都以 f·L/D 的形式进入， 灵敏度比值恒为 1，又一个秩亏。第二，判据可以反过来用：

|D| <= 3%   <=>   K_M/K_P in [0.9151, 1.0957]
           <=>   K 的单侧预算 +9.57% (D<0) / -8.49% (D>0)

设计规格: 总 K 的相对误差预算 9.6%  —— 可以直接写进采购与装配要求

八、声明盒必须按阶段拆，否则数字会骗人

阶段盒里还剩什么角点 |D| 含义
Ⅰ 设计（阀未配平）KEV±50% + KHS±20% + L±20% + d±0.5% 5.70%已超 3% 判据
Ⅱ 调试（阀配平后）只剩阀位读数与重复性（±0.2 的 K）0.29% 配平把水平误差全部吸收
Ⅲ 运行（阀位固定）只剩曲线失真（§六）1.94%（A）/ 1.32%（B） 这才是「台架失真」，且符号不可控
这张表是本轮最有实践价值的一页。 把三个阶段混成一个盒，会得出「新台架不确定度 5.7%」这种既不真也不假的数。 正确的写法是分行报：设计态 5.70%（这是采购规格）；配平后 0.29%（这是仪表能力）；运行态 1.94%（这是模型失真，符号由管壁状态决定）。 同时它给出一条流程性结论：「配平」是判据成立的前提，不是优化步骤——不配平就谈不上 3%。

十、可写 / 不可写

可写「由 uR = √LR 得 KR = 1，故缩比台架须以节流件复现原型总阻力； 在 26 → 16.016 mm、11 → 5.5 m 的这组尺寸下，所需节流参考 K 为 6.34（光滑管）或 2.24（等效粗糙）， 对应窄段 9.41 或 11.14 mm，手册四条突缩式只带来 0.18 mm 的差异。」

可写「在 4:1 功率范围内，配平后的残余曲线失真为 1.94%（光滑管，负向）或 1.32%（等效粗糙，正向）； 设计点为零，符号由管壁状态决定。」

可写「3% 判据等价于总 K 的 9.6% 相对误差预算；未配平的设计态角点达 5.70%，故配平是判据成立的前提。」

不可写「新台架不确定度 1.9%」——它是一个声明设计在假设管壁状态下的失真，不是测量不确定度。

不可写「KHS = 2.6 是构件之和」——它比自己的和只高 4.5%，但高就是高。

不可写「9.41 mm 是节流件尺寸」——它是「某表面状态下」的条件值，另一种状态是 11.14。

不可写「Blasius 闭合是保守的一支」——它把 D 推向负侧 1.94%，B 推向正侧 1.32%，两支互不包络。

下一步只剩两件（都不需要新文献）。
① 把「声明」写成一张可交底的图纸清单：每段 A / Dh / L / 弯头数、阀件 Kv(开度, Re) 样本、管材 ε 等级。 这一张表填完，§五 的八行就从「声明」变成「规格」，论文的输入域一节也就定稿了。
② 把 §六 的 D(qm) 换成「曲线对曲线」的判据：本文此前一直用单点 D， 而这台台架第一次让「D 是功率的函数」成为必须回答的问题。程诚 2023 说「降高度曲线一对一不失真」， 但那是同一 FoM 下的结论；这里 FoM 是流量比，结论是曲线确实会歪，且歪的方向由摩擦指数决定。这一条可以直接成一节。
