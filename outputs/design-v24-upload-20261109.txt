[D] the 155D requirement and the 22.8 target cannot both hold at 16 mm
==============================================================================
    the spec asks for >= 155D from each bottom elbow to the orifice, i.e. a
    bottom leg of 2 x 155D = 310D = 4.96 m at 16 mm.
      bore 16.0 mm: bottom leg 4.96 m, L = 11.06 m, L/D = 691, K = 27.51
      bore 20.0 mm: bottom leg 6.20 m, L = 12.30 m, L/D = 615, K = 26.65
      bore 26.0 mm: bottom leg 8.06 m, L = 14.16 m, L/D = 545, K = 26.16
    -> at 16 mm the requirement alone gives K = 27.51, 20.7% above 22.8,
       before any orifice is added.  A larger bore relaxes it only because
       the riser stays 3.00 m while D grows; it does not relax the pipe
       friction share, which is what K/L/D fixes.

    so the design has to give up one of: the 155D distance, the four-elbow
    topology, the 2.00 m height, or the 22.8 target.  There is no fifth way
    at this bore.

[E] three distortions, because the formula's premise is not stated
==============================================================================
    prototype design point: m = 1.25 kg/s, u = 0.2280 m/s

    (1) pure K ratio, the formula used since v16:
        D_K = (K_M/K_P)^(-1/3) - 1
          K_M = 43.070, K_P = 22.800  ->  D = -19.105%
          K_M = 43.070, K_P = 19.308  ->  D = -23.466%
          K_M = 43.070, K_P = 24.318  ->  D = -17.349%
        This form assumes the driving head is the same on both sides, i.e.
        H_M = H_P and dT_M = dT_P.  Here H_M/H_P = 0.597, so the premise
        fails by 40% and the number above is not the velocity error.
        The same expression at the loop's own operating point (Re 17662,
        K = 31.18) gives D = -9.91%; the deficit is smaller there because
        f falls with Re, but it is still six times the 3% target.

    (2) Froude-normalised, dT matched:
        u_r = sqrt(H_r/K_r), target u_r* = sqrt(l_r), D_F = u_r/u_r* - 1
        H_r = 0.5970, l_r = 0.6154, K_r = 1.8890
        u_r = 0.5622, u_r* = 0.7845, D_F = -28.34%
        the same with K_r = 1 (length corrected):
        u_r = 0.7727, D_F = -1.50%
        -> the height is consistent with the bore (0.597 against 0.615);
           the whole distortion is the length.

    (3) same heater power on both sides, Q_r = 1:
        u_r = [H_r/(A_r K_r)]^(1/3) = 0.9415
        this is not a similarity criterion, only 'one heater, two benches'.

    which one is the paper's FoM is a declaration, not a calculation.
    The first two are far outside 3%, and both are dominated by the same
    input: L = 16.00 m.
