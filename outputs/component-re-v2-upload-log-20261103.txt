[B] 逐构件 K_i(Re)：把 m 从常数改成函数
==============================================================================
  v1 的 A2 断言「局部损失系数的 Re 指数不超过壁面摩擦的 0.2」。
  这句话把两件不同的事混在一根轴上：f 的 0.2 是**壁面剪切**的标度，
  而局阻是**分离与二次流**，两者没有理由共用同一个指数。下面是逐构件证据。

  B1  90 度斜接弯头（sharp mitre，圆管，无导流片）
       K = 427.5 Re^(-0.77) + 0.9 ,  500 <= Re <= 60000 ,  拟合误差 ±3%
       来源：Al-Tameemi & Ricco, ASME J. Fluids Eng.（已下载全文，式(4) 直读）
       原文摘要：「decrease sharply with Re up to about Re = 20000, at higher Re approach mildly K = 0.9」

          Re          K  局部指数 m = dlnK/dlnRe 判定
  ----------------------------------------------------------------------
         500     4.4705                   0.6150 区间内
        1000     2.9938                   0.5385 区间内
        2000     2.1278                   0.4443 区间内
        5000     1.5064                   0.3100 区间内
       10000     1.2556                   0.2181 区间内
       20000     1.1085                   0.1448 区间内
       40000     1.0223                   0.0921 区间内
       60000     0.9895                   0.0696 区间内
      100000     0.9604                   0.0484 外推，勿用

      => 在 Re = 500 处局部指数 0.615，是 0.2 的三倍；Re = 1e4 处 0.218 仍超过 0.2。
         只有 Re >= 2e4 以后才落进「<=0.2」。这不是「分离损失的一般性质」，
         是**斜接弯头在 500<Re<2e4 这段的经验事实**，换个构件就换一个数。

  B2  90 度圆角弯头（r/D ~ 1.5-2.0），手册 Re 修正因子 K_Re
       来源：ASHRAE Handbook 管件损失表 3-6（引自 Idelchik 1986 Diagram 6-5）
       注意：该表是**矩形风管**斜接弯头，用作「形状与量级」旁证，不作圆管定量依据。

  Re 区间                     K_Re 之比     该区间平均指数
  ----------------------------------------------------------------------
  10000 -> 20000                 1.1111             0.1520
  20000 -> 30000                 1.0588             0.1410
  30000 -> 40000                 1.0439             0.1492
  40000 -> 60000                 1.0459             0.1106
  60000 -> 80000                 1.0283             0.0970
  80000 -> 100000                1.0192             0.0854
  100000 -> 200000               1.0400             0.0566

      => 该表**从 Re = 1e4 起**；1e4 以下没有表。整段平均指数 0.12~0.15，
         也在 0.2 以内，但同样只是「这段 Re 里恰好如此」。
         要紧的是：**手册自己承认 1e4 以下无表** —— 而缩比台架恰恰往那边走。

  B3  标准 90 度弯头（Crane 2-K 系数复算，2 英寸管）
       Re:   100      1000     2300     1e4      1e5      1e6
       K:    8.59     1.39     0.94     0.67     0.60     0.59
       逐段指数：1e2-1e3 = 0.791 ;  1e3-2.3e3 = 0.470 ;  2.3e3-1e4 = 0.230 ;  1e4-1e5 = 0.048
       来源等级：二手汇编（Crane TP-410 的 2-K 系数经第三方复算），原文未核。
       => 跨整段 1e3-1e4 的平均指数 = 0.317 —— 普通弯头也过 0.3。

  B4  突扩：K = (1 - A1/A2)^2 ，Borda-Carnot，湍流下与 Re 无关，m = 0。
       这是唯一一个能写成「恒等于 0」的构件，因为它的损失全部来自不可逆掺混，
       而掺混尺度由几何决定。等级 L2（教科书关联式），不是 L1 实测。

  B5  阀门：K 对 Re 的依赖被**开度**压过去
       闸阀全开 K = 0.15~0.30；75% 开 0.9；50% 开 4.5~5.6；25% 开 17~24。
       来源：Crane TP-410 经二手表（Bai & Bai, Subsea Engineering Handbook 表 13-7；
             Crane 原表未核）。全开与半开差 20 倍，远大于任何 Re 修正。
       => 这一条给出的是**比 A2 更硬的不确定性来源**：开度不是 Re 问题，
          而是「台架与原型是否同一个开度」这个工程事实。它落在 delta 里，
          但它的量级由开度差决定，任何 Re 指数都盖不住。

[C] A2 的数值反例：包络可以被超过
==============================================================================
  A2 写成不等式就是 K_M/K_P <= r^(-0.2)，r = Re_M/Re_P <= 1。
  用 B1 的实测关联式直接检验（同一构件、只是 Re 不同，A1 显然满足）：

    Re_P  \  Re_M      500      1e3      3e3      1e4      3e4
    ------------------------------------------------------------------
    10000             1.96!   1.50!   1.13!      --        --
    30000             1.87!   1.44!   1.08!   0.96       --
    60000             1.73!   1.33!   1.00    0.89    0.93
    100000            1.61!   1.24!   0.93    0.82    0.86
    300000            1.34!   1.03!   0.77    0.69    0.72

    单元格 = 实比 / 包络比。>1 即 A2 被违反（标 !）。

  最坏一格：Re_P = 6e4、Re_M = 500
    实测 K_M/K_P = 4.5180  =>  delta_i = +351.8%
    A2 包络 r^(-0.2) = 2.6052  =>  delta_i <= +160.5%
    包络低估 191 个百分点，因子 1.73。

  => 结论：A2 不是「分离损失的一般性质」，而是一个**必须逐案例核对的窗口条件**。
     违反的判据是「区间[Re_M, Re_P]上的平均指数 > 0.2」。因为 m 随 Re 单调下降，
     平均指数主要由 Re_M 决定：网格里 Re_M <= 3e3 基本都违反，Re_M >= 1e4 尚未出现。
     注意 m 在单点上仍超 0.2（1e4 处 0.218），只是被区间上游的低指数稀释掉了。
     缩小比例恰恰把台架推进 Re_M 更低的窗口 —— 这是方向性的风险，不是精度问题。

==============================================================================
[D] 上包络与混合值是两个数，只报一个没有信息量
==============================================================================
  记构件权重 alpha_i = k_i,P / k_P，sum alpha_i = 1；单个构件 K_i,M/K_i,P = r^(-m_i)。
  则精确式与上界分别是：
     k_M/k_P = sum alpha_i r^(-m_i)        =>  delta_mix = 上式 - 1   （精确，需 alpha）
     k_M/k_P <= r^(-m_max)                =>  delta_env = 上式 - 1   （只需 m_max）
  闭式间隙（两构件退化，m_max 占权重 alpha）：
     delta_env - delta_mix = (1-alpha) * [ r^(-m_max) - r^(-m_rest) ]

  数值（r = 0.3461，m_max = 0.2，m_rest = 0.05）：
     delta_env  = +23.6402%
     delta_rest = +5.4484%

  alpha_max           delta_mix      delta_env         间隙    env/mix
  ------------------------------------------------------------------------------
  0.10                 +7.2676%      +23.6402%     16.37 pp       3.25
  0.20                 +9.0867%      +23.6402%     14.55 pp       2.60
  0.30                +10.9059%      +23.6402%     12.73 pp       2.17
  0.50                +14.5443%      +23.6402%      9.10 pp       1.63
  0.80                +20.0018%      +23.6402%      3.64 pp       1.18
  1.00                +23.6402%      +23.6402%      0.00 pp       1.00
  alpha_max = 最不利构件（m = m_max）占原型总损失 k_P 的份额

  => 同一个「Re_R = 0.3461」，报出来的 delta 可以在 +5.4% 到 +23.6% 之间移动 4.4 倍，
     全看最不利构件占多少损失份额。所以：
       (i) 只给 delta_env 的论文结论，读者无法复核（alpha 未声明）；
       (ii) 只给 delta_mix 的结论，依赖图纸（alpha 就是逐段阻力，正是拿不到的那样东西）；
       (iii) 可写的形式是**两个都给**，并明写「alpha 未知时 delta 落在 [delta_mix, delta_env]」。
  这也解释了为什么 v1 那句「delta 已经不需要留白了」是错的：
  留白的不是 delta 的数，是 alpha 的数；delta 只是 alpha 的函数。

[E] 把 Re 联立进去：自洽解与它暴露的问题
==============================================================================
  复核第 2 条要求「设计阶段把 Re 与未知流量联立」。做法如下。

  模型内 Re 比与流量的关系（v5 的 f 组已隐含，这里显式写出）：
     Re = 4 mdot / (pi D mu)  =>  Re_R = (m_M/m_P) / (d * mu_R) = 1 / (r_m * d * mu_R)
     而 r_m = x * R_id  =>  Re_R(x) = 1 / (x * R_id * d * mu_R(T(x)))
  符号：x 增大 => 流量增大 => Re_R 减小 => delta_env 增大 => G 增大 => x 再增大。
        这是**正反馈**，不是收敛型耦合。

  自洽方程：  x^3 * rho_R = G(x, w, delta_env(x)) * cp_R ,  delta_env(x) = Re_R(x)^(-m) - 1

  先看 Re_R 在根附近的实际数值（Zhao，w = 0.291472）：

           x        Re_R(x)     delta_env(x)    3% 允许的 delta     差多少倍
  ----------------------------------------------------------------------------
      1.0000       0.353553        +23.1144%           +0.5389%         42.9
      1.0288       0.345001        +23.7189%           +0.5389%         44.0
      1.0500       0.339004        +24.1535%           +0.5389%         44.8
      1.1000       0.325770        +25.1463%           +0.5389%         46.7
      1.2000       0.302591        +27.0073%           +0.5389%         50.1

  自洽解（m = 0.2，w 取四个值）：

           w           x*       D = x*-1 3% 内?           Re_R(x*)
  ----------------------------------------------------------------------------
      0.0000     1.076276       +7.6276% 不在             0.331897
      0.2000     1.080587       +8.0587% 不在             0.330763
      0.2915     1.082557       +8.2557% 不在             0.330249
      0.4000     1.084893       +8.4893% 不在             0.329640

  => 自洽解随 w 落在 +7.6% ~ +8.5%，**全部不在 3% 内**。原因不是数值，是正反馈：
     要让 x 停在 1.03，delta 必须 <= 0.54%（[A]），而 Re_R 在 x=1.03 处只给到
     delta_env = 23.74%，比允许值大 44 倍。两者不可能同时满足。

  这不是「模型坏了」，而是把两件不同性质的东西放进了同一个方程：
     delta_env 是**上界**（对任何 alpha 都成立，故必然宽松）；
     3% 带要的是**实际值**（由 alpha 决定）。
  把上界当成实际值回代，得到的是一个「最坏情形自洽解」，它当然不在 3% 内。
  正确的用法只有两种：
     (a) 判定式：delta_env <= delta_allow(w) ？ —— 充分条件，可能永远不成立；
     (b) 参数化：把 delta 当自变量扫，报 (delta, w) 可行域，不宣称单个案例"保证"。

[G] 重写后的清单
==============================================================================
  可以写：
    1. 条件命题（前提全部明写、不含任何物理断言）：若各构件同一参考速度、权重归一、
       K_i 随 Re 单调不增、且该 Re 窗口内 K_i,M/K_i,P <= r^(-m_max)，则 0 <= delta <= r^(-m_max)-1。
    2. m_max 是**声明输入**，不是物理常数。逐构件表（B1-B5）给出取值区间与来源等级：
       斜接弯头 0.62@Re=500 ... 0.07@Re=6e4（L1，已核 PDF）；
       圆角弯头 0.12~0.15（L2，矩形风管表，仅旁证）；
       普通弯头 0.32@1e3-1e4（二手汇编）；突扩 0（L2）；
       阀门：开度主导，全开 0.15 半数开 4.5，差 20 倍（二手 Crane）。
    3. 包络与混合值必须同时给：delta 落在 [delta_mix, delta_env]，间隙 = (1-alpha)[r^(-m_max)-r^(-m_rest)]。
    4. 「Re 包络不构成 3% 保证」有定量形式：Re_R=0.3461 允许 delta 到 23.6%，
       而 w=0.2915 只允许 0.54%，宽 44 倍。
    5. 反例：A2 在 Re_M <= 3e3（斜接弯头）被违反，最坏格超包络 1.73 倍（Re_P=6e4, Re_M=500）。

  不能写：
    1. 「delta 的物理参数域已经建立」—— 域没有建立，只有一个以 m_max 为参数的族。
    2. 「Re_R >= 0.6418 保证 3%」——那是 w=0 端点，且用的是包络而非实际值（[A][E]）。
    3. 「A2 是分离损失的一般性质」——被 B1 的实测关联式否定（[C]）。
    4. 「三个案例的 3% 带分别为 …」——K_+ 是案例量，v1 那张表作废（[F]）。
    5. 「US = 1.9~3.2 W/K 是 L2」——h_out、导热率、保温厚度、环境温度全是自取值，L4 情景。
    6. 「某个 delta 值」——没有 alpha 就没有 delta 的数；能给的只有区间端点。

  一句话：v1 把「delta 未知」换成了「Re_R 必须多大」，这一步方向对，
          但换来的不是判据，是**一个把未知量从 delta 搬到 m_max 的等价改写**。
          真正的关口仍然是 alpha（逐段阻力），而它的入口是成对压差或图纸，不是文献检索。
