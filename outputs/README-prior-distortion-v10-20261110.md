# v10 交接包

先读 `v10_WorkBuddy区间核复核与功率方向_20261110.md`。它区分 WorkBuddy 本轮数值修复、仍缺的严格证明、新完成的连续体温升外包，以及最有希望的功率单调命题。

## 当前可写结论

- MPFR v9：全盒、连续 3–6 kW，`−17.177% ≤ D_j < −0.136%`。这是宽外包，不能据此判断全窗是否均超过 3%。
- MPFR v10：同域体温升 FoM，`−1.386% ≤ D_T ≤ 22.351%`。它不是壁温，也仍是宽外包。
- 6 kW 固定功率已有严格 `D_j < −3.357%`。若能证明 `D_j` 对共同功率全域单调递增，则全窗 `D_j<−3%` 随即成立；目前只在 1024 个角点的三个功率值上观察到递增。
- 直接阈值判号的简单实现：5750–6000 W、四共享轴各四分，16/256 格判过线，其余判不定。这不是 240 个反例。

## 运行

Python 3.12，`numpy`、`gmpy2`。在本目录运行：

```
python probe_power_trend_v10_20261110.py
python mpfr_threshold_probe_v10_20261110.py
python mpfr_bulk_temperature_v10_20261110.py
```

包内 `workbuddy_received/` 放用户提供的修复代码、报告和日志，供对照；v10 MPFR 脚本不依赖它。严格结论只针对冻结的 `core_v2.py` 常数及声明设计盒，不是实物认证。
