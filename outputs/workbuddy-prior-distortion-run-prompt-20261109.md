# 给 WorkBuddy 的运行提示词

请先读压缩包 `README.md`、`docs/01_scope_v1.md` 和 `docs/02_v29_literature_audit.md`，再核对原文与历史脚本。本轮任务是**真正跑出方法论文第一版的条件先验失真预测**，不要再把完整实物装置认证、油品厂家资料或实验验证当启动门槛。

## 研究对象与原则

目标为铅基快堆自然循环的设计阶段失真预测。P 与 M 各自由事先声明的几何、热边界、LBE 物性和构件阻力**独立前向求解**；缩放准则、Yue 理论总阻力 22.8、既有实验或 CFD 流量都不能用来反调主线设计输入。旧 `design_v24` 的“必须去孔板”是旧配平目标下的判断；在此主线中，16 m + 10 mm 孔板可作为一个**独立候选设计**，其名义阻力大也是真实预测结果，不用凑 22.8。旧 `probe_v29` 的油侧 `h_o` 是计算值，不是测量。

## 请按以下顺序执行

1. **核对材料并冻结 P/M 输入表**：优先用 Yue 2017 与 Xu 的 P 几何、NEA 2015 物性和构件式；M 从 16 mm、16 m、10 mm 固定孔板的已声明候选开始。分清原文数据、关联式计算、独立设计声明和仅供模型形式比较的情景。热边界首版允许事先声明冷腿/加热段入口受控温度；可把油路可行性放在旁证栏，无须完整冷机模型。逐构件记录 `L、A、D_h、K` 的参考动压与关联式 `Re/Pe/T` 适用域。若某个原文数值确实缺失，做清楚标注的条件情景并继续运行；不要默默回填、无限检索或把 P/M 混成同一工况。
2. **先定义 FoM**：说明比较的是基准点绝对响应、归一化曲线形状，还是以事先指定的功能参考比定义点值失真；不得把这三者混称一个上界。至少输出 `m` 的 FoM；如果温升受同一能量式约束，应说明它的非独立性。参考尺在看到求解输出之前固定。
3. **重写双侧前向模型**：对每侧能量、浮升与分段压降联立求稳态根。输出名义工况、功率扫描、每段 `Re/K/Δp`、温度与能量残差。检查正入热、正阻力、物性/关联式有效域、根存在与多根处理。不要把 `D=(K_M/K_P)^(-1/3)-1` 当通式。
4. **摄动与 GSA**：先做局部导数或 OAT 以识别主导通道，再对事先声明的联合输入域做 GSA；分布若自选，明确称“设计情景分布”。分类的关联式选择分支单独报，不混成一个连续参数。给采样数、种子与误差/置信区间；若不用 SALib，可用经检验的替代实现并说明。
5. **单独求条件界**：在同一物理可行域上用可解释的极值/区间方法给出 `D_min、D_max` 和最大绝对失真；如果只完成网格或采样，应叫“已搜索到的极值”，不叫证明上界。记录域外点及其拒绝原因。GSA 只用于排序或指导分盒，不替代求界。

## 交付

请给 `inputs_v1.yaml`（或 CSV/Markdown 表）、可一键运行的双侧前向与摄动/GSA/求界脚本、运行日志、结果 CSV、至少一张 P/M 分段阻力与 FoM 曲线图，以及一份简洁报告。报告须明确：**条件设计域是什么、名义失真多少、哪些输入主导、目前得到的是采样极值还是已证上界、哪些设计选择最能缩小失真。** 不要以“尚无实验验证”作为停止理由；在结论处如实标出这是模型条件先验预测即可。

如果为避免式子/口径歧义必须做一个设计选择，请给出理由、记录版本并继续，不要在旧报告的撤回清单上原地循环。
