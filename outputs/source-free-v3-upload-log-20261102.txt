[0] v2 的 "7.8e-14 认证间隙" 撤回：两处都不是证明

   (i) v2 写 |M_x| <= |M(b)-M(a)|/(b-a)，称"中值定理界"。
       中值定理只给"存在一点等于割线"，不给"全区间被割线界住"。

       密集采样 max|M_x| = 0.000915790（x=0.9 处取到，单调递减）。
   => v2 表里 min F_x=2.05 不是有效证明值：那个界比真导数小 6.2%，
      结论（F_x>0）侥幸仍成立，但**推导无效**。

   (ii) enclose() 用 81 点最值 + 10x 相邻差当包络。

        故 7.8e-14 只能叫"程序报告的数值宽度"，不是认证误差。
   => 整句撤回。下面用区间算术重做。

[B] 复核给的解析界 [0, +9.914%]：常数逐条核验
==============================================================================
   论证链（不依赖浮点证书，只用两条不等式）：
     (a) w=0：F(x,0)=x^3-M(x)，M(1)=1、F_x>0  =>  根恰为 x=1，D_m=0。
     (b) 对 x∈[1,xbar]：M(x)<=1 且 mu_R(x)<=1（下面核验）；
         且 (l/d)f(x)>=1（f 增、f(1)=1.296840>1）。
         于是 F(1,w)=1-M(1)[1+w(f(1)-1)]<=0；
         F(xbar,w)=xbar^3-M(xbar)[1+w(f-1)]>=xbar^3-M(xbar)f(xbar)
                   >=xbar^3-(RID d xbar mu_R)^n >=xbar^3-(RID d xbar)^n=0。
         => 对每个 w 都有根落在 [1,xbar]，D_m∈[0, xbar-1]。
     (c) F_w=-M[(l/d)f-1]<0 => 根随 w 增 => 上端点 x(w=1) 最大。

   核验（4001 点，仅作"常数是否成立"的数值检查，正式依据是上面的不等式）：
     max M(x)   = 1.000000000000   (需 <=1)
     max mu_R(x)= 1.000000000000   (需 <=1)
     T_M(xbar)  = 603.249 K，与 T_P=596.874 K 同物性区
     xbar = (R_id d)^(n/(3-n)) = 2^(3/22) = 1.0991312226

   => 模型内**可证明**：0 <= D_m <= +9.9131%（保守十进制写 +9.914%）。
      它比 v2 的数值端点 +9.7782% 宽 0.135 pp，但不靠 1e-14 的外舍入证书。
      两条结论层次不同，必须分开写：
        可证界  [0, +9.914%]   —— 只用两条不等式，人手可查
        数值端点 +9.7782%      —— 区间证书下的紧包络（[A] 节），或退一步
                                  只作"双精度求根结果"
      两者都只约束 w 一个参数，都依赖 d=0.5、delta=0、绝热、物性版本。
