一句话：四条复核全部成立。最要紧的不是那两个末位数字，而是判据的形状变了：|D_m|≤3% 不是"δ≤9.2727% 且 w≤w*"，而是 (δ,w) 平面上的一条带——δ=−10% 时 w 必须落在 [0.032573, 0.475787]，把 w 压到 0 反而失真 −3.45%。顺着复核往下查，还发现 v5 的解析界少写了一条前提 λ/d≤1（赵恰好 λ=d=0.5，所以"看不出错"）。

关于第 ③ 条要说清比例：9.275604% 比 9.2727% 只高 2.86×10−5（相对 0.031%），在 δ 本身还没有实物范围的前提下毫无工程意义。真正被推翻的是句式——"硬上限"暗示"δ 超过就必然越界"，而实际是"δ 超过就连 w=0 都不行"；以及"δ≤0 时判据不变"这句，它在 δ=−0.10 直接给反例。

二、上界的适用域：三层，外加一条 v5 没写的前提

复核只点了 M≤1，但顺着同一条证明链检查，v5 实际用了三件事，写成文字只写了两件：

① M(x) ≤ 1        在根处   —— 物性方向，x≥1 时 T_M≥T_P 且 c_p/ρ 之比 <1
② μ_R(x) ≤ 1      在根处   —— μ = m₀·exp(754.1/T) 随 T 单调减
③ λ/d ≤ 1         几何     —— **v5 只写了 ①②，③ 是隐含的**

第 ③ 条来自 G=(1−w)A+w(λ/d)f：只有 λ/d≤1 才能把 (λ/d)f 换成 B·xⁿ 而不放大。赵恰好 λ=d=0.5，λ/d=1，所以 v5 的式子"看起来对"——这与 v2 把 c_p 放分母、漏掉 λ/d 是同一类错误：参数恰好相等，检查者看不出来。一般化闭式是

x ≤ max{ A^(1/3), (c·B)^(1/(3−n)) },    c = λ/d,  B = (R_id·d)ⁿ,  A = 1+δ
c=λ/dx̄c=(cB)1/(3−n)解析上限端点 max D结论
0.50.854248+0.0000%−14.4165%（w=1）上限取 A1/3=1，仍包住
1.01.099131+9.9131%+9.7782%（w=1）宽出 +0.1349 pp（即 v5 的数）
2.01.414214+41.4214%+40.7220%（w=1）宽出 +0.6993 pp

于是"适用域"要分三层写，不能混成一句：

  • 层一（纯数学）：若根处 M≤1、μ_R≤1、λ/d≤1，则上式成立。
  • 层二（本模型）：M(x)≤1 等价于根 ≤x_M=5.204652，在 w=0 支上即 δ≤139.9857。这不是物理界，是把多项式物性硬外推到 875 K 得到的算术边界。
  • 层三（关联式验证域）：比层二窄得多。本项目物性只有 398.15 K 以上有出处，上限出处仍待核。不能拿层二的 875 K 当"物理可用"的证据。

论文里这句话应写成：「在 M(x)≤1、μ_R≤1、λ/d≤1 的物性/几何域内（本案例根 x≤5.2047，即 T≤875.8 K），δ 参数化上界成立」。不写"对所有 δ>−1"。这不等于退回无界——界仍然是 δ 的显式函数，只是加了域。

三、下界：可以去掉 (λ/d)f≥1，前提是 B>1

复核给的下界论证对：x<1 时 M≥1、μ_R≥1，故 f=B·xⁿ·μ_Rⁿ ≥ B·xⁿ。要再推到 >x³ 需要 B > x3−n；本案例

B = (R_id·d)ⁿ = (2.828427)^0.25 = 1.296840 > 1
x<1  ⇒  x^(3−n) < 1 < B   ⇒   f(x) > x³ 对所有 x<1 成立

所以 v5 那条"(λ/d)f≥1 于声明域"是多余的，且它本身有反例：δ=−0.99、w=0 的根 x=0.215501，该点 f=0.909520<1（但 f/x³=90.88，要用的正是这个比）。下界数值核对：

四、主修正：|D_m|≤3% 是一条带，不是两个阈值

4.1 闭式怎么来的

在固定目标点 x_t 处，F=0 等价于 G(w)=K_t，其中 K_t=x_t³ρ_R/cp,R=x_t³/M(x_t)；而 G(w)=(1−w)A+w·f_t 对 w 是仿射的。于是两边一移项就出闭式，不需要扫 w、不需要求根：

w_t(δ) = (K_t − A) / (f_t − A),        A = 1+δ
x_t = 0.97  →  w₋(δ)           x_t = 1.03  →  w₊(δ)

可行带：  max(0, w₋(δ)) ≤ w ≤ min(1, w₊(δ)),   且须左端 ≤ 右端

每个设计只算一次两个常数，之后 δ 进显式有理函数：

K₋ = 0.912648800525    f₋ = 1.288319247874
K₊ = 1.092755604047    f₊ = 1.305130341205
dw_t/dδ = (K_t − f_t)/(f_t − A)² < 0     ⇒ 两条边界都随 δ 单调下降

4.3 三个结构性结论

① 正向有上限、负向没有。正向上限是 δcrit=K₊−1=9.2755604%（这时 w₊→0，带宽归零）。负向 δ→−1 时 w₋→K₋/f₋=0.708403、w₊→K₊/f₊=0.837277，带仍非空（宽 0.1289）。物理读法：局阻偏小可以靠提高摩擦份额救回来；局阻偏大过 9.28% 则怎么分配都救不回来。

② δ<0 时 w=0 已越 −3%。δ=−0.10、w=0 时 D=−3.4501%，必须把 w 抬到 0.0326 以上才回到带内。所以 v5 的"w≤w*"是只写下界不写上界的写法——它在 δ≤0 时恰好掩盖了负向越界。

③ 判据可移植的是函数，不是数。两个设计只要各自算出 (K₋,K₊,f₋,f₊)，曲线就有同一形状：w_t=(K_t−A)/(f_t−A)。这与前几轮"数不可移植、函数可移植"是同一条。

五、两个 δ 阈值之差：主项是根包络间隙，不是物性

δ_num = x₁³/M(x₁) − 1 = +0.323077721      x₁ = 1.097782446340,  M(x₁) = 0.999915935700
δ_ana = x̄³ − 1        = +0.327848828      x̄  = 1.099131222559

δ_ana − δ_num = [x̄³ − x₁³] + x₁³[1 − 1/M(x₁)]
              = +0.004882331  +  (−0.000111224)  =  +0.004771107

主项占 102.3%（物性项为负、起抵消作用），所以正确说法是"保守包络造成的阈值间隙"。v5 写的"正好是 1−M(x₁) 的三倍"是错的：1−M=8.41×10−5，三倍 2.52×10−4，与真正的物性项 1.11×10−4 还差两个量级，与总差 4.77×10−3 差一个半量级。

六、F_dep_iv：缺陷、污染范围与修正

原式 G=(1+δ)+w[(λ/d)f−(1+δ)]；v5 写成 G=1+w[(λ/d)f−(1+δ)]，只有 δ=0 时等价。反例：

δ=0.1, w=0, x=1:  F_iv     = [−0.100000000000005, −0.099999999999995]
                  F_dep_iv = [−4.33e−15, +4.33e−15]     ← 把非根判成根

修正后（G=(1+δ)+w[...]）：
δ=0.1, w=0.3, x=1.02:  F_iv = [−0.0994744419313034, −0.0994744419312921]
                       修正版 = [−0.0994744419313032, −0.0994744419312923]

污染范围：v5 只在 KYLIN 根管一段调用 F_dep_iv，而那里 Model 默认 δ=0，因此已印出的 KYLIN 根管结论（严格递减、端点即极值、−8×10−4 pp 来自 m_R=.268）不受影响。今后凡非零 δ 的判根/判号，必须先改成上面的形式。

七、文献边界：δ 仍然没有实物范围

Yue 2017 表 2 的 K_EV≈2.5 / K_HS 2.6–2.9 / K_pipe 17.7–19.1 仍为转述（DOI 10.1007/s41365-017-0187-x；nst.sinap.ac.cn 站内检索实测返回空集）。即使该表确为同一装置的逐段阻力分解：

  • 它只给单侧（台架）的阻力分解 → 只能帮 w；
  • δ = k_M/k_P − 1 需要原型与台架两侧的局阻 → 单侧给不出；
  • 因此 δ 的实物域仍为空，本报告的 δ 一律是"未标定情景参数"。

八、可宣称 / 不可宣称

可宣称

  1. 在 M(x)≤1、μ_R≤1、λ/d≤1 的物性/几何域内， min{0,A1/3−1} ≤ D_m ≤ max{A1/3,(cB)1/(3−n)}−1，c=λ/d。本案例该域为根 x≤5.2047（T≤875.8 K）；δ=0 时退化为 +9.9131%。
  2. |D_m|≤3% 的判据是一条带：δ < K₊−1 = 9.2755604% 且 w ∈ [max(0,w₋), min(1,w₊)]，w_±=(K_±−A)/(f_±−A)。两条边界对 δ 单调下降。
  3. 负向无阈值：δ→−1 仍存在可行带 [0.708403, 0.837277]（模型内）。
  4. KYLIN 根管结论不受 F_dep_iv 缺陷影响（该处 δ=0）。

不可宣称

  1. 「界对所有 δ>−1 成立」——x=6 反例；需 M≤1。
  2. 「δ≤9.2727% 是硬上限」「δ≤0 时判据不变」——漏负向分支，且阈值应取 K₊−1。
  3. 「λ/d 不影响界」——v5 隐含 c=1；c≠1 时第二支要乘 c。
  4. 「δ 有实物范围」——Yue 表 2 未核，且单侧不够。
  5. 任何把上面的带当"台架保证 ≤3%"的句子——它是模型条件曲线。
