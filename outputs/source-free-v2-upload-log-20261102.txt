[0] 通式重新推导：两处修正
==============================================================================
   集总动量（Boussinesq，β=1.1944/ρ：(ρ^2 β) ∝ ρ）+ 绝热能量 Q=m c_p ΔT：

     ρ g β ΔT H = K m^2/(2 ρ A^2)   =>   m^2 = 2 ρ ΔT H A^2/K
     ΔT = Q/(m c_p)

   取 r=m_P/m_M、A_R=A_P/A_M、H_R=H_P/H_M、Q_R=Q_P/Q_M、
      rho_R=rho_M/rho_P、c_p,R=c_p,M/c_p,P、K_R=K_M/K_P：

     r^2 = A_R^2 H_R (ΔT_P/ΔT_M) K_R/rho_R
     ΔT_P/ΔT_M = Q_R c_p,R / r          <= 这一行 v1 写在了分母

     r^3 = A_R^2 H_R Q_R K_R c_p,R / rho_R            …… (*)

   令 R_id=(A_R^2 H_R Q_R)^(1/3)、x=r/R_id：
     x^3 = K_R c_p,R / rho_R                            …… v2 通式
          v1 写成 x^3 = K_R/(rho_R c_p,R)，比热比放反。

   阻力分解。K_P=K_f,P+K_l,P，w=K_f,P/K_P；f∝Re^(-n)，
   Re ∝ m/(D μ) => Re_P/Re_M = r d mu_R，f_R=(r d mu_R)^n：

     K_R = [K_f,M + K_l,M]/K_P = w (lambda/d) f_R + (1-w)(1+delta)

   其中 lambda=L_M/L_P、d=D_M/D_P、delta=(K_l,M-K_l,P)/K_l,P。
     v1 的 K_R=1+w(f_R-1) 隐含 lambda/d=1 且 delta=0：
     它只对"各段 L 与 D 同比缩"成立（赵的理想圆管正是 lambda=d=0.5）。
   于是 v2 的待解方程：

     x^3 (rho_R/c_p,R) = (1-w)(1+delta) + w (lambda/d) (x R_id d mu_R)^n

   两处修正里，c_p 方向对赵只值 0.06 pp；lambda/d 对 KYLIN 值 2 pp 以上，
   并且把 KYLIN 全相似的"假失真"消掉（第三节）。
