2026-11-03 · 第十一轮 · 7 节 / 12 表 · 脚本 closure_v11.py（379 行日志，%% 残留 0 处）
复核输入：identifiability-v10-review-20261103（main 4a35464）· 原始文献：Yue 2017 PDF、Li 2015 PDF

一句话。三处意见全部成立，其中两处是我的算术错误、一处是我把结论说过头了。改完之后，本轮把复核给的下一道关口做了：用 Yue 的 Table 1/2/3 与式(3)(6)–(9) 逐项重算 KYLIN 的单侧阻力，得到两个可核的新数——Heff = 3.312 m（与 Xu 表 1 的 3.35 m 差 1.1%），以及Table 2 反解的 f 比 Blasius 高 61%、指数只有 0.049（Blasius 是 0.25）。后者决定 Table 2 只能定 L3。

一、三处认账

1.1 「δ 没有观测足迹」说过头了

站得住的部分是秩分析：方程 F=0 只含 A=(1−w)(1+δ) 与 B=w·(λ/d) 两个聚合量，所以一个成对流量 FoM 只能给出一条直线 A + B·f = K。这一点复核也保留。

站不住的是由此推出「δ 不可观测、文献永远补不了」。δ = kM/kP − 1 是成对局部阻力系数比，它在逐段压差里有直接足迹。正确的表述是：δ 在「这一个 FoM」里没有足迹，不在「任何观测」里没有足迹。

连带两处也要改：v10 的 w=0.95 那行给出 A=−0.150716、δ<−1，已离开非负局阻定义域，不能再当物理候选；δ≥0 也不是普适前提——阀门开度不同可以让局阻失配为负，所以 v10 的 δ∈[0, 8.88%] 只能读作「c=1 且 δ≥0 的声明情景」。

二、识别设计重做：功率不是旋钮，μR 才是

复核那句「功率跨度本身不保证两侧 Re 比发生变化」，在模型里有精确的代数形式。模型的 f 是

f(x) = (x·R_id·d·μ_R)^n，而 x·R_id = r_m（流量比）
     ⇒  f = (r_m · d · μ_R)^n

里面没有功率，也没有 Re。一对成对工况在 24 kW 与 240 kW 上，只要两侧同按 P1/3 走，r_m、d、μR 全都不变 ⇒ f 逐位相同 ⇒ 是同一个方程。v10 的 f2/f1=(Q比)−1/12 隐含「只有一侧流量变」，成对台架上不成立。

结论：即使设计到最优，现实精度下 B 也只能定到 114%。不是样本不够，是分母太小：B = 0.291，而 σD=2% 给 σK=0.06，乘 √2 再除以 Δf=0.256 就是 0.33，超过 B 本身。所以「从流量 FoM 识别 (A,B)」这条路应当放弃，改为：报 (A,B) 的等值线 + 明细写区间；δ 走另一条观测（成对逐段压差）。

三、KYLIN 几何与阻力：Table 2 的五个点逐项重算

输入全部取自 Yue PDF：p2 Table 1（总高 5 m、HS 长 1.8 m、活性 0.8 m、主管内径 26 mm、HS 内径 54 mm、棒径 22 mm）、p3 式(3)(6)–(9)、p4 Table 2。

3.1 面积与水力直径

A_pipe = π/4 × 0.026²  = 5.30929e−4 m²
A_HS   = π/4 × (0.054² − 0.022²) = 1.91009e−3 m²
D_h,HS = 0.054 − 0.022 = 0.032 m
A_pipe/A_HS = 0.277961   ⇒  (A_pipe/A_HS)² = 0.077262

那个 0.077 就是 KHS 只有 2.6 的原因：Kl,eff = f·(1.8/0.032)·0.077 = 4.346·f。漏掉这个因子，HS 段损失会被放大 12.9 倍（0.169 → 2.19）。

四、f = 0.0395 与 0.0245 的差从哪来

4.1 先排除「长度记错了」

若坚持 Blasius 的 0.024503，复现 Kpipe=17.7 需要 Leff = 16.70×0.026/0.024503 = 17.72 m，是 11 m 的 1.61 倍。但长度改不了斜率：L=17.72 m 在 Re=5560 处给 Kpipe=25.97，表里是 19.1（高 36%）。长度只能平移，不能改斜率 ⇒ 长度不是原因。

六、24 kW → 17.9 kW：能算，但检验力有限

6.1 标定

用 Li §3.3 的 24 kW / 1.21 kg/s（最大开度、最大温差）反解：K24 = 23.173；与 Table 2 在 ṁ=1.21 的插值 22.880 差 +1.28%——与 Heff 自身 ±1% 的不确定度同阶，可以认为 24 kW 点与作者模型是同一个 K。

6.2 四种算法，结论一致

不做任何重标定，17.9 kW 的预测落在 1.091–1.099，实测 1.12，偏差 −2.0% ~ −2.6%。这个量级本身是可以接受的。

6.3 但它证明不了阻力分解

从 m=0.25 走到 m=0.05，预测只动 0.0078 kg/s（0.7%）。原因很直接：ṁ ∝ K−1/3，而 K 在 24→17.9 kW 之间只变 1.8%，流量只变 0.6%。要区分两种 f 律，需要 0.7% 的流量分辨率；K 型热电偶在 ΔT=108.6 K 上已经给 ±1.4%——差 2 倍，做不到。

反过来，要解释「实测 1.12 vs 预测 1.094」的 2.07%，需要下列任一项成立：K 低 6.2%，或净功率高 6.2%，或 Heff 从 3.31 变成 3.52 m。三者都在「口径未对齐」的合理范围内。所以这个点无法证伪阻力分解，它能做的是另外三件事：

  • P1/3 律：Li 四点 log-log 斜率实测 0.563，K 恒定时应为 0.333，差 1.69 倍——数据本身就否掉了 K 恒定。但它否不掉的是「K 随功率变」。
  • 阀位一致性：见 6.4，这是它真正卡住的东西。
  • 有没有在中途换 regime（层流化、气体夹带）。

四点隐含 K 变 2.95 倍。摩擦给不出这个变化：ṁ 变 2.4 倍时，m=0.25 只让 K 变 1.25 倍，m=0.05 只变 1.05 倍。而 Li §3.3 明写 24 kW 点是「最大温差且阀开度」下取的，§3.2.1 的扫描只说了「二级油流量保持 1.02 kg/s」，没有阀位记录。

所以这 2.95 倍的 K 变化，最可能是阀位，不是物理。这恰好反过来支持复核那句「同一阀位」：不记阀位，单侧闭合连「哪一条 K(ṁ) 曲线」都定不下来。这是本轮最硬的一条实验设计要求，而且它不是从文献推出来的，是从 Li 自己的四点数据里逼出来的。

七、可写 / 不可写

可写

  • 3% 判据的双侧带 A ∈ [0.537139607, 0.712346444]，点值距上边界 0.003818604（+0.5389%），距下边界宽 45.0 倍；单调性已核。
  • 单点秩：一个成对流量 FoM 给一条等值线；δ 在这一个 FoM 里没有足迹，但在成对逐段压差里有。
  • σB/B：最好设计 28%，现实 114%。「从流量 FoM 识别 (A,B)」应放弃。
  • Heff = 3.312 m（Yue Table 3 反解）与 Xu 表 1 的 3.35 m 互校，差 1.1%。
  • Table 2 反解 f = 0.0395–0.0428，比 Blasius 高 17%–61%，指数 0.049（Blasius 0.25）；KHS 的斜率来自构件项（mfit=0.056），不是摩擦。
  • 24 kW → 17.9 kW：预测 1.091–1.099，实测 1.12，偏差 −2%；判别力 0.7%，不足以识别 f 律。

不可写

  • 「十倍功率把 B 定到 9.3%」——作废（应为 32%，且该设计在成对台架上不成立）。
  • 「δ 不可观测 / 文献永远补不了」——作废，只成立到「这一个 FoM 分不开」。
  • 「A ≤ Acrit 就是 3% 判据」——作废，须写双侧。
  • 「Table 2 可复现 / 可作 L2」——不可，按 L3 处理。
  • 「24 kW→17.9 kW 验证了阻力分解」——不可。24 kW 是标定点，17.9 kW 只差 26%，K 只变 1.8%，这个区间没有检验力。

下一步（按依赖排序）

  1. 把 Table 2 的 f 口径问清楚：作者用的是哪套物性（ρ 与 μ 差 44 K）、哪个 f 关联式（指数 0.049 不是 Blasius）。拿不到就只能标 L3，并把「复现作者口径」写在结论里，而不是「验证」。
  2. 成对识别设计：旋钮是 μR（温度对），不是功率；并要求 σD ≤ 0.5%，即必须独立测流量（标定段/电磁流量计），不能用能量平衡反算——Li 与 Yue 的流量都是后者。
  3. 阀位台账：所有工况记录阀门开度（并固定）。Li 的四点已经证明缺这一列会让 K 差 2.95 倍。
  4. GSA 入口：先用 (A,B) 做声明模型的情景灵敏度；物理概率 GSA 需要 (A,B) 的联合可行域，而单个 CFD 点的等值线不是二维盒。
