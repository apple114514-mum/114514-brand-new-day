一、重定位：先验与后验是两种问题，不是两种精度

先验分析的定义很窄：不确定度来源只能来自声明——公差、关联式验证域、仪表规格、物性版本、口径离散。 输出是「所声明模型内、所声明域上的偏差集合」，而不是「模型对不对」。后者要真值，本文没有，也不需要。

这条前提一旦定死，前面几轮的三个方向要改。

二、3% 余量的精确形式

赵案声明口径点值 D0 = +2.876835%，到 +3% 的余量是 0.123165 pp。这 0.123 pp 要由所有输入共同分担。 一阶关系是

dD = Y · e_i · dln(x_i),   Y = 1 + D0 = 1.028768352,   e_i = ln 弹性

令每个输入单独吃掉全部余量，得它允许的相对偏差：

输入ln 弹性 eitol@3%（%）tol@1pp（%）倍数
r_m+1.00000.11970.97208.1192
d+1.33330.08980.72908.1192
A_R+0.66670.17961.45818.1192
H_R−0.33330.35922.91618.1192
Q_R−0.33330.35922.91618.1192

倍数一列恒为 8.1192，因为两列都是同一个线性式，只差右端项（0.123165 pp 对 1 pp）。含义很直接：

同一个输入，用来支撑「1 pp」能偏 0.97%，用来支撑「满足 3%」只能偏 0.12%。 v8 那张表报的是「要 1 pp 需多准」，本轮报的是「要踩住 3% 需多准」——后者才是判据。

这不是新公式，是把 v8 的预算按实际余量重新标定。但它改变了一件事的份量： 原来「面积比要准到 1.46%」听起来很宽松，现在「r_m 要准到 0.12%」就不是了。

三、表 5 的印刷位数已经吃掉 77.5%

表 5 给 m_P = 540（无小数）、m_M = 92.79（两位）。按半个末位估计读数不确定度：

量绝对相对说明
m_P±0.50.0926%整数，末位即个单位
m_M±0.0050.0054%两位小数，本身不是瓶颈
r_m 合成—0.0927%两项平方和开根

而 r_m 在 3% 判据下的允许偏差只有 0.1197%。比值 77.5%。

赵案「满足 3%」这句话的成立，几乎完全由表 5 那两个数字印了几位小数决定。 m_P 若印成 540.0，允许量里立刻腾出八成；若印成 541，直接跨过 3%。 这是纯先验结论，不需要任何实验。

反向算一遍：只放 r_m 的印刷精度、其它按声明值固定，D_m 落在 [+2.781418%, +2.972253%]，跨距 0.191 pp，上端距 3% 只剩 0.0277 pp。

五、两张图的弹性：说「谁主导」必须先标图名

这里有两张不同的图，问法不同，答案的符号都可能相反。

Map I  （闭式，四个比值，不需求根）
       D_m = r_m · d^(4/3) / (H_R · Q_R)^(1/3) − 1

Map II （求根，含损失比 w 与阻力指数 n）
       F(x; w, d, n) = 0  ⇒  D_m = x − 1

基准点上两者重合（都 +2.876835%）。这是 QR2 = 32 的巧合 （4√2 的平方正好 32，于是 Rid 恰等于 QR），不是恒等式。扰动一开就分开。

5.1 三条解读，缺一条就会说错话

(a) d 的符号确实相反。Map I 里 d 是长度比，放大它等于放大理想比、偏差变大； Map II 里 d 进阻力项 w(λ/d)f，d 大则局阻小、流量更易上去、偏差被压。 所以正文任何「d 是主导参数」的句子，必须写清是哪张图。

(b) H_R 与 Q_R 在 Map II 里几乎消失。Map I 给 −0.3429，Map II 只剩 +0.0087 / +0.0133。 这不是数值噪声——三个步长 1e-4 / 1e-3 / 1e-2 给到同一位数。 原因是 Map II 的 D = x−1 已经用 Rid 归一化，改 H_R 只改基准、不改比值； 而 Map I 里 H_R 是设计参数，改它就是改相似性。 「有效高度主导」这句话只在 Map I 上成立，搬到 Map II 会差 39 倍。

(c) A_R 在 Map II 恒不可见。它只通过 Rid 进模型，与 H_R 同样被归一化掉。 这解释了 v8「A_R 是最不确定的一项」与 Map II 上「看不出危害」为什么不矛盾： 不是它无害，是这张图看不见它。

六、情景灵敏度与 GSA 的边界

不能把这套东西叫 GSA。GSA 要求输入联合分布，本文只有声明域（区间）； 而且 (A, B) 有 49.8 pp 的规范自由度（v10），直接对它抽样等于把一个人为坐标当成物理输入。 正确做法是对物理量（r_m, d, A_R, H_R, Q_R, n、物性版本）抽样，让 (A, B) 内生。

输出强度需要什么本文能否给
单因子区间强声明域能
情景包络（全组合角点）中声明域 + 独立性假设能
概率分布 / 方差分解弱联合分布不能（无来源）

措辞于是跟着定：

  • 「所声明域上观察到的最大绝对偏差」——可以说。导师 10-10 那句「角点最坏改成观察到」在这里落地。
  • 「保证不超过」——不能说。包络不是上界证书。
  • 「贡献率 / 谁主导」——只能在单因子口径下说，且标图名。
