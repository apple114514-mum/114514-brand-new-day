[A] 上界的适用域：三条前提，其中一条 v5 没写
==============================================================================
   上界 x <= max{A^(1/3), xbar} 的证明实际用了三件事：
     ① M(x) <= 1      在根处（物性方向）
     ② mu_R(x) <= 1   在根处（m1=754.1>0，x>=1 时 T_M>=T_P）
     ③ lambda/d <= 1  几何 —— **v5 只写了 ①②，③ 是隐含的**
   第 ③ 条来自 G=(1-w)A+w(lambda/d)f：只有 lambda/d<=1 才能把 f 换成 Bx^n
   而不放大。赵恰好 lambda=d=0.5，lambda/d=1，所以 v5 的式子"看起来对"；
   这与 v2 把 c_p 放分母是同一类"恰好参数相等所以看不出错"。

   一般化闭式（c=lambda/d 任意）：

        x <= max{ A^(1/3), (c*B)^(1/(3-n)) }         c=lambda/d, B=(R_id d)^n

   数值核对（把 c 换掉，其他不变，看端点是否被包住）：
   c      xbar_c     解析上限         端点 D(w=0)/D(w=1)         界宽出

   2.00   1.414214    +41.421356%    +0.000000%  +40.722039%    +0.6993 pp
   => 三条都对得上；c=1 一行就是 v5 的数（+9.9131%）。

   于是"适用域"的精确说法是三层，论文里必须分开写：
     层一（纯数学）：若根处 M<=1、mu_R<=1、lambda/d<=1，则界成立。
     层二（本模型）：M(x)<=1 等价于根 <= x_M=5.204652，即 delta<=139.985733（w=0 支）。
     层三（物性关联式验证域）：比层二窄得多，本项目只有 398.15 K 以上、

   论文写法：
     "在 M(x)<=1 的物性域内（本案例根 x<=5.2047、T<=875.8 K），δ 参数化界成立"，
     不写"对所有 delta>-1"。

     B=(R_id d)^n=(2.828427)^0.25=1.296839555  >1  ⇒ x<1 时 x^(3-n)<1<B 恒成立。

[F] F_dep_iv 的 delta!=0 缺陷：修与不修各影响什么
==============================================================================
   原式 G=(1+delta)+w[(l/d)f-(1+delta)]；v5 写成 G=1+w[(l/d)f-(1+delta)]，
   只有 delta=0 时等价。反例：
     delta=0.1, w=0, x=1：F_iv=[-0.100000000000005,-0.099999999999995]   F_dep_iv=[-4.32986979603811e-15,4.32986979603811e-15]
     => F_dep_iv 漏掉 -delta，把非根判成根。

   污染范围：v5 只在 [E] 的 KYLIN 根管里调用它，而那里 delta=0（Model 默认），
   所以**已印出的 KYLIN 根管结论未被污染**。今后凡非零 delta 的判根/判号，
   必须改用 F_iv 或修好的 F_dep_iv。v6 采用修正版：
     G = (1+delta) + w[(l/d)f-(1+delta)]，残差与原式一致（下面核对）
     delta=0.1, w=0.3, x=1.02：F_iv=[-0.0994744419313034,-0.0994744419312921]
     （F_dep_iv 正确版见 build_corrected()，数值应与上式区间重叠）
