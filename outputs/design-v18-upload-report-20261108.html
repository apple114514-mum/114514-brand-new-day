二、导数：把 −1/3 改回 (−(1+D)/3)

D = R−1/3 − 1 作为 R = KM/KP 的函数是精确的；但它的导数

dD/dlnR = -(1+D)/3      仅在 D=0 处等于 -1/3
D = 0    -> -0.33333
D = -2%  -> -0.32667
D = +2%  -> -0.34000

更关键的是：如果整体乘性地缩放 KM 并重新解流量，正确的弹性是

dlnx/dlna = -1/(3+s),  s = dlnK_M/dlnm
closure A: s = -0.113574  ->  -0.346449
closure B: s = -0.035089  ->  -0.337278

两个都在 −0.34 附近，离 −1/3 有 2–4%。这正是「把 K 预算换算成 D 预算」时必须用的系数。

命题结论状态

三、闭合一：加热段低 Re

环隙层流有闭式解，不必查表：

alpha = d_i/d_o = 0.40741
f*Re = 64(1-alpha)^2 / [1+alpha^2-(1-alpha^2)/ln(1/alpha)] = 94.762
     (a->0 给 64、a->1 给 96，两个极限都对，所以这个式子可用)

于是三段声明闭合：层流 f=94.762/Re；过渡 2300–5000 在双对数上连线；湍流用朱锋杰式。过渡段没有出处，这是声明，不是引用。

这里有个比数值更重要的区分。v17 让模型直接抄原型表的那一行（0.50 kg/s 时 KHS = 2.8），等于把原型的 Re 趋势搬进了模型。模型自己的 Re 只有原型的 0.44 倍，两者的 KHS 本来就该不同——这个差本身就是失真的一部分，抄表就把它藏起来了。换成模型自己的 Re，设计点 KHS = 2.4674（不是 2.6），阀门从 6.342 重新配到 6.475，0.50 kg/s 的 D 从 −2.03% 移到 −1.80%。0.23 pp，是本轮最大的一处更正，比联立/冻结的 0.08 pp 大得多。

但要说清楚代价有多大：环隙摩擦相对于主管动压被 (A_pipe/A_HS)^2 = 0.0773 缩了 13 倍，所以整条区间 KHS 只动 0.026（22.8 的 0.11%），D 只动约 0.04 pp。对流量 FoM 是小事；对热工 FoM（Nu、壁温）不是——后者这一轮没有界。这是第三次出现「局部换热失真对流量 FoM 不可见」（前两次：Wang 2025、赵案的 εQ）。

四、闭合二：阀门 Kv(Re)

喉部 9.41 mm，Re_throat = 4q_m/(π d_thr μ)：1.25 kg/s 时 20606，0.50 kg/s 时 8242。全程湍流，所以「Kv 为常数」在适用域内可以辩护，域外必须用厂家曲线。但它的斜率值多少钱？设 Kv ∝ Re−mv：

m_v = 0.10 就让 A 支从 −1.80% 走到 −2.64%，0.84 pp，等于整条曲线失真的一半。Kv 占总 K 的 28%（6.475/22.8），所以它的 Re 指数不能当零。结论：常数阀是一条有价的声明，不是无害简化；采购文件里要写「Kv(开度, Re) 曲线」而不是「Kv = 6.5」。

五、闭合三：热量口径只剩一个因子

动量与能量联立：Kρu2/2 = ρ g β H ΔT，Q = ρ u A cpΔT，得

u^3 = 2 g beta H Q /(K rho cp A)
取比、并令 u_R^ideal = sqrt(L_R):
  (u_R/u_R^ideal)^3 = PHI / K_R ,   D = (PHI/K_R)^(1/3) - 1
  PHI = [H_R Q_R /(A_R L_R^1.5)] * [beta_R /(rho_R cp_R)]

所有热量问题——功率口径、ΔT 口径、热损、物性参考温度——全部收进一个乘性因子 Φ，且 dD/dlnΦ = 1/3。

约定Φ含义
Φ = 1（设计约定）1.0000Q_R = 0.268316 = m_R，即 ΔT_R=1 且物性比为 1
模型温度低 100 K（473 vs 573 K）0.96225β×0.9876、ρ×1.0125、cp×1.0137 ⇒ D 移 −1.27 pp（占 3% 预算的 42%）
Φ 误差 1%—D 移 0.33 pp
热量单独吃满 3%±9.27%Φ 预算 = (1±3%)3

两个推论。① Φ = 1 要求 QM = 0.2683 QP(qm) 逐点跟随流量；恒功率加热器直接破坏它。② 模型若不在同一温度运行，β、ρ、cp 三个比值的乘积就进 Φ——100 K 是 1.27 pp，300 K 就吃掉整个预算。

六、连续曲线求界：不用再靠五个点

D(m) 对每个 m 都有定义（解 x3KM(x s m)/KP(m) = 1），KP(m) 在 Yue 五行上做双对数插值（声明）。600 点扫描：

闭合D(0.50)D(1.25)单调sup|D|距 3%
A 光滑 Blasius−1.80%0是1.80%1.20 pp
B Yue 反算 f+1.59%0是1.59%1.41 pp
单调性比数值更重要：D 在区间内单调，所以上确界就在端点取值，不需要分支定界。这让「条件上界」从「五个采样点里最大」升级成「连续区间上的 sup」——虽然它仍然只对这两个声明的 f 闭合成立，也仍然依赖五行之间的插值方式。

7.2 阶段Ⅲ（已配平）：静态误差恒等抵消

这是本轮最反直觉、也最该写进论文的一条。配平把阀门定在设计点使 KM(1.25) = 22.8。此后任何一个不随流量变的误差都会恒等抵消：若 KEV 实际是 3.75、阀门小 1.25，两者在任何流量下的和都不变。所以KEV 的 ±50% 在配平后对 D 的影响严格为零——GSA 给出 ST = 0.003，与解析预期一致。
