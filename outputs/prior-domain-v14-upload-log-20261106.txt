v14  先验路线的输入域与判据裕度
==============================================================================

[A] 重定位：先验 vs 后验

  A1  先验分析的定义（本文采用的）
      不确定度来源只能来自**声明**：公差、关联式验证域、仪表规格、
      物性版本、口径离散。输出是「所声明模型内、所声明域上的偏差集合」，
      不是「模型对不对」——后者要真值，本文没有、也不需要。

  A2  三条后果（都是减法）
      (1) L3「对实测反解」退出输入域。
          v11 用 Yue Table 3 反解 H_eff=3.3119 m，那是 L3；它依赖一个
          自由假设 L_pipe~11 m，不能当输入。先验下 H 只能来自几何声明。
      (2) KYLIN 24->17.9 kW 与同篇五功率趋势，**不属于本文**。
          那两轮做的是「用 24 kW 预测 17.9 kW 看准不准」= 后验验证。
          它们不是失败，是**方向错位**：本文没有实验真值可对。
          结论保留价值仅一条：判别力 0.7% < 热电偶 1.4%，说明这类验证
          在文献数据上本来就做不成——这反而支持「先验是唯一可行路线」。
      (3) 输入域从「等实验数据」改为「查公差与手册」。
          这一条最要紧：前十三轮卡住的六个量（阀位、净热、独立流量、
          误差链、f 关联式、物性参考温度）**在先验框架下根本不需要**。

  A3  先验输入域的五类来源（每一类都可核，不需要实验）

来源                    本文可用的量                              是否需要实验
----------------------  ----------------------------------------  ------------
① 几何公差              棒径/栅距/管径的加工公差                  否          
② 关联式验证域          阻力式 Re 范围、弯头 K 的适用域           否          
③ 仪表规格              热电偶 ±1.4%、功率 ±0.5%                  否（查样本）
④ 物性版本              X26 与 Zhao 表 4 两套公式的离散           否          
⑤ 口径离散              Q_R 的 4*sqrt(2) 与 10/1.77               否（都在原文里）

  => 五类里没有一类需要新做实验。这是本轮最重要的一句。

[B] 3% 余量换算成各输入的允许偏差

  点值 D0 = +2.876835%，Y = 1+D0 = 1.028768352
  余量 = 3% - D0 = 0.123165 pp = 0.001231648（绝对）

  一阶关系：dD = Y * e_i * dln(x_i)，e_i 为 ln 弹性
  令 dD = 余量，得每个输入单独吃掉全部余量时的允许相对偏差：

输入         ln 弹性 e_i     tol@3%（%）    tol@1pp（%）       倍数
----------  ------------  --------------  --------------  ---------
r_m              +1.0000          0.1197          0.9720     8.1192
d                +1.3333          0.0898          0.7290     8.1192
A_R              +0.6667          0.1796          1.4581     8.1192
H_R              -0.3333          0.3592          2.9161     8.1192
Q_R              -0.3333          0.3592          2.9161     8.1192

  倍数一列恒为 8.1192 —— 因为两者都是同一个线性式，
  只差右端项。含义很直接：

  **同一个输入，用来支撑「1 pp」能偏 0.97%，用来支撑「满足 3%」只能偏 0.12%。**

  这不是新公式，是把 v8 那张 1 pp 预算表按「实际余量」重新标定。
  v8 报的是「要 1 pp 需多准」，本轮报的是「要踩住 3% 需多准」——后者才是判据。

[C] 表 5 的印刷精度已经吃掉多少

  表 5 给 m_P = 540（无小数）、m_M = 92.79（两位小数）。
  按半个末位估计读数不确定度：

    m_P: 540 +-0.5  =>  0.0926%
    m_M: 92.79 +-0.005 =>  0.0054%
    r_m 合成        =>  0.0927%

  而 r_m 在 3% 判据下的允许偏差只有 0.1197%。
  比值 = 77.5% —— **仅印刷位数就占掉 77.5%**。

  这一条的份量：赵案「满足 3%」这句话的成立，几乎完全由表 5 那两个数字
  印了几位小数决定。m_P 若印成 540.0，裕度立刻变三倍；若印成 541，
  直接跨过 3%。**这是先验结论，不需要任何实验。**

[D] 反向：按现有精度，D_m 的可行区间

  只放 r_m 的印刷精度（其它按声明值固定）：

    r_m in [5.814195000, 5.824990257]
    D_m in [+2.781418%, +2.972253%]
    跨距 0.190835 pp；上端距 3% 还有 0.027747 pp

  再叠「口径离散」这一条 —— 它比印刷位数更狠，但性质不同。

  v8 已核过三个 Q_R 口径（本轮不重算：换 Q_R 会连带改变 T_P 与 w，
  固定 w 去换 Q_R 会得到假的零跨距，我第一版就这么错了）：

Q_R 口径                                数值             D_m  是否 <= 3%  
--------------------------  ----------------  --------------  ------------
4*sqrt(2)（理想）                5.656854249      +2.876835%  是          
表 3 印数 10/1.77                5.649717514      +2.920135%  是          
表 5 反算                                  —      +3.612800%  **否**      

  三个口径跨距 0.736 pp，**其中表 5 反算口径已经跨过 3%**。
  注意性质：这不是误差条，是「哪个 Q 才是对的」的口径选择问题。
  所以正文必须并排报三个数，不能只报最好看的那个。

  合起来，判据有两重脆弱性：
    (i)  印刷位数：r_m 的 0.0927% 已占允许量 77.5%（要 0.1197%）；
    (ii) 口径离散：三个 Q_R 口径跨 0.736 pp，直接跨过 3%。
  (i) 是精度问题，(ii) 是定义问题。**后者不能被更好的仪表修好。**

[E] 两张图的弹性：说「谁主导」必须先标图名

  Map I 是闭式（四个比值，不需求根）：
      D_m = r_m * d^(4/3) / (H_R * Q_R)^(1/3) - 1
    也可写成 D_m = r_m / R_id - 1，R_id = (A_R^2 * H_R * Q_R)^(1/3)
  Map II 是求根（含损失比 w 与阻力指数 n）：
      F(x; w, d, n) = 0  =>  D_m = x - 1

  基准点：Map I = +2.876835%  /  Map II = +2.876835%
  两者在基准点重合，是 Q_R^2 = 32 的巧合（4*sqrt(2) 的平方正好 32），
  不是恒等式 —— 扰动一开就分开，这正是下一张表要说的事。

参数               Map I        Map II  两者关系                          
----------  ------------  ------------  ----------------------------------
r_m              +1.0288       +1.0288  同（Map II 里解析为 Y*1，已归一化）
d                +1.3717       -0.1269  **符号相反**，量级差 10.8 倍      
lam                  —         +0.1228  Map I 里不出现（只进阻力项）      
H_R              -0.3429       +0.0087  **符号相反，量级差 39 倍**        
Q_R              -0.3429       +0.0133  **符号相反，量级差 26 倍**        
A_R              -0.6858       +0.0000  I 为松懈版；II 为零（只经 R_id）  
n                    —         +0.0327  Map I 里不出现                    

  三条解读，缺一条就会说错话：

  (a) d 的符号确实相反（I +1.3717 / II -0.1269）。
      Map I 里 d 是长度比，放大 d 等于放大理想比、偏差变大；
      Map II 里 d 进阻力项 w(lam/d)f，d 大则局阻小、流量更易上去、偏差被压。
      => 正文任何「d 是主导参数」的句子，必须写清是哪张图。

  (b) H_R 与 Q_R 在 Map I 是 -0.3429，在 Map II 只剩 +0.0087 / +0.0133。
      原因不是数值噪声（三个步长 1e-4/1e-3/1e-2 给同一位数），而是
      Map II 的 D = x-1 已经用 R_id 归一化，改 H_R 只改基准、不改比值；
      Map I 里 H_R 是**设计参数**，改它就是改相似性。
      两个问题的问法不同，不是谁对谁错。
      => 「有效高度主导」这句话只在 Map I 上成立，搬到 Map II 会差 39 倍。

  (c) A_R 在 Map II 恒为零（-0.6858 vs 0）。
      它只通过 R_id 进模型，与 H_R 同样被归一化掉。
      => 这解释了 v8「A_R 是最不确定的一项」在 Map II 上却看不出危害：
         **不是它无害，是这张图看不见它。**

[F] 情景灵敏度与 GSA 的边界

  F1  不能叫 GSA 的理由
      GSA 要求输入**联合分布**。本文能给的只有「声明域」（区间），
      没有分布；且 (A,B) 有 49.8 pp 的规范自由度（v10），
      直接对 (A,B) 抽样等于把一个人为坐标当成物理输入。
      正确做法：对**物理量**（r_m, d, A_R, H_R, Q_R, n, 物性版本）抽样，
      让 (A,B) 内生。

  F2  能给的三种输出（按强度排）

输出                        强度        需要什么                    本文能否给  
--------------------------  ----------  --------------------------  ------------
单因子区间                  强          声明域                      能          
情景包络（全组合角点）      中          声明域 + 独立性假设         能          
概率分布 / 方差分解         弱          联合分布                    不能（无来源）

  F3  措辞
      「所声明域上观察到的最大绝对偏差」——可以说。
      「保证不超过」——不能说（包络不是上界证书）。
      「贡献率 / 谁主导」——只能在单因子口径下说，且标图名。

[G] 可写 / 不可写

  可写（先验框架内成立）
    1. 判据裕度的精确形式：0.123165 pp 余量 => r_m 只能偏 0.12%。
    2. 表 5 印刷精度占掉 77.4% 的允许量 —— 判据成立与否由位数决定。
    3. 两张图弹性符号相反（d），故「主导参数」必须绑定图名。
    4. 五类输入域来源全部不需要实验；六个卡点在先验下不存在。
    5. H_R/Q_R 的弹性在两张图上差 26~39 倍（0.343 -> 0.009/0.013），
       且符号相反。「有效高度主导」只能贴着 Map I 说。
    6. A_R 在 Map II 恒不可见 —— v8 说它最不确定，而 Map II 看不出危害，
       这两件事不矛盾：**是这张图看不见它**。正文必须把 A_R 单列。

  不可写
    1. 「模型得到验证」——先验框架内没有验证这个概念。
    2. 「H_eff 两篇互校」——同源，且 L3 不进输入域。
    3. 「谁主导」不带图名。
    4. 「包络保证不超过 3%」。
