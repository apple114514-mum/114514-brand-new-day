# 物理参数域问题：给 DeepSeek 的研究交接

**截至 2026-11-06。** 目标是在台架设计阶段，对自然循环缩比的流量等关注量给出**模型条件下、输入域有来源的先验失真界**。目前数学归约和情景判据已能运行；瓶颈是把几何、局阻、热量和误差的**物理可行域**建立起来。请优先突破这个瓶颈，不要再用任意的 `±5%`、`±7%` 或独立均匀参数盒填空。

## 1. 已完成的工作及各自用途

1. **基准和关注量**：以明确的理想流量比为分母，定义 `D_m = m_M/m_M^ideal − 1`；分母、功率口径和流通面积定义变了，所谓“失真”也会变。另关注温升，但它与同控制体热量和流量相关，不能当独立观测。
2. **两张映射**：Map I 用已知的成对输出归约失真，能反推输入需要多准；它包含事后 CFD 流量，**不是设计阶段预测**。Map II 从几何、热量、阻力和物性前向求关注量，才承担先验条件界。
3. **模型内降维**：在固定口径和模型闭合下，可写成 `K(x)=x³/M(x)=A+B f(x)`，其中 `x=1+D_m`、`A=(1−w)(1+δ)`、`B=w(λ/d)`；`w` 为原型分布摩擦份额，`δ=k_M/k_P−1` 为两侧同参考动压下的等效局阻失配，`λ` 为摩擦路径长度比，`d` 为所选水力直径比。**这只是声明模型的重参数化**，不能把 `A、B` 的拟合值当实物测量。非线性、大扰动上界还须核对物性有效域、根的存在唯一性和区间包含。
4. **摄动、GSA、上界各有职责**：摄动给局部梯度、误差预算和优先测量项；GSA 在给定**有来源的联合域或分布**后给全域贡献排序；最大失真度由解析不等式或经验证的区间方法给出。GSA 的排序不能代替最坏情形界。

## 3. 最硬的参数域缺口

| 量 | 目前状态 | 合格的物理域需要什么 |
|---|---|---|
| 净面积比 `A_R`、水力直径比 `d`、摩擦长度比 `λ` | 赵案只有宏观 2:1 几何签名；净流道及逐段路径未列。 | 两侧流道截面、棒束/多孔介质等效规则、逐段长度和制造公差；明确参考截面。不能同时把 `A_R` 与 `d²` 作为独立不确定输入。 |
| `w` 与 `δ` | 一个成对流量 FoM 只给 `A+Bf=K` 的一条等值线；`w=.291472` 等是选 `δ=0` 和热量口径后的校准坐标。 | 同口径成对逐段压差、流量、密度、面积、阀门开度及误差；或两套能分离 `A、B` 的成对工况，且必须检验两点 `f` 的分离度与共同误差。`δ` 只在**单个总流量 FoM**下不可辨识，不是永远不可测。 |
| 逐构件 `K_i(Re)` | Al-Tameemi–Ricco 的水/空气斜接弯头式反驳了“所有局阻指数 ≤0.2”的通用假设；它本身也不能移作 KYLIN 阀门/三通的域。 | 匹配构件形状、开度、粗糙度和 Re 范围的原始关联式及验证误差；构件权重须用**同一参考动压**换算。拿不到时把 `δ` 留作显式自由参数。 |
| 有效入热比、散热、物性 | KYLIN 五功率相对拟合可得等效偏移 `L_fit≈1.25 kW`，但它**不是已测加热段外表热损**；绝对热账和热平衡推流量未闭合。物性下限 `398.15 K` 的原始适用域出处仍待核。 | 加热段及沿程分段热平衡、净/毛功率定义、独立流量或热量测量、物性原式及适用温区。至少两个功率点才能检验“恒定热损”情景。 |
| 误差与相关性 | 文献未给够同工况仪表、CFD、图读的联合误差；`±0.03 kg/s`、`σ_D=.5 pp` 等均是演示情景。 | 仪表校准、热量反算的协方差、加工公差、关联式验证残差；不能把原文数字印位当误差界。 |

KYLIN 第十三轮的 `L_fit` 只说明：在指定理论阻力插值与 17.9 kW 锚点归一化下，一项曲线偏移可使五个图读点接近。最新复核已撤回“它是实物热损”“测一次热损就可按 0.66/1.38 kW 三分机制”“局阻最多解释 63%”等结论。有效高度的正确集总式为 `m³=H·P_net/(C·K)`；固定几何下把 `H` 设常数是模型声明，不是实测界。

## 4. 请 DeepSeek 具体突破的问题

请以**物理参数域的来源与可辨识性**为主题，优先找出能支持赵案 `A_R、d、λ` 和成对 `δ、w` 的**原始量**。逐项给出：定义和参考动压/控制体、原文页码及表/式、数值或区间、Re/温度/阀位等适用条件、误差来源、变量相关性、是否属于原文直给或条件反算。原文找不到就明确留白，勿用经验百分比补。

建议按三条路径分别判断：

1. **文献/图纸路径**：赵案原型与台架是否有可获得的净流道、棒束/多孔介质映射、逐段压差或热源积分？KYLIN 的单侧资料能否只用于检验模型闭合，避免冒充成对局阻？
2. **部分识别路径**：若无法分别定 `w、δ`，可否从已观测的总阻力和物理非负性、阀位记录、分段压差得到**联合可行集**，而非独立参数盒？区分“数据归约点值”“模型条件界”“实物保证”。
3. **最小补测路径**：按对 3% 结论的影响排序，指出最少需补哪几个量、在哪两侧/哪些工况测、需什么同口径定义；给可执行的验收方法。若域建不起来，请给出诚实可发表的较小主张，例如参数化可行域与测量需求，而不是宣称具体台架已保证 `≤3%`。

请交付一张**参数—来源—适用域—相关性—缺口—可否进先验界**矩阵，以及最多三条最有希望的突破路线。每个数值都附可复核原文坐标；先检查反例与已撤回项，再提出新范围。**不要声称“本研究是第一个做先验失真界”**，也不要把 GSA 情景分布说成实物概率分布。
