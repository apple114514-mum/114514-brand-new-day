# 已上传文献再利用核查：联合前向输入域

2026-11-09。范围：已上传的 Yue 2017、Li 2015、Shi 2019、Zhang 2020、IAEA LFR-21、OECD/NEA 2015、Xu 2025、Carnevali 2025，以及赵鹏程 2020 的参考文献。只判断这些材料能否支撑本项目的**独立前向输入**；文献里的缩放准则不作为模型几何或阻力的配平约束。以下“PDF 页”从文件首页起算。

## 最有用的四项发现

1. **P 侧热边界并非完全空白。** Yue 2017 PDF p4 §4.1 给出一个可复现的 **CFD 比较分支**：17.9 kW 加热壁面热流、HX 油侧换热系数 `4.89 W/(cm²·K)`、油侧自由流温度 `200 °C`；p5 §4.2 明说该 CFD 令回路绝热，并把底部阀门替换成直管。这足以写出一个**文献声明的 P-CFD 热边界情景**，但不能叫 KYLIN-II 实物热边界，也不能把该局部换热系数直接叫作整台换热器 `UA`。Yue p4 Table 3 另有 4–24 kW **理论**功率矩阵；p6 §5.2 给 17.9 kW 理论/实验/CFD 流量 `1.10/1.12/1.20 kg/s`。若选择 P-CFD，比较对象和功率必须与此分支一致。
2. **`1.25 kg/s、K=22.8` 不是 P 侧实测稳态锚。** Yue p4 Table 2 是按指定流量计算的理论阻力表；p3 式(6)–(9) 明列 `K=K_HS+K_EV+K_pipe`，其中 11 m 管长是作者的 *assumed conservatively*，`K_EV≈2.5` 据该设施先前经验。该表没有单列阀门 `K`。Yue p6 §5.2 又说 CFD 未模拟横支阀门，导致预测流量偏大。因此可把 22.8 用于**核对文献理论阻力口径**，不能把任意假设功率前向得到的 `ṁ_P/1.25` 叫作相对实测的闭合残差；`ζ_v=0.10–0.50` 也不是原文提供的阀位区间。
3. **NEA 手册给出两个不同层级的“适用域”。** 2015 手册 PDF p932 Table 15.3.2 列 Churchill 圆管摩擦为 *all ranges*；p934 Table 15.3.3 列有限厚孔板第 3 式 `Re>10³`。但 p940 §15.5 明说本章基于 HELIOS 的**最佳实践建议**仅可推荐于实验 `10⁴<Re_D<2×10⁵`，且自然循环尚待进一步基准验证；p939–940 Table 15.4.1 的推荐孔板式还是 `Re>10⁵` 的另一式。故本设计在 `Re≈3×10³–10⁴` 使用第 3 式属于**表列公式域内的条件模型**，并未获得 HELIOS 低 Re/LBE 自然循环实验保证。这是核域中应单列的模型形式情景，不应只设 `Re>1000` 一道门便称“已验证”。
4. **已有两篇 LBE 实验可用作阻力模型形式对照。** Shi et al., *Progress in Nuclear Energy* 115 (2019) 99–106，上传文件 `1-s2.0-S0149197019300605-main.pdf`，PDF p6 式(7)：环隙 `f=0.102(ε/D_e+462/Re)^0.295`，`5000<Re<35000`；Fig.12 中拟合曲线约高于 Blasius 30%。其测试环隙为外管内径 26 mm、棒径 20 mm（PDF p2），**不同于 Yue 的 54/22 mm 环隙**，且文中 `ε=0.0015 mm` 是选取值，不是该新设计的粗糙度实测。Zhang et al., *Applied Thermal Engineering* 180 (2020) 115820，上传文件 `1-s2.0-S1359431120333020-main.pdf`，PDF p4–6：20/35 mm 圆管 LBE，实测拟合 `f=0.1581/Re^0.13`（p6 式(24)，实验 `3.8×10⁴<Re<1.8×10⁵`），并明确说其粗糙度来自推荐值、没有实际测量。这两式能证明“单用光滑管摩擦式不是唯一有据选择”，却**不能外推成**拟建 16 mm 管在 `Re≈3×10³–2.4×10⁴` 的已证上下界。

## 对《联合核域操作方案》的具体修订

1. **先固定 P 分支身份。** 最便于完整前向的是“Yue 17.9 kW CFD 边界 P”，但它代表**论文的 CFD 场景**；另一条“Yue Table 2/3 理论 P”可以做文献输出对照。不要同时拿 Table 2 的 `1.25` 当已观测流量、用 Table 3 的 24 kW、再借 §4.1 的油侧边界——那是三个不同口径。
2. **把 P 阀门做成分支，不给无出处的默认区间。** 理论式(6)–(9)和 CFD 都没有明确的阀门压降；实物有横支阀门且开度未定。可设“无阀理论/CFD”与“含阀的明示情景”，后者所取 `K_v` 范围必须标设计假设。IAEA 设施档案不能替它定值。
3. **热核域需一个独立的冷却控制律。** Yue 的 CFD 边界可作 P 的一种已声明方案；拟建 M 可声明“加热入口温度受控、冷却量由控制器调整”，并检查所需 `UA`、油侧温度及能力。仅给 `UA_max` 不能决定实际冷却量；在未给控制律时，入口温度也不能同时被视为自由输入与求解输出。
4. **摩擦和孔板采用“基础闭合＋形式情景”，不伪造概率。** Churchill、孔板第 3 式可作基础条件模型；Shi 的环隙式、Zhang 的圆管式是几何或 Re 不同的**结构性警示/外推情景**，不能直接当新回路系数区间的概率边界。GSA 分开报告每个模型分支，连续参数只在各自有效域内扰动。
5. **比较尺 `r_ref` 仍是研究者预先定义的功能目标。** 文献能给功率、温度和某些预测/实验流量，却不能替论文决定“哪一种功能算等价”。若用 `Q/Δh` 定义，须让 `Q` 和目标 `Δh` 独立于同一组前向输出；否则 FoM 会被能量守恒消成零。没有明确目标时，先报告 `ṁ_M/ṁ_P` 与 `r_ref` 的函数，不报“3% 失真已满足”。

## 参考文献链的下一优先级

- **Yue ref. 21 / NEA 第15章：** Cho 等，2011，LACANES Phase I，*Journal of Nuclear Materials* 415:404–414。它在 NEA 2015 手册中已被摘要并用于表 15.4.1；若要核 HELIOS 原始 Re、孔板面积比和各构件压差，应读原论文。它**不能**补 KYLIN 的阀位。
- **赵鹏程 2020 ref. [5]：** 吴磊等，2016，《自然循环系统流动—阻力特性理论和实验研究》，《核动力工程》37(03):10–15。题目与本项目的回路阻力曲线最贴近，当前上传材料未包含原文；先索取它，再判断几何/工质/工况是否可移植。
- **NEA 2007 物性手册：** Yue 2017 ref. 1。若要追 X26 密度式或早期物性版本，可核原式；现阶段 NEA 2015 已足以给两侧同口径物性模型，2007 版不会替代阀门/冷却边界。
