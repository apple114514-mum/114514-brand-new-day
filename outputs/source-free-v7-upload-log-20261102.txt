[B] v6 两处缺陷的精确定位
================================================================================
  v6 的原式：min{0, A^(1/3)-1} <= D <= max{A^(1/3), q}-1

  缺陷 1（下界）：min{0, A^(1/3)-1} 在 delta>=0 时等于 0，
    这等价于断言 K_R >= A，即 (1-w)A + w c f >= A，即 c f >= A。
    w=1 时 K_R = c f；只要 c f < A 就有 x<1 即 D<0。
    Zhao 的 c=1 时 f(1)=B=1.2968>1，所以这条恰好成立 —— 这是 c=1 的巧合。
  缺陷 2（上界）：推导用了 f(x) <= B x^n，即 mu_R <= 1，即 T_M >= T_P，即 x >= 1。
    当 c<1（或 delta<0）把根推到 x<1 时，mu_R>1，该步失效。
    v6 补了一句"x<1 时 D<0 <= max-1"，但 max{A^(1/3),q}-1 在
    c<1 且 delta<0 时是负数，这句话不成立。

  佐证（缺陷 1）c=.5, delta=0, w=1：
    根 x = 0.855835044351（< 1），K_R = c*f = 0.626777676750（< A = 1）
    D = -14.416496%    而 v6 下界给 0%

  佐证（缺陷 2）同一根处：
    x = 0.855835044351 < 1  =>  T = 587.623 K < T_P = 596.874 K
    mu_R = 1.020091208043 > 1  =>  f > B x^n 成立
    f = 1.253555353499    B*x^n = 1.247336884339   f/(B x^n) = 1.004985397

  在 delta=0 时，v6 下界 D>=0 成立当且仅当 w=1 端的根 x>=1，
  即 c*f(1) >= 1。而 f(1) = B（x=1 处 T=T_P，mu_R=1），故条件化成

      c >= 1/B = 0.771105412704

  数值求解 D(w=1)=0 的临界 c0 = 0.771105412704
  与 1/B 的差 = -3.331e-16  =>  "c >= 1/B" 与数值临界点一致

    c = 1  <=>  长度与直径同比例缩（几何相似缩比）

[D] 对称条件界：命题、证明、分支前提
================================================================================
  记 A = 1+delta, q = (cB)^(1/(3-n))。命题：

      min{1, A^(1/3), q} - 1  <=  D_m  <=  max{1, A^(1/3), q} - 1

  证明（两支，均只用 x^3 = M[(1-w)A + w c f] 与 f 对 x 的界）：
    支一 x>=1。若根处 M<=1、mu_R<=1，则 f<=B x^n，故
      x^3 <= (1-w)A + w c B x^n。
      反设 x > max{1, A^(1/3), q}，则 A < x^3 且 cB x^n < x^3，
      凸组合 (1-w)A + wcBx^n < x^3，与 x^3 <= 该式矛盾。故 x <= max{1,A^(1/3),q}。
    支二 0<x<1。若根处 M>=1、mu_R>=1，则 f>=B x^n，故
      x^3 >= (1-w)A + w c B x^n。
      反设 x < min{1, A^(1/3), q}，则 A > x^3 且 cB x^n > x^3，
      该式 > x^3，与 x^3 >= 该式矛盾。故 x >= min{1,A^(1/3),q}。
    两支穷尽，命题成立。

  ★ 关键：这是对"根"的条件命题，不含循环论证 —— 不预设根的位置，
    只要求根所在那一支的 M、mu_R 方向成立。

  分支前提的数值核验：
    M(x)=1 的第二个交点 x1 = 5.204652  （T = 875.8082 K）
    x in [1, x1] : M<=1 且 mu_R<=1 ？ 违约 0 / 2000
    x in [0.3, 1) : M>=1 且 mu_R>=1 ？ 违约 0 / 1400
    => 支一的有效域是 x <= 5.204652，不是"M 单调"（见 [E]）

  三层结构（论文必须分开写）：
    层一 纯数学：上面两支，前提是根处 (M,mu_R) 的方向。
    层二 本模型：5.204652 是支一的上限；本模型网格内最大根远小于它（见 [F]）。
    层三 物性域：网格内根的温度上限（见 [F]），才是真正受限的一层。
