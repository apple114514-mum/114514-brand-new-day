紧包络+9.7782%：区间证书，依赖 libm 的 ulp 假设，宽度 6.2e−15。

4. δ=±7% 撤回

Xu 的 <7.3% 是标准缩比 CFD 算例的流量偏差上限，不是局部阻力系数之比。复核给的代数反驳我逐项算了：若 Dm=+7.3% 全归局阻，则

K_R 需增 (1.073)^3 − 1 = 0.235376     （不是 0.073）
δ = 0.235376/(1−w)：
  w=0.0 → δ=+0.2354     w=0.3 → +0.3363
  w=0.5 → +0.4708     w=0.8 → +1.1769
  w→1   → 分母消失，δ 无法反推

而且 Xu 报的是"多个算例的小于 7.3%"，不是一个点；那个残差里同时含几何、热路、物性、湍流模型。"7% 是 δ 的一手量级锚"整句撤回。

w=1 时 (1−w)(1+δ)=0，δ 完全退出，所以上端对 δ 不敏感；w=0 时只剩 (1+δ)，δ 只压低下端。这个"单边性"是真结论，它把"δ 不确定"从"整个界不确定"缩小成"只有下端不确定"。但下端那个 −2.39% 是情景值，不是界。

给 δ 设物理域只有三条路：同一流道逐段压降实测、摩擦关联式的有效域、独立阻力标定。Xu 的"实验前用调节阀标定阻力"是一条方法建议，不提供数值范围。

6. Xu §2 是四条判据，不是一条

式判据含义本项目对应
(6)ΠRi = gHβΔT/u2Richardson（浮升/惯性）被设计映射吸收
(7)ΠFr,i = (f l/d + k)R = 1总损失系数（摩擦 + 局阻）就是 KR=1
(8)ΠQs = ql/(C d u ΔT)热源被 QR 映射吸收
(9)Πst = ksl/(C d u ρ ΔT)壁导热原文自己豁免（"not required to strictly consist"）

原文只把 (9) 豁免，(6)(7)(8) 都留着。所以"唯一要求"不成立。准确的说法是：在所声明模型里，Dm 只通过 KR 起作用——因为 (6)(8) 已被设计映射吸收，(9) 与 (7) 是 Xu 也判定只能靠标定处理的项。

而且 Xu 的 (7) 是总损失不是纯摩擦，这正好对上我们的 KR=(1−w)(1+δ)+w(λ/d)f（δ 就是 k 的不相似项）。所以 KR=1 与 ΠFr=1 是同一个条件——这一点可以正面引 Xu，但要说"总损失判据"，不能说"摩擦数"。

顺带一个真验证：把准则指数反推出来

用 c 的解析指数（不用 Xu 表 2 的三位小数）：
  c = 0.5 → d_R = c^0.7 = 0.615572， m_R = c^1.9 = 0.267943
  (λ/d)·f(1) − 1 = −2.220e−16      w=1 的 D = 0
                                    w=0 的 D = 0

把 KR=1 代入通式即得 (λ/d)(r d)n=1 ⇒ r=d(1−n)/nc−1/n，n=1/4 时给 dR=c0.7、mR=c1.9，与 Xu 式(10)(11) 逐位相同。Xu 由 H2TS 得到，本式由集总动量 + 能量得到，出发点不同，这不是恒等式重排。

注意：用 Xu 表 2 印出的三位小数（dR=0.616、mR=0.268）代入，偏差是 −0.0008% 而不是 0。那 8e−6 来自印刷取整，不是模型失真。
