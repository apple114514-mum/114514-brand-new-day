[C] ★ 主结果：D_m 的输入分辨率
==============================================================================
  赵案现值：r_m = 5.819592629, d = 0.5000, Q_R = 5.656854249, H_R = 2.00
            R_id = 5.656854249   D_m = +2.876835284%
  可观测量只有四个，D_m 是它们的显式函数，不需要求根。

  输入             弹性 dD/dln  1 pp 预算所需精度        备注
  --------------------------------------------------------------------------------------
  r_m 流量比       +1.0288      0.97%                    表5 两位有效数字已是 0.05%
  d 长度比         +1.3717      0.73%                    只能由均匀缩放推
  A_R 面积比       +0.6858      1.46%                    净流道，最不确定的一项
  Q_R 功率比       -0.3429      2.92%                    两表口径差 2%，见 [E]
  H_R 高度比       -0.3429      2.92%                    表3 直给 2/1

  「1 pp 预算」= 允许 D_m 有 1 个百分点的不确定度时，该输入需要准到多少。
  这不是误差传播练习，它直接给出实验/设计侧的可交付要求：
    要做 3% 级别的失真判定，净流通面积比必须准到 1.5% 以内。

  反过来说，D_m = 0 的临界值（把单个输入放开、其余不动）：
  输入           现值             使 D_m=0         相对变化
  --------------------------------------------------------------------
  d 长度比       0.500000         0.489476         -2.105%
  A_R 面积比     0.250000         0.239587         -4.165%
  Q_R 功率比     5.656854         6.159249         +8.881%

  => 净流通面积比偏小 4.17%（0.2500 -> 0.2396），+2.88% 的失真就归零。
     物理上这意味着：若台架流道未按几何比例缩（例如堆芯棒径保持原型值），
     名义上的"相似"就不再是真相似，观测到的偏差会全部被输入假设吸收。
     换句话说：该案例声称的失真量级，与它自身输入的不确定度同阶。
     这不是坏消息 —— 它把「测不准」换成了「要测到多准」，是可交付的结论。

[D] kappa = 0.9987384 的身份：它就是 Q_R 的取整比
==============================================================================
  Q_R(表3 印数 10/1.77) / Q_R(脚本声明 4*sqrt2) = 0.9987383915
  记忆里记的 kappa                                    = 0.9987384000
  相对差 = 8.49e-09  （即 7 位有效数字内相同）

  Q_R = 4*sqrt2  <=>  Q_M = 1.767767 MW，表中印作 1.77 MW
  Q_R = 10/1.77  <=>  Q_M = 1.770000 MW
  => 4*sqrt2 是「把 1.7678 圆整成 1.77」的另一种写法，两者都符合原文。

  恒等式闭合检验（T_P = 596.874422 K, T_M = 598.723261 K, w_cal = 0.291472160）:
    c_p,R = 0.999762219476   rho_R = 0.999787322245   G = K_R = 1.088839060800
    kappa          c_p,R*G/rho_R          残差
    1.0000000000   1.088811722111         -6.661e-16
    0.9987384000   1.087438077242         -1.374e-03

  => kappa = 1 时残差 6.7e-16（就是浮点噪声）；kappa = 0.9987 时残差 1.4e-3。
     结论：恒等式的干净形式是 (1+D_m)^3 = c_p,R*K_R/rho_R，没有 kappa。
     旧记录里的 kappa 是为「R_id 用 4*sqrt2、K_R 用 10/1.77」这种混搭打的补丁，
     现在两处统一取同一个 Q_R 即可，kappa 应从论文里删掉。

  连带更正：K_R = 1.1125 与 w = 0.370 都不成立。
    K_R = 1.088839061（由 D_m 反解，delta=0）
    w   = 0.291472160（= (K_R-1)/(f_R-1)，f_R = 1.304794327）
    1.1125 与 0.370 是 kappa 与 eps_Q 同时压进 K_R 的产物，两项都不该进 K_R。

    rho_R = 0.999615157   A_R(核心) = (1.071/2.142)^2 = 0.250000000

[J] delta 的 Re 包络重定级
==============================================================================
  上一轮写的：0 <= delta <= Re_R^(-0.2) - 1，前提 A1、A2。
  重定级：
  前提     内容                           等级         为什么
  --------------------------------------------------------------------------------------
  A1       两侧同湍流、构件类型与数量相同 L4           这是设计意图，三篇原文都没给清单
  A2       K_i(Re) 单调不增、指数 <= 0.2  L2           分离损失比壁面摩擦对 Re 更钝，属关联式性质

  数值（mu_R 计入后）：
  案例                   Re_R         delta 上端     mu 比的口径
  ------------------------------------------------------------------------------
  赵 2020 成对 CFD       0.3450       23.7182%       由模型自身温度场
