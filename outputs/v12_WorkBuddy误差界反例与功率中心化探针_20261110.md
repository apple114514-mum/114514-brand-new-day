# v12：复核 v11 误差界与功率中心化

日期：2026-11-10。冻结的 P/M 回路、十轴盒、3–6 kW 功率窗和 FoM 均未改。本件仅审计 WorkBuddy v11 上传的证明及探索功率方向，不调整物理参数域。

## 1. v11 的主要进展与仍有效的结论

WorkBuddy 把 v10 的三处措辞错误逐条改正，额外找到两个数值抵消核；这些改动有价值。其 10 858 个导数点值全正、16 个子箱的区间导数均跨零，也正确地被标为**搜索/判不定**。它复现了 v10 的三个结果。独立 MPFR 路径此前证明的全窗 `−17.177% ≤ D_j < −0.136%`、连续体温升 `−1.386% ≤ D_T ≤ 22.351%` 不依赖下面的 Decimal 问题，继续有效。

## 2. 新发现：v11 的“四核统一解析误差界”不成立

v11 声称四个 Decimal 核在 `a∈[10⁻⁸,0.1]` 上统一满足 `|相对工作误差| ≤ 288u/a²`，其中 P=32 时 `u=5×10⁻³²`。对它实际使用的

```
h(a) = 1/a² − exp(−a)/(1−exp(−a))²
```

取**声明域内** binary64 输入 `a=0.00010010536854846448`，按 `ivcore.py` 同一个 P=32 Decimal 表达式求值：

| 量 | 值 |
|---|---:|
| Decimal 工作值 | `0.083333333291578813289030` |
| 1024 位 MPFR 参考前 25 位 | `0.0833333332915788132990045…` |
| 实际相对工作误差 | `1.19695×10⁻¹⁹` |
| v11 宣称上界 | `1.43697×10⁻²¹` |
| **实际 / 宣称** | **83.30** |
| 最后转换成 binary64 的误差 | `0.0795 ulp`，仍落在 4 ulp 外扩内 |

完整复算见 `audit_v11_decimal_bound_v12_20261110.py/.log`。因此错的是**所写误差界的阶数和“据此全域证明”的归因**，并没有据此发现修复后输出漏包，也没有推翻独立 MPFR 全窗证书。

为什么多出一阶？把 `e=exp(−a)` 当中间量，则 `h=1/a²−e/(1−e)²` 对 `e` 的导数为

```
∂h/∂e = −(1+e)/(1−e)³  ≈ −2/a³  (a→0⁺).
```

`exp` 的一次绝对舍入约 `u`，会传成 `O(u/a³)` 的绝对误差；`h≈1/12`，相对误差也为 `O(u/a³)`。v11 把“最大中间量 / 结果”直接代入通用公式，没覆盖这个**分母对已舍入 `e` 的敏感性**。

### 对这个核的替代保守界

在 `0<a≤0.1` 且 `u≤5×10⁻³²` 下，令 `s=1−e^(−a)`，有 `a/(1+a)≤s≤a`。按 v11 的单步相对舍入模型，顺着原表达式逐项外扩，可得：

- `exp` 和随后 `1−exp` 的误差：`|ŝ−s|≤2u`；
- 平方后的分母 `q̂`：`q̂≥0.99s²`、`|q̂−s²|≤5su`；
- 分式 `ê/q̂` 的误差：不超过 `6u/s³`；
- `1/a²` 支路及最后相减：分别不超过 `3u/a²`、`2u`。

因此 `|ĥ−h| < 3u/a²+6u/s³+2u <9u/a³`。又因

```
h = 1/a² − 1/[4sinh²(a/2)]
  ≥ 1/[12(1+a²/24)²] > 1/13,
```

所以这个核有保守**相对**界 `|ĥ/h−1| < 117u/a³`；为留余量，可写 **`160u/a³`**。在最不利的精度切换处 `a=10⁻⁴, P=32`，它为 `8×10⁻¹⁸`。四个 binary64 ulp 的相对宽度**至少** `4×2⁻⁵³≈4.44×10⁻¹⁶`，故仅工作误差已有超过 **55 倍**余量；最后一次 Decimal→binary64 转换至多再用去 0.5 ulp。v11 用 `4×2⁻⁵²≈8.88×10⁻¹⁶` 作统一预算，是其**上端**，不能用来证明最小可用余量。`a<10⁻⁴` 时用 P=64，界更小。

这只补了 **`mean_ratio_der`** 这一核。其他三个核应各自按实际表达式传播误差，不能凭那条已被反例推翻的“四核统一公式”直接宣称全域证明。项目级论文的严格数值结论继续引用 MPFR 链。

## 3. “中心化”不能只在结果上改写

WorkBuddy 建议把浮升 `B` 写成 `(Q/m)g`、阻力 `R` 写成 `m²h`，再比较两侧功率弹性。这在**根上**是正确恒等变形：

```
d ln m/d ln Q
 = [1 + ∂ln g/∂ln Q − ∂ln h/∂ln Q]
   /[3 + ∂ln h/∂ln m − ∂ln g/∂ln m].
```

但若先把 `B`、`R` 各算成宽区间，再除以 `Q/m`、`m²`，相同变量的关联已经丢掉，事后重排不能收回。`probe_power_centering_v12_20261110.py` 用 MPFR 在 6 kW 的**第一个共享轴子箱**检验了这一点（只作方法探针）：

| 四共享轴每轴分数 | 直接式 `dln(m_M/m_P)/dQ` | 事后归一式 |
|---:|---:|---:|
| 2 | `[−2.59×10⁻⁵, +7.26×10⁻⁵]` | `[−6.08×10⁻⁵, +1.18×10⁻⁴]` |
| 4 | `[−1.25×10⁻⁵, +2.81×10⁻⁵]` | `[−3.57×10⁻⁵, +5.15×10⁻⁵]` |
| 8 | `[−5.09×10⁻⁶, +1.53×10⁻⁵]` | `[−2.27×10⁻⁵, +3.19×10⁻⁵]` |
| 16 | `[−1.13×10⁻⁶, +9.88×10⁻⁶]` | `[−1.59×10⁻⁵, +2.36×10⁻⁵]` |

这一个子箱内，事后归一**比直接式更宽**；它没有否定解析中心化路线，只说明必须在**温度递推和浮升计算内部**先提出公共 `Q/m`，再做区间求值。点值 10 858 个全正仍是研究方向线索，不是连续域证明。

## 4. 交接文件还有两处应更正

上传的 `00_HANDOFF.md` §2 写“Churchill 无过渡峰”。已有 `mpfr_churchill_peak_v8_20261110.log` 严格给出 `Re=3000` 导数为正、`Re=3300` 导数为负，故**光滑的 Churchill 单式仍有局部峰**；本项目已接受的根区间在峰右侧。这句话应改成“没有人工切换，且所接受根避开局部峰”。

同节“八轴定号角点归约 ⇒ 盒内极值在显式角点”也须标清对象：已证的是**每侧残差**对若干轴的方向；`D_j=m_M/(A_Rm_P)−1` 对共享轴不能由两侧残差同号直接推出角点极值。v8 热损轴的导数变号反例已经说明原因。

## 5. 当前状态和下一步

- **新增已核事实**：v11 的 `288u/a²` 全域统一界有域内反例；该核经逐式传播可改用 `160u/a³`，本例修复输出仍远在 4 ulp 之内。

- **最高价值下一步**：在温度递推内符号化提出共同 `Q/m` 主项，再对余项的两侧差直接做 MPFR 包含。若仍判不定，就保留已有宽严格界及搜索候选，论文中明确限制。不要用“采样全正”或“外推到 −2.97%”替代证明。
