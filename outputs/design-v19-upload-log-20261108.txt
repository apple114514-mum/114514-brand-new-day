B1  subtract the design-point balance. Since the trim pins K_M(m_d)=K_tgt,
    K_M(m) - K_tgt = DP + DH + DV with
      DP = (L/d) [f(Re_m) - f(Re_d)]        pipe, both sides of the trim
      DH = band [h(Re_HS,m) - h(Re_HS,d)]   heating annulus
      DV = K_v,d [z^(-m_v) - 1]             valve
    For every m < m_d: f larger, h larger, z<1 -> all three terms > 0.
    So K_M(m) > K_tgt on the WHOLE declared span, and the sign of D is
    decided by which side of the ratio rises faster:
      D < 0  <=>  K_M rises faster than K_P   (A: 11.8% vs 6.1%)
      D > 0  <=>  K_P rises faster than K_M   (B: 6.1% vs 1.3%)
    First order, D = [ln K_P - ln K_M]/3: distortion is not 'the model is
    off', it is 'the two sides grow at different rates'. The valve is a
    constant, so it can move the level but never the growth rate.

B2  which coordinate is worst? differentiate K_M - K_tgt:
      d/dL      = [f(Re_m)-f(Re_d)]/d            > 0 for m<m_d
      d/dd      = (n_p-1)(L/d^2)[f_m-f_d] scaled  < 0 for m<m_d
      d/dband   = [h_m-h_d]                       > 0
      d/dK_EV   = 1 - z^(-m_v)                    < 0 for m<m_d
      d/dm_v    = -K_v,d z^(-m_v) ln z            > 0

  I EXPECTED mu to cancel and it does not - the exact reason is worth
  one sentence in the paper. With f = C Re^(-n),
      f(Re_m)/f(Re_d) = z^(-n),   z = m/m_d,   which is mu-free.
  If the whole K_M scaled with f, a uniform viscosity shift would
  vanish. But the trim PINS K_M(m_d)=22.8, so what enters D is the
  INCREMENT, not the ratio:
      DP = (L/d)[f_m - f_d] = (L/d) f_d (z^(-n) - 1)  ~  f_d  ~  mu^n
  A 100 K colder model has mu 1.3208x, hence f_d 1.0720x, hence DP 1.0720x.
  So the viscosity channel is about a quarter of the heat channel, not
  zero: v18's sentence needs the mu term added, and the review's
  objection stands. What is true is narrower: mu shifts the operating
  POINT (the Re at which you run), not the similarity argument, so it
  must be declared with the temperature, not with the fluid.
