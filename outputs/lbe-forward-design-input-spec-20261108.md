# LBE 自然循环先验研究：一版完整的独立设计输入

**用途与边界。** 这是一台**拟建模型回路**的方案级输入，不是 KYLIN-II 已建装置的图纸，也不是整回路失真上界。先选几何、构件与控制边界，再正向计算；主线不使用 `K_M/K_P=1`、`K_target=22.8` 或设计点 `D_m=0` 来反解孔板或阀门。下表的「拟定验收条件」必须在图纸、采购或运行方案中落实，不能改称文献实测值。本文暂只针对**循环流量 FoM**；改成圆管加热后，原型环隙的壁温/Nu FoM 不能沿用。

## 1. 先固定可计算的拓扑

采用内径 **16.00 mm 的单通道闭合矩形回路**：两竖段各 3.00 m，两横段各 5.00 m，四处为 **90° 锐角斜接圆管弯头**，总直管中心线长度名义 16.00 m。孔板位于下横段中点，距两端弯头各 2.50 m；每段长度图纸验收为名义值 ±0.01 m。热段是在上升竖管底部 **1.00±0.01 m 外加热圆管**；冷段是在下降竖管顶部 **1.00±0.01 m 外冷却圆管**。不用模型侧环隙。加热段和冷却段保持同一内径，无插入式棒束或突然面积变化。源与汇中心标高名义相差 2.00 m；浮升项实际按沿程密度积分计算，不把 2.00 m 强制当常数有效高度。

从每个弯头到孔板至少有 `2.49/0.01605=155D` 的直管；竖段间距至少约 `186D`。这超过 Al‑Tameemi–Ricco 锐角斜接弯头实验段所用的上游 `100D`、下游 `140D`。**距离是减少构件相互干扰的设计条件，不等于证明四个弯头的损失可以无误差相加。** 弯头须按该论文的锐角斜接几何制作；换成长半径弯头须换关联式。

主流路**不装连续调节阀，也不装全开 Y 型截止阀**。灌注、排气、排放和检修阀放在运行时关闭的支路或可拆短节上。直通式、同内径的测量段不引入新的节流几何。主管上的支路口、焊接错边和测量接口合计记作 `K_aux`，设置 **`0≤K_aux≤0.5` 的设计验收要求**，并在图纸上采用齐平口、避免伸入流道。`0.5` 不是 NEA 或阀门论文的已核物理上限；若不能由详细图纸、厂家资料或后续检查证明，就保留 `K_aux` 为自由情景参数，不发表实物保证。运行时如必须有**内联隔离阀**，本方案失效，需另给该阀同开度 `K(Re)` 与参考截面。

## 2. 输入台账：来源、值、约束身份

| 输入 | 本版取法 | 身份与后续验收 |
|---|---|---|
| 主管内径 / 外径 | `D_i=16.00±0.05 mm`；`D_o=20.00±0.10 mm` | **独立拟定图纸尺寸**；须核实际净流通内径。外径用于保温计算，不能替代内径 |
| 四段直管 | 竖向 `3.00±0.01 m`×2、横向 `5.00±0.01 m`×2 | **独立拟定布置**；总长 `15.96–16.04 m`；不按缩放指数反求 |
| 固定有限厚度孔板 | 孔径 `10.00±0.02 mm`，厚度 `2.00±0.05 mm`，位于下横段中部 | **独立拟定加工验收**；孔板整体损失使用 NEA 15.3.3 第 3 式，不另加突缩/突扩 |
| 四个弯头 | 90° 锐角斜接圆管，各一件 | 几何**设计选择**；`K_i(Re)` 用 Al‑Tameemi–Ricco 式(4)，其水/空气实验迁移到 LBE 属**模型条件** |
| 壁面 | 等效砂粒粗糙度 `0–10 μm` | **拟定采购与服役验收**；不能把 `Ra` 直接等同等效砂粒粗糙度；氧化/腐蚀后须重核 |
| 辅助口总损失 | `0≤K_aux≤0.5`，以主管动压定义 | **未获来源的设计验收阈值**；它是剩余阻力闭合的显式关口 |
| 模型热源 | 外加热竖直圆管 1 m；电输入 `Q_e=3–6 kW` | **拟定运行与设备能力**；计量准确度目标 ±0.5% 仅为采购要求，不是已有仪表报告 |
| 加热入口温度 | 控制 `T_H,in=473.15–483.15 K` | **拟定可控边界**；控制点在加热段入口，不用冷热腿温差替代加热段进出口温差 |
| 冷源 | 外冷却竖直圆管 1 m；冷却侧流体沿程不高于 `433.15 K`；有效 `UA_c≥150 W/K`；热移除能力 `≥6 kW` | **拟定换热器验收**；`UA` 必须在相应 LBE 流量和油侧工况下成立，当前文献未证明这台新换热器已达到 |
| 环境 / 保温 | `T_a=293.15–313.15 K`；除冷段外至少 50 mm 保温；全温域 `k_ins≤0.05 W/(m·K)` | **拟定建筑与材料验收**；外表散热按保温导热上限处理 |
| 热桥 | 加热器接线、支架、仪表口等合计 `UA_bridge≤0.5 W/K` | **拟定总预算**；各热桥份额之和受约束，不是各项独立都取 0.5 |
| LBE 物性 | NEA 2015 表 2.19.3 的 `ρ(T), c_p(T), μ(T)`，两回路同版本 | **文献推荐式**；ρ 400–1300 K、`c_p` 400–1100 K、μ 400–1200 K |
| 计算轨迹核域 | `0.10≤ṁ≤0.40 kg/s`、`473.15≤T(s)≤773.15 K` | **求解后验收门槛**，不是给 GSA 独立抽样的流量/温度输入；越界需重设方案或关联式 |

压力损失系数均以当地 **16 mm 类主管平均速度动压** `ρu²/2` 定义。主管若有实际变径、过滤器、内插仪表或未列构件，必须单列，其损失不可混入 `K_aux≤0.5` 而不审核。

## 3. 从几何和物性正向算阻力

在各段当地温度计算 `Re=4ṁ/(πD_i μ(T))`，`μ(T)=4.94×10⁻⁴ exp(754.1/T)` Pa·s。该候选几何的阻力构成是

```text
K_pipe(s) = f_Churchill(Re(s), ε/D_i) · ds/D_i
K_bend,i = 427.5 Re_i^(−0.77) + 0.9           （四个指定锐角斜接弯头）
K_orifice = [0.5(1−β)+(1−β)²+τ(1−β)^(3/2)]/β²
β=(d_h/D_i)², ℓ=t/D_i, φ=.25+.535ℓ^(−8)/(.05+ℓ^(−8)), τ=(2.4−ℓ)10^(−φ)
K_total = ∫ f_Churchill(Re(s),ε/D_i) ds/D_i + ΣK_bend,i + K_orifice + K_aux
```

Churchill 为 NEA 表 15.3.2 第 6 式（**all ranges**）；孔板为表 15.3.3 第 3 式（`Re_D>1000`）；弯头为 Al‑Tameemi–Ricco 式(4)（`500≤Re≤60000`）。**本式的“总”只包括已列构件和 `K_aux`，不是对原型 KYLIN-II 实物总阻力的辨识。** 温度不均匀时应逐段用 `ρ_i` 和参考面积计算压降，不能先把不同密度的 `K_i` 无条件求和再乘单一动压。

为检查数量级，[复算脚本](lbe-forward-design-input-audit-20261108.py)在**等温 `573.15 K,ṁ=0.20 kg/s`**、名义光滑管和 `K_aux=0` 下给 `Re=8643`、`K_pipe=32.285`、四弯头 `5.191`、孔板 `5.594`、总 `43.070`。这不是按 `22.8` 配出的值；亦不意味着整个运行域都等温。对 `ṁ=0.10/0.20/0.40`、`T=473.15/573.15/773.15 K` 与六项尺寸/阻力端点形成的 **576 行离散诊断网格**，`Re≈3262–24372`、`K_total≈34.35–56.80`。后一个区间**不是连续参数域的认证极值，也未计关联式模型误差**；原始行见 [CSV](lbe-forward-design-input-grid-20261108.csv)。若把 NEA 黏度推荐式的 ±8% 当情景，最低 Re 仍约 `3262/1.08≈3021`，高于孔板及弯头门槛。

此处孔板的 `K≈5.594` 与先前「按 `22.8` 配平需 `6.475`」接近只是数值巧合。不得据此改写为“孔板自动满足缩放准则”。

## 4. 热边界要给出沿程分布，不只给一个 Φ

在 16 m 回路中，冷却段名义 1 m；其余 15 m 外侧保温。保温外表面换热阻为正，因此把外表面温度直接取环境温度可给径向稳态导热的**条件上限**（另外计热桥）：

```text
U′_ins ≤ 2π k_ins / ln[(r_o+t_ins)/r_o]
q′_loss(s) ≤ U′_ins [T(s)−T_a]
Q_loss ≤ U′_ins L_ins (T_max−T_a,min) + UA_bridge (T_max−T_a,min)
```

用外半径最大 `10.05 mm`、保温最薄 `50 mm`、导热率上限 `0.05`、保温长度上限 `16.04−0.99=15.05 m`，得到 `U′_ins≤0.17574 W/(m·K)`、`Q_loss≤1.510 kW`（包含热桥预算）。这个上限很宽，**不能写作预计热损 0.1–0.2 kW**；在电输入下界 3 kW 时，仅能据该保守热账推出**留给冷却段的稳态热负荷**不低于约 **1.49 kW**。加热段实际传给流体的热量需单独扣加热段外漏，不能把整回路散热一次性从加热段入口扣除。若供货保温导热率或热桥验收不到上述规格，必须重新计算。

前向方程以 `h(T)=∫c_p(T)dT` 写为 `ṁ dh/ds=q′_e(s)−q′_c(s)−q′_loss(s)`。热源沿指定 1 m 分布；冷源在指定 1 m 作**均匀抽热的受控边界**，其总量 `Q_c` 由周期能量闭合和 `T_H,in` 控制条件共同确定，并检查 `0≤Q_c≤6 kW`、换热端差及所需 `UA_c`。用 `−∮ρ(T(s))g dz` 计算浮升压头，与按当地 `T(s),ṁ` 得到的各段损失联立求稳态根。这样 `ṁ`、温度场、冷却负荷是**输出**，不作为四个互不相关的随机输入。

`UA_c≥150 W/K` 是在 LBE 最低 473.15 K、冷源最高 433.15 K 时，为 `6 kW/40 K` 设置的**设备能力验收目标**；若油侧升温或实际传热面积导致最小端差不足 40 K，此规格不足，须改换热器设计。该热边界是**条件工程方案**，并未由现有论文验证。即使它成立，也不推出原型 KYLIN-II 的热路与该新圆管相同。

## 5. 对 DeepSeek 建议的取舍，以及还差什么

| 建议 | 本版处理 | 原因 |
|---|---|---|
| 孔板作主节流件 | **采用**，孔径/厚度/公差和 NEA 式同时给出 | 整体孔板式覆盖本版 Re；不需要借突缩+突扩拼阻力 |
| 直管替代孔板 | 保留为其他候选，不与孔板同装 | 直管过渡区 Churchill 曲线可能有内部极值；不妨碍数值求界，但此版先固定一种方案 |
| 全开 Y 型阀取 `K=0.1–0.5` | **不采纳**；正常循环路径不设此阀 | 未核该阀在本几何、开度和 Re 下的系数；“全开”不等于近零阻力 |
| 环隙层/湍流极值作上下界 | **不采纳**；模型改为外加热圆管 | 两端公式不自动包住转捩流；原型 KYLIN 的环隙仍需按原型独立处理 |
| 热损取 `0.1–0.2 kW` | **不采纳**；以保温/热桥规格给出 1.510 kW 的条件上限 | 单一猜测热损无法定义沿程浮升温度场 |
| `D=(K_M/K_P)^(−1/3)−1` 直接算最终 FoM | **不采纳为一般式** | 该式还需热量、面积、高度、物性与参考目标满足特定同口径条件；本版先求两侧物理流量，再按预声明 FoM 定义比较 |
| 2024–2026 阀门/迷宫新论文 | 作为**待核线索** | 当前未收到这些原文及可定位 `K(Re)` 的表/式，不能用摘要推定 `m_v≤0.05` |

**已解决的设计输入问题：**拟建模型的主流路拓扑、孔板/圆管/弯头的几何与前向公式、流量及温度关联式核域、保温热损的控制体和正向上限均已有一版**可审查的明确方案**，且不使用缩放法配平。**尚未闭合为实物保证：**`K_aux≤0.5`、等效粗糙度上限、保温/热桥规格和冷却器 `UA` 是提出的验收条件；LBE 中弯头式的模型误差没有严格上界；原型 KYLIN-II 的阀位、热路和逐构件阻力未由这些新设计值替代。用户若接受本拓扑，下一步应审查图纸/采购是否能承诺这几项规格；**在此之前不报整回路最大失真或 GSA 排序**。
