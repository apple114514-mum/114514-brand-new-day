# KYLIN-II 缩比初设 v17 独立复核与下一步

**结论先行。** v17 完成了一个实质推进：给定原型理论阻力表、缩比映射和两种管段闭合后，可以反解节流件并把单点配平延伸到多工况比较。设计点所需参考阻力 `K_valve=6.342/2.241` 和环隙 `Re≈9511` 均复算通过。但报告中“前向预测”“曲线最大失真”“5.70% 角点上界”“−1/3 精确导数”需要更正；目前可称**五个理论工况上的条件设计演示**，尚不能称整条曲线或实物的认证界。

本复核使用 [独立脚本](design-v17-independent-audit-20261108.py) 和 [逐点结果](design-v17-independent-audit-20261108.csv)。来源坐标：Yue 等 2017 PDF 第 2 页 Table 1、第 3 页式 (3)、第 4 页 Table 2；Xu FR26-170 PDF 第 4 页 Table 2；OECD/NEA 2015 手册印刷页 935 的 Tables 15.3.5–15.3.6。Yue Table 2 是**理论阻力矩阵**，不是各阀位的实测阻力；原文和上轮核读见 [v16 报告](component-resistance-design-v16-20261108.md)。

## 设计点：成立的部分与前提

环隙必须用湿周：`Re_HS=4ṁ/[π(d_o+d_i)μ]`。以 54/22 mm、1.25 kg/s 和 `μ=2.2019×10⁻³ Pa·s` 计算得到 **9510.62**，与 Yue Table 2 的 9520 相差约 0.1%。旧的 `4ṁ/(πD_hμ)` 套到了非圆截面，确实错了。

按 v17 **全部声明**保留 `K_HS=2.6`、`K_EV=2.5`，模型主管 16.016 mm、5.5 m、设计流量 `0.2683×1.25 kg/s`，反解得到：

| 管段闭合 | 模型管 `K_pipe` | 所需节流参考 `K` |
|---|---:|---:|
| A：光滑 Blasius | 约 11.358 | **6.3421** |
| B：Yue 理论表反算 `f` | 约 15.459 | **2.2405** |

`K_R=1` **在指定的理想缩比律下**是设计条件：`H_R=L_R=0.5`，`u_R≈√L_R`，两侧 `ΔT_R=1`，同口径净功率与物性比保持声明值时，动量、能量式合并可得设计点 `K_M/K_P≈1`。换理想比、热量口径或物性条件时需重新推导，不宜写成任何自然循环缩比都只能有这一个 `K_R`。

四种突缩式在 A 闭合下使窄段内径相差约 **0.18 mm**，在 B 闭合下相差约 **0.30 mm**；报告中“只差 0.18 mm”只描述 A。两支管段闭合的差异仍明显更大，但 B 的来源是 Yue **理论** `K_pipe` 和假定长度，不是已测管壁粗糙度；不能把尺寸差独立归因于表面状态。

## 离开设计点：必须把 Re 随未知流量联立

v17 先令台架流量等于理想值 `ṁ_M=sṁ_P`，在该处计算 `K_M`，再代入 `D=(K_M/K_P)^(-1/3)−1`。这给的是**冻结在理想流量的代入估计**。同一声明模型的前向解应令 `x=ṁ_M/(sṁ_P)`，求

```text
x³ K_M(x s ṁ_P) / K_P(ṁ_P) = 1,       D = x − 1 .
```

此式也以两侧净热比、物性比、有效浮升高度比、面积比恰按所选理想映射保持为前提。若这些因子不相似，右端要保留相应比值，不能仍设为 1。代回实际根后，幂关系可作为**等式重排**，但其中 `K_M` 必须在实际流量评价。

| 原型流量 kg/s | 模型主管理想 Re | A：v17 代入 | A：联立前向 | B：v17 代入 | B：联立前向 |
|---:|---:|---:|---:|---:|---:|
| 1.25 | 12108 | 0 | 0 | 0 | 0 |
| 1.00 | 9687 | −0.276% | **−0.288%** | +0.431% | **+0.432%** |
| 0.75 | 7265 | −0.841% | **−0.876%** | +0.900% | **+0.903%** |
| 0.50 | 4843 | −1.942% | **−2.027%** | +1.323% | **+1.327%** |
| 0.25 | 2422 | −4.615% | **−4.831%** | +1.356% | **+1.361%** |

设计点仍为零，符号趋势仍相反；但“运行态最大 1.94%/1.32%”应暂改为**五行表中 0.50–1.25 kg/s 四行的 2.03%/1.33%，且仅在原型表及模型闭合声明下**。没有行间 `K_P`、`K_HS` 与 `K_v` 的函数及其适用域，就不能声称连续区间的最大值已被证明。

这两个符号是**整套假设下总阻力曲线斜率的结果**。v17 在每行同时改变原型 `K_P`、所沿用的加热段 `K_HS`，又把阀门参考 `K` 固定为常数；真实阀门的 `K_v(Re,开度)` 尚未给出。单凭这五行不能断言“只有摩擦指数决定符号”。

## 流态门槛：主管可算，不等于全回路可算

v17 的 0.25 kg/s 行，模型主管 `Re≈2422`。它处于通常称为过渡的范围，不能直接判作**层流**；可以确定的是，它不在 v17 采用的光滑湍流 Blasius 声明域内。更关键的是同样缩放加热段 54/22 mm 时，模型加热段环隙的理想 Re 为：

| 原型流量 kg/s | 0.25 | 0.50 | 0.75 | 1.00 | 1.25 |
|---|---:|---:|---:|---:|---:|
| 模型加热段 Re | 828 | **1657** | 2485 | 3314 | 4142 |

因此即使把主管端点截在 `Re>4000`，0.50 kg/s 时加热段仍在低 Re 区，却沿用原型 `K_HS=2.8`。上一轮已核的环隙实验式只覆盖另一径比 `d_o/d_i≈1.30` 和 `Re>5000`，不能补到本装置径比约 2.45。v17 所谓“0.50–1.25 全回路可用域”尚未建立。Yue Table 2 本身也只覆盖**流量 0.25–1.25 kg/s**；0.50–1.25 是 **2.5:1 流量比**，不能叫“4:1 功率范围”。

## 摄动和 3% 判据：公式改成可用的版本

若把总 `K_M` 当成外生常数，`D=R_K^(-1/3)-1` 的**函数式**是精确的；但其导数是 `dD/d ln R_K=−(1+D)/3`，只在 `D=0` 处等于 `−1/3`。若整体乘性地改变一个随流量变化的 `K_M(ṁ)` 并重新求根，则在设计点

```text
d ln x / d ln a = −1 / [3 + d ln K_M / d ln ṁ_M],
K_M -> a K_M .
```

两种闭合在设计点分别得到 **−0.34645** 与 **−0.33728**，故“`−1/3` 精确且不是线性化”是对函数值与局部导数的混用。对主管 `f∝Re^(−n)`，固定模型流量时 `K_f∝L·d^(n−1)`；因此 `∂K_f/∂ln L=K_f`，`∂K_f/∂ln d=(n−1)K_f`，两者也**不具有相同灵敏度**。直径还通过面积和理想比影响整体结果，不可由这条局部式宣称与长度秩亏。

仅对上述纯损失比模型，精确的 3% 条件是

```text
|D| ≤ 0.03  ⇔  1.03^(−3) ≤ K_M/K_P ≤ 0.97^(−3)
            ⇔  0.915141659 ≤ K_M/K_P ≤ 1.095682682 .
```

即参考 `K` 向下允许约 **8.49%**，向上约 **9.57%**；这是一条**条件化、非对称的总阻力分配指标**，不是不看热路、物性及阀门 Re 效应就可直接下发的采购总规格。v17 脚本打印端点时把上下界顺序写反，报告文字则写对了。

## 三阶段盒：做法有价值，数字还不是界

按设计、调试、固定阀位运行分开输入域是正确的研究组织方式。v17 的阶段Ⅰ把若干假设幅度线性加成 `ΔK=3.899`，再用局部摄动给 **5.70%**；即使接受这同一个集总 `ΔK`、保持其他因子固定，精确幂映射两端也为 **−5.13% / +6.45%**。所以 5.70% 既不是所写盒的精确角点，也不是证明过的最坏上界。

此外，阶段Ⅰ计算用 `K_HS±20%`，其输入表却列 `2.48–2.72`（约 ±4.6%）；`L±20%` 对应的长度也未与 `L_P=10–12 m` 对齐。`K_EV±50%`、阀门 `±0.2 K`、管径 `±0.5%` 是**研究者声明的情景/待指定采购能力**，Yue 原表只给名义值。阶段Ⅱ的 0.29% 也不能称“仪表能力”，因为并无阀位重复性样本或仪表规格。阶段Ⅲ还须把仍在运行的 `K_v(Re)`、加热段 `K_HS(Re)` 和功率/热损状态计入。

## 加热段阻力的 4.5% 差额尚未定位

按 v17 所设 `T 形入口 1.29 + 面积项 0.64 + 环隙摩擦 0.190685 + 出口突缩 0.361020 = 2.481705`，与表值 2.6 差 **0.118295**。这是一个有用的误差核对，但不足以证明四个构件正是作者 Table 2 的分解。报告认为面积项 `0.64` 与 Borda–Carnot 的 `0.521341` 相差约 0.119，恰好解释残差；**符号相反**：若以 Borda–Carnot 代换，合计降为 **2.363046**，残差反而升至 **0.236954**。出口突缩 `0.361` 也是关联式计算值，并非 Yue 逐构件实测 `K_out`；还需核该式的参考面积和 Re 有效域。不能把残差归因为“作者优化了这一项”。

## 对论文的具体推进

建议保留题目中的**设计阶段条件界**，并把下一轮对象锁定为“**固定阀位后的流量曲线失真**”。这已能在没有新实验的情况下完成，但先须给出一份**新台架设计规格**：每段净面积/水力直径/长度、管壁粗糙度范围、加热段在层流与过渡区的阻力闭合、节流件 `K_v(开度,Re)` 曲线、热量口径与运行温度范围。每项标文献验证域或“自选设计域”。随后：

1. 在设计点按所选理想比配平，明确 valve `K` 是参考动压下的值。
2. 对每个功率/原型流量联立解两侧 FoM，给出摄动导数与模型内含义。
3. 对**声明的**设计规格盒做 GSA 排序；分类闭合 A/B 分层比较，不赋予虚构概率。
4. 对最重要的输入用区间求根/分支定界计算 `sup |D(q,p)|`，并单列关联式适用域。这样得到的是论文所需的先验**条件**界；实物测量可作为后续检验，不是此项方法的前提。

目前最小且不自欺的正文句子：**“在 Yue 理论阻力表与所声明的模型管段闭合下，节流设计可使 1.25 kg/s 设计点的总阻力比为 1；固定该节流值并联立流量后，所列 0.50–1.25 kg/s 四个理论点的纯损失项偏差为 A：0 至 −2.03%、B：0 至 +1.33%。这不是连续流量域的认证最大值，且加热段低 Re 阻力和热边界仍待纳入。”**
