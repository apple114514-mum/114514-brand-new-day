二、v6 错在哪：两处缺陷的精确定位

v6 的原式是 min{0, A^(1/3)−1} ≤ D_m ≤ max{A^(1/3), q}−1，A=1+δ、q=(cB)^(1/(3−n))。两个缺陷互不相同，必须分开修。

缺陷 1（下界）：它偷偷假设了 K_R ≥ A

δ≥0 时 min{0, A^(1/3)−1}=0，等价于断言 D≥0，即 K_R ≥ A。而 K_R=(1−w)A + w·c·f，w=1 时只剩 c·f。只要 c·f < A，根就落到 x<1，D<0。Zhao 的 c=1 时 f(1)=B=1.2968>1，这条恰好成立——这是 c=1 的巧合，不是通式。

c=0.5, δ=0, w=1 的根：
  x    = 0.855835044351        (< 1)
  K_R  = c·f = 0.626777676750  (< A = 1)
  D    = −14.416496%           而 v6 下界给 0%

缺陷 2（上界）：f ≤ B·x^n 那一步要求 x ≥ 1

推导用了 f(x) ≤ B x^n，等价于 μ_R ≤ 1，等价于 T_M ≥ T_P，也就是 x ≥ 1。当 c<1（或 δ<0）把根推到 x<1 时，μ_R>1，这一步反向。v6 当时补了一句"x<1 时 D<0 ≤ max−1"，但 max{A^(1/3),q}−1 在 c<1 且 δ<0 时是负数，这句话不成立。

三、新结果 1：v6 下界的失效边界是一个精确等式

δ=0 时，v6 下界 D ≥ 0 成立 当且仅当 w=1 端的根 x ≥ 1，即 c·f(1) ≥ 1。而 x=1 处 T=T_P、μ_R=1，故 f(1)=B，条件化成

c ≥ 1/B = 0.771105412704

数值交叉验证：直接解 D(w=1)=0 得临界 c₀ = 0.771105412704，与 1/B 差 −3.331e−16。这不是拟合，是恒等。

物理含义。c = λ/d = (L_M/L_P)/(D_M/D_P)：c=1 是长度与直径同比例缩（几何相似缩比），c<1 是长度方向比直径方向缩得更多，也就是降高度这一类缩比。所以 v6 下界的失效区恰好是降高度区。

这不是无害的边角。论文里唯一的"降高度"案例 KYLIN-II 恰好是 c = 0.5 < 0.7711，正落在失效区内。也就是说 v6 的通式在本项目自己最关心的那个缩比类型上就是错的，只是 Zhao 的 c=1 把问题遮住了。

四、对称条件界：命题与证明

复核给出的修正式我复算确认成立，并把它的证明结构写清楚：

记 A = 1+δ、q = (cB)^(1/(3−n))，则

min{1, A^(1/3), q} − 1 ≤ D_m ≤ max{1, A^(1/3), q} − 1

支一  x ≥ 1。若根处 M ≤ 1、μ_R ≤ 1，则 f ≤ B·x^n，故
        x³ ≤ (1−w)A + w·c·B·x^n
      反设 x > max{1, A^(1/3), q}，则 A < x³ 且 cB·x^n < x³，
      凸组合 (1−w)A + w·cB·x^n < x³，与上式矛盾。
      故 x ≤ max{1, A^(1/3), q}。

支二  0 < x < 1。若根处 M ≥ 1、μ_R ≥ 1，则 f ≥ B·x^n，故
        x³ ≥ (1−w)A + w·c·B·x^n
      反设 x < min{1, A^(1/3), q}，则 A > x³ 且 cB·x^n > x³，
      该式 > x³，与上式矛盾。
      故 x ≥ min{1, A^(1/3), q}。

两支穷尽 ⇒ 命题成立。

为什么这不是循环论证。它是对"根"的条件命题：不预设根落在哪一支、也不预设 x 的上界，只要求根所在那一支的 M、μ_R 方向成立。这一点必须在正文里写清楚，否则会被读成"用结论证结论"。

v4/v5/v6 都写过：dlnM/dT 的上确界是 −1.242e−5 < 0，所以 M 随 T 单调递减，于是 M(x) ≤ M(1) = 1。本轮逐点算 dlnM/dT = c_p′/c_p − ρ′/ρ（赵表 4 物性）：

dlnM/dT 在 T* = 737.4784 K（对应 x* = 3.151520）变号，上确界是正的（约 +1.98e−5），不是负的。所以"M 随 T 单调递减"这句话本身是错的。

但结论没垮：M(x) 先降后升，在 x* 处取到极小 0.999031265，再回到 1（x₁=5.204652）之后才超过 1。所以正确表述是：「M(x) ≤ 1 在 [1, x₁] 上成立」是层二的数值事实，不是由单调性推出来的。

v4/v5/v6 的这句理由全部作废，结论保留。这正是前面几轮反复出现的同一种错误模式：结论对、理由编得太顺。三个版本号连着抄了一遍，谁都没去算 dlnM/dT 的符号。

这条界松不松：按四区统计，不预设原因

松弛的来源不是 δ 的符号，而是 A^(1/3) 与 q 是否落在 1 的同一侧：

  • 两者都 > 1：min 里 1 胜出，下界被钉在 0，而真实最小值是 min{A^(1/3),q}−1 > 0 ⇒ 下侧松。
  • 两者都 < 1：max 里 1 胜出，上界被钉在 0，而真实最大值是 max{A^(1/3),q}−1 < 0 ⇒ 上侧松。
  • 一上一下：1 被夹在中间，界紧，平均松弛 0.15–0.34 pp。

同一侧时松弛 12–16 pp，不同侧时不到 0.4 pp，差两个量级。所以这条界的用法必须说清楚：先看 c 与 1/B、δ 与 0 的相对位置，再决定要不要另证单调性改用端点反解。不要一句"保守界"就交差。

九、可宣称 / 不可宣称

可宣称（模型内条件结果）

  • 对任意 c>0，在根处 (M, μ_R) 方向成立的条件下，|D_m| 被 min/max{1, A^(1/3), q} 包住；c=1 时退化为 Zhao 特例界 [0, +9.913122%]。
  • v6 下界 D≥0 的精确适用边界 c ≥ 1/B = 0.771105412704，数值临界点与解析式重合到 3e−16。
  • Zhao c=1 的 3% 双侧可行带是精确反解，保留；δ_crit=9.2755604% 等号可行。
  • 摄动导数闭式与有限差分一致到 1e−10。

不可宣称

  • 不得说对称界"紧"。它把 1 纳入 min/max 以保证两支穷尽；同侧时松弛可达 12–16 pp。
  • 不得说"对所有 δ>−1、所有 c"。仍受层二（x≤5.204652）与层三（物性域）限制。
  • 不得把任何一条界说成台架保证。δ、净流道、逐段阻力仍无来源。
  • 不得再说 M 随 T 单调递减。这句话在三个版本里出现过，符号算错了。
