可辨识性与参数域：δ 到底能不能「确认」

2026-11-03 · 第十轮 · 10 节 8 表 · 脚本 identifiability_v10.py（248 行日志）· 技能包 lit-mirror_skillpack_2026-11-03.zip

一句话结论。前九轮一直在给 δ 找范围——Re 包络、逐构件 Ki(Re)、参数溯源。 本轮换了个更靠前的问题：δ 在这个模型里有没有观测足迹。答案是没有，而且这不是数据不足。

把 c = λ/d 从 0.6 扫到 1.5，δ 从 −12.06% 走到 +37.79%（跨 49.8 pp）， 而自洽解 x 每一位数字都不变（差异 0.00e+00）。50 pp 的 δ 差别不产生任何可观测量差别。

所以「一直确认不了」不是做得不够，是在给一个不可观测的坐标找范围。 但这不坏——方程里真正出现的只有两个量 A、B，它们是可辨识的， 而且 3% 判据只依赖它们。转过身来做可辨识量，这条路当天就通了。

一、结构事实：方程里只有两个数

模型方程（source_free_bound_v5.py 的 F_s）是

x³ · ρT/ρTP = G(x,w) · cp,T/cp,TP
G(x,w) = (1−w)(1+δ) + w·(λ/d)·f(x)
f(x)   = (Rid · x · d · μR(T))n

记

A = (1−w)(1+δ)      ← 与 Re 无关的那一块（形阻 + 几何）
B = w·(λ/d)          ← 随 Re 软化那一块的幅度（摩擦）

则 G = A + B·f(x)，而 f 只依赖 (x; d, Rid, μR, n)。于是

F = 0  ⟺  x³·ρ/cp = A + B·f(x)

A、B 之外的参数一个都不出现。这不是近似，是方程的形式。 反解也直接：w = B/c、δ = A/(1−w) − 1。所以 (w, δ) 是 (A, B, c) 的坐标变换，不是三个独立物理量。

一个坐标变换的结果能不能「从文献确认」，取决于被变换的量是否可观测。 δ 恰恰不可观测——下面三节就是证明，一层比一层狠。

四、两点才可辨识：B 来自 KR(x) 的斜率

两个工况给两个方程，A、B 就能分开：

A + B·f(x₁) = K₁
A + B·f(x₂) = K₂
⇒  B = (K₁−K₂)/(f₁−f₂),   A = K₁ − B·f₁
⇒  |dB| ≈ √2·σK/|f₁−f₂|,   σK ≈ 3σD

自然循环下 ṁ ∝ Q1/3（第八轮弹性锚），故 Re 比 = (Q比)1/3， f 比 = (Q比)−1/12。功率跨度越大，f₁−f₂ 越大：

这正是 Carnevali 2025 说的「判据要给出对 FoM 本身的影响」——报告 FoM 的区间，而不是报告「通过/不通过」。 量级（≈3%）是站得住的，判决（≤3%）站不住。这个区分本身就是方法学贡献。

七、直接回答「一直确认不了吗」：三种人三种答案

角色能不能确认 δ先决条件
有图纸 + 有功率扫描能先定 c，再由 A、B 反算 δ
只有论文（含我们）不能，且是结构性不能c 与 B 都拿不到，δ 无足迹
论文作者不该报 δ报 (A,B) 与 D 的区间

三样东西各缺一路，而且没有一样是文献检索能补的：

量是什么从哪里来文献能给吗
Bw·(λ/d)，摩擦块幅度功率扫描（实验）不能
cλ/d，段长/管径比两台装置图纸不能（原文不给分配）
δA/(1−B/c) − 1，是导出的由 A、B、c 算出不能，它不是观测量

前九轮把 δ 当成第三样独立信息去找——它其实是前两样的函数。 这就是为什么包络、逐构件 Ki(Re)、参数溯源三条路都走不到底： 它们都在给一个没有观测足迹的坐标找范围。

八、关于「Codex 看不到文献」这件事

技能装不出网络。技能是文本加脚本，不能让一个不能联网的链路看到网页。 所以「Codex 视角受限」靠装技能解决不了，得换角色：联网侧只负责取件、抽文本、定级； 推理侧只读工作区里的 .txt，按页码引。把「检索者」改成「读者」，局限就消失了。

这就是随这份报告一起交付的 lit-mirror 技能在做的事：

  1. 取件单——给联网侧的具体要求（要哪张表、哪个式子、哪页），不是「帮我找一下 XX 文献」。 判断值不值得付一次全文费的三条：逐段/逐构件数据、多功率点、测量方法与不确定度。三条都没有，付费也白花。
  2. pdf2txt.py——PDF 抽成带 [[pN]] 页码锚的纯文本，离线、只依赖 pypdf。 扫描件会报 EMPTY_PAGE，不许凭印象补。
  3. 证据卡 + claims.csv——每条数字后面必须跟 [[pN]] 表M；定级只用 L1/L2/L3/L4，L3 不得当 L1 用。
  4. mirror_check.py——审计缺件，退出码 0 才算过。缺件清单就是下一张取件单，这是这个技能真正的输出。

交给推理侧只需要一句：「你只能引用 claims.csv 里 grade ≥ L2 的条目，每条要给 [[pN]] 表M；其余写未核。」 不要给它 PDF——它读不了，还会假装读过。

九、可写 / 不可写

可写

  1. 把模型重参数化为 x³·ρ/cp = A + B·f(x)，A、B 是两个可辨识聚合量；
  2. 单成对工况下 D 可辨识、(A,B) 不可辨识——这是模型的结构性质，可证明、可复算；
  3. δ 是 (A,B,c) 的坐标变换结果，报它的诱导区间并注明所声明的 c；
  4. 3% 判据写成 A ≤ Acrit(B) = Kt − B·f(xt)，即对形阻块的设计要求——这就是「可反解的设计要求」；
  5. 判决脆弱性给成 D 的区间，不给二元结论；
  6. 实验要求：功率扫描跨度 ↔ B 精度 ↔ D 精度的换算表（第四节）。

不可写

  1. 「δ 的物理参数域是 [0, 23.6%]」——先声明 c，否则这句话无意义；
  2. 「赵案满足 3%」——裕度 0.54%，而 B 的 ±10% 是其 10 倍；
  3. 「补到某篇文献的逐段阻力就能确认」——逐段阻力只能定 w，定不了 B 与 c；
  4. 「δ 需要留白」——留白的是 B 与 c；δ 不留白，它是算出来的。
