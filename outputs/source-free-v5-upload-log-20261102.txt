[B] 新结果：上界对 delta 的依赖有闭式，且不需要单调性
==============================================================================
   记 A=1+delta，B=(R_id d)^n，xbar=B^(1/(3-n))。断言：

        x <= max{ A^(1/3), xbar }       对所有 w∈[0,1]、所有 delta>-1

   证明（四步，只用 M<=1 与 mu_R<=1）：
     1. x>=1 时 T_M>=T_P；mu=m0 exp(m1/T) 随 T 减（m1=754.1>0）=> mu_R<=1
        => f=(R_id x d mu_R)^n <= B x^n。
     2. F=0 且 M<=1  =>  x^3 = M[(1-w)A+w(l/d)f] <= (1-w)A + w B x^n。
     3. 反设 x>max{A^(1/3),xbar}：则 x^3>A 且 x^(3-n)>B => B x^n < x^3，
        右端 < (1-w)x^3 + w x^3 = x^3，与第 2 步矛盾。
     4. x<1 时 D_m=x-1<0 <= max{A^(1/3),xbar}-1（因 xbar>1）。
   => 成立。下端要多一条前提：(l/d)f>=1 于声明域（本案例 [A] 已验：1.250~1.397）。
      在此前提下 G>=(1-w)(1+delta)+w*1>=min{1+delta,1}，于是：
        delta<=0：F_w<0 => D 递增 => 最小在 w=0；w=0 处 x^3=M(x)(1+delta)>=(1+delta)
                  （x<=1 时 M>=1）=> x>=A^(1/3)
        delta>=0：G>=1 => 若 x<1 则 x^3>=M(x)>1 矛盾，故 x>=1 => D>=0
      合起来（前提：M<=1、mu_R<=1、(l/d)f>=1）：

        min{0, A^(1/3)-1}  <=  D_m  <=  max{A^(1/3), xbar} - 1
