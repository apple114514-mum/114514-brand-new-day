# 固定几何阻力件：经典关联式、分段适用域与正向计算

**结论。** 当前上传的 [OECD/NEA 2015 LBE 手册关键页](fluid-component-nea-evidence-20261108.pdf)已有比“先用 CFD 标定迷宫件”更适合纯先验主线的构件式：表 15.3.3 的**有限厚度孔板**关联式第 3 条适用 `Re_D>10³`；表 15.3.2 的 **Churchill 圆管摩擦式**覆盖全部 Re。它们可直接由事先选定的几何和 NEA 物性正向计算阻力。此处只算**新增构件阻力**，不把它误报成整个回路的 FoM 最大失真。

## 1. 来源与独立设计示范

| 输入 | 本报告采用值 | 身份 |
|---|---:|---|
| 模型主管内径 `D` | **16.00 mm** | 本研究独立声明的圆整尺寸；不是从 `K_target=22.8` 反解 |
| 候选 A：薄板孔径 `d`、厚度 `t` | **10.00 mm、2.00 mm** | 独立声明的可加工几何；孔板整体系数按 NEA 表 15.3.3 计算 |
| 候选 B：同径水平直管增加长度 `L` | **2.00 m** | 独立的布局方案；与 A 为**可选方案**，此处不默认两件同装 |
| 设计计算窗口 | `ṁ=0.10–0.40 kg/s`、`T=423.15–773.15 K` | 显式声明的示范运行域；温区与 Li 2015 的 150–500 °C 装置范围相同，流量范围不是测量/缩比定律 |
| 物性 | `ρ=11065−1.293T`；`μ=4.94×10⁻⁴ exp(754.1/T)` | NEA 2015 表 2.19.3；分别适用 400–1300 K、400–1200 K |
| 壁面 | `ε=0` 的光滑极限 | 候选 B 的名义闭合；实际粗糙度须另列规格，不把 `ε=0` 当实物事实 |

在所有计算中，`Re_D=4ṁ/(πDμ)`，`Re_d=4ṁ/(πdμ)`；`ζ` 一律相对于 **16 mm 主管动压** `ρu_D²/2`。原文表号和条件见 [NEA 原始页节选](fluid-component-nea-evidence-20261108.pdf)：PDF 第 131、932、934、936 页。复算数据由 [脚本](fluid-component-prior-domain-20261108.py)生成，见 [CSV](fluid-component-prior-domain-points-20261108.csv)。

## 2. 候选 A：固定孔板，低 Re 段已有对应式

NEA 表 15.3.3 第 3 条是**孔板区域的不可恢复压损**，并非把相邻突缩和突扩简单相加。令 `β=A₀/A₁=(d/D)²`、`ℓ=t/D`，则

```text
φ = 0.25 + 0.535 ℓ⁻⁸/(0.05+ℓ⁻⁸)
τ = (2.4−ℓ)·10^(−φ)
ζ_orifice,3 = [0.5(1−β)+(1−β)²+τ(1−β)^(3/2)]/β²
适用条件：Re_D > 10³   [NEA 2015, PDF p934, Table 15.3.3, correlation 3]
```

**正向结果：**`β=0.390625`、`ℓ=0.125`、`τ=0.373234`，故 `ζ_orifice,3=5.593959`。在声明的全域内，`Re_D=2711–24296`，均大于 `10³`；孔板自身 `Re_d=4337–38873`。即便把 NEA 表列出的黏度估计误差 `+8%` 同向放到最低 Re 角，主管 Re 仍约 **2510**，高于关联式门槛。因此先前担心的 `Re≈8000` 不能用 `Re>10⁴` 突缩式的问题，**对于这一个实际选择的孔板整体关联式已消除**。这并不把表 15.3.6 的突缩式有效域改写掉。

作为高 Re 模型形式交叉检查，表 15.3.3 第 2 条（仅 `Re_D>10⁴`）对同几何给 `ζ_orifice,2=5.722931`，比第 3 条高 **2.31%**。两式差是关联式差异，**不是有覆盖保证的误差条**；第 2 条在低于门槛的子域不能用。

若将孔径制造公差**声明**为 `d∈[9.98,10.02] mm`，厚度暂固定，且只在第 3 条模型内计算，由 `ζ` 随 `d` 严格递减，端点给 `ζ∈[5.527527,5.661184]`（向外保留三位可写 `[5.527,5.662]`）。这是一个**设计规格对应的条件包络**；是否真的可制造、检验到 ±0.02 mm，须在图纸/采购中确认。若把孔径宽度改为 ±0.10 mm，`ζ≈[5.2695,5.9382]`，可见**孔径是优先控制的公差**。

对应不可恢复压降 `Δp=ζṁ²/(2ρA_D²)`：在 `(ṁ,T)=(0.10 kg/s,423.15 K)` 约 **65.8 Pa**，在 `(0.40 kg/s,773.15 K)` 约 **1100 Pa**。这是部件压降，不是整环路压降。

## 3. 候选 B：同径直管，过渡流用全域摩擦式

额外直管的阻力为 `ζ_pipe=f_D(Re_D,ε/D)·L/D`。NEA 表 15.3.2 列：层流 `f_D=64/Re_D`（约 `Re_D≤2000`）；光滑湍流 Blasius `f_D=0.3164/Re_D^0.25`（`4000<Re_D<10⁵`）；**Churchill 全 Re**：

```text
f_D = 8 [(8/Re_D)^12 + (A+B)^(−3/2)]^(1/12)
A = {2.457 ln[1/((7/Re_D)^0.9 + 0.27 ε/D)]}^16
B = (37530/Re_D)^16
```

本示范 `Re_D=2711–24296`，故低温、低流量角跨入过渡区；不能把 Blasius 硬套在整个盒上。按光滑极限、`L/D=125` 的 Churchill 式：

| T / K | ṁ / kg·s⁻¹ | Re_D | `ζ_pipe` |
|---:|---:|---:|---:|
| 423.15 | 0.10 | 2711 | **4.980** |
| 423.15 | 0.25 | 6777 | 4.326 |
| 573.15 | 0.25 | 10804 | 3.794 |
| 773.15 | 0.40 | 24296 | **3.077** |

**最大值不在角点：**Churchill 曲线在过渡附近有峰。对整个 `Re_D` 区间作一维数值扫描，峰值候选约 `Re_D=3116`、`ζ_pipe=5.396`；这不是区间认证。若只查上表角点会把最大值漏掉。为后续 FoM 最大失真求界，应对这个一维峰用导数隔离或区间分支定界。

`ε=10 μm` 若作为**另一个声明情景**，高流量端 `ζ_pipe` 从 3.077 增至约 3.280；这个粗糙度并未由已选厂家管材证明，故不可冒充已知公差。

## 4. 按 Re 分段：该用哪条式

| 构件/工况 | 直接可用的关联式 | 本例域内结论 |
|---|---|---|
| 圆管低 Re `≤2000` | NEA 表 15.3.2：`64/Re_D` | 本例不进入；若扩展低流量，按此核层流极限 |
| 圆管 `2000–4000` | NEA 表 15.3.2：Churchill 全域式；可另查表中 2200–3000 的连接式 | 本例低温、低流量角进入；不能用纯 Blasius |
| 圆管 `>4000` | Churchill 主计算；Blasius（光滑且 <10⁵）或 Colebrook（给定 `ε`）交叉检查 | 本例其余多数工况可交叉检查 |
| **实际有限厚度孔板** `Re_D>1000` | NEA 表 15.3.3 **第 3 条** | 本例全域有效；模型内 `ζ` 不显含 Re |
| 孔板 `Re_D>10000` | 同表第 2 条 | 只在相应高 Re 子域作模型形式比较；低 Re 禁用 |
| **不同几何**：分离的突缩＋突扩 | 表 15.3.6 Vennard 突缩为 **all range**；表 15.3.5 Borda-Carnot 突扩 `Re>3300` | 不能与上述完整孔板式相加。若另造分离式阶梯件，低温 `ṁ=0.10` 时主管 `Re=2711`，突扩适用域尚未覆盖；423.15 K 需约 `ṁ>0.122 kg/s` 才有 `Re_D>3300` |

> 一个原报告中的错号值得更正：NEA 表 15.3.6 的**前三条**突缩式要求 `Re>10⁴`，**第四条 Vennard 标为 all range**；此前溯源表将“四条都 >10⁴”合写，错在最后一条。即便如此，实际选的是孔板，就应优先用**孔板整体式**，不能换几何拼式以凑数。

## 5. 为什么未把环隙、迷宫件和 Y 型阀列为已闭合主件

- **加热环隙不是这台方案的紧凑主节流器。** 若独立声明一个 `34/14 mm` 同心环隙、长度 0.9 m、主管 16 mm，则 `Re_ann=4ṁ/[π(D_o+D_i)μ]≈904–8099`。完全发展层流时可解析算 `f_D Re=64(1−α)²/[1+α²−(1−α²)/ln(1/α)]≈94.790`（`α=14/34`）。但流态转捩区的这套几何尚无上传原文可给严格误差带；朱锋杰等 2018 的 `f=0.685/Re^0.30` 虽覆盖 `5000<Re<35000`，实验环隙为 `26/20 mm`，径比不同。层流式与湍流式的两端值**不能无证明地称为转捩区上下界**。所以环隙保留为加热段分支，暂不把它当新增主阻力源。
- **迷宫件：**在目前已上传原文中没有找到 DeepSeek 所述“LBE 挡板高度/级数→`ζ`”关联式及低 Re 适用域。它仍是研究候选，不能凭“挡板间距近似无关”设 `dlnζ/dlnRe≈0`。
- **Y 型截止阀：**目前原文中也未核到所述 PREKY 阀门压降式。即便 `Δp∝v^2.4` 属实，固定开度时 `ζ∝v^0.4`，不能当作常数阻力。隔离阀可固定全开，但在整个回路前向模型里仍需列其**所选器件**的正阻力区间；这里没有把它偷偷设为零。

## 6. 对纯先验主线的结果

**第一种可落地的正向方案是：独立确定 `D=16 mm、d=10 mm、t=2 mm` 的孔板，使用表 15.3.3 第 3 条，在本示范域内得到 `ζ≈5.594`；固定孔径 ±0.02 mm 的条件包络为 `[5.5275,5.6612]`。**它无需由 `K_total=22.8` 反算，也无需对全回路逐点跑 CFD。若选择同径 2 m 直管，则全 Re Churchill 式给的是另一条 `ζ(Re)` 曲线，数值扫描约 `3.077–5.396`，过渡区峰需进一步证明。

这两组仍是**部件级结果**：要把它们转成 FoM 最大失真，还需将原有回路所有管段、加热/冷却段、热边界和隔离阀的设计域一次性写入同一前向方程，然后在该域上求根和求界。旧 v17–v19 的“反解配平阀门”继续留作缩放准则对照，不进入主线输入。
