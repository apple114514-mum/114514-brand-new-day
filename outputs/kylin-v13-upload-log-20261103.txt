[B] 三个候选因子各能补多少：物性几乎为零，阻力有天花板

  闭合式 mdot^3 = P_net/(K*C*H)，取对数微分：
    dln(mdot) = (1/3)[dln(P_net) - dln K - dln C - dln H]
  要解释 R = 1.416102（4.3 相对 17.9），需要括号内累计 -0.347908。

  B1  物性组合 C = cp/(2*beta*rho^2*g*A^2)
      T=483 K: cp=146.7313  beta=1.265690e-04  rho=10456.75  C=1917.0340
      T=633 K: cp=143.7304  beta=1.290184e-04  rho=10258.22  C=1914.1689
      C(低)/C(高) = 1.001497 —— 变化 0.150%。
      cp 降、rho 降、beta 升三者几乎精确抵消，**LBE 的 C 对温度不敏感**。
      150 K 的温度跨度只给 C 带来 0.150% 的变化，折成流量 -0.050%。
      => 物性口径这条解释基本不存在；它连 1% 都补不到。

  B2  有效高度 H
      几何不变，H 只能是 3.3119 m（v12 六行反解值）。
      mdot ∝ H^(-1/3)，故 R = H/H0：要补满缺口需 H = 4.6900 m。
      这比反解值高 41.6%，且超过 Xu 表 1 给的浮升 3.35 m 与 v12 的 ±0.02 m 区间。
      => 排除；H 在单侧闭合里是常数，不是旋钮。

  B3  总阻力 K
      Table 2 插值：K_total 24.0080 -> 23.0600（+4.11%），K_pipe 18.7080 -> 17.9080
      沿程占 K_total 的 77.92%、局阻占 22.08%。
      表内等效 Re 指数 m = 0.06813；要单独解释趋势需 m = 0.58831 —— 差 8.6 倍。

      表内这个指数与 v11 的反解（0.0487~0.068）自洽，但 v11 已查明它是
      Table 2 的口径问题（等效 eps/D=9.5e-3、eps=0.25 mm），**不是物理**。
      所以不能拿表内指数当阻力上限，改从锚点做物理分解：
        K_pipe  = 1 + (K_pipe,hi - 1) * r^(-0.25)       r = mdot/1.12
        K_local = K_local,hi * r^(-m_local)
      以 1.12 kg/s 处的 17.908 / 5.152 为基准往 0.62 kg/s 外推：

  m_local     K_pipe    K_local    K_total      K 比   占 ln(R) 份额
---------  ---------  ---------  ---------  --------  --------------
     0.25    20.6019     5.9729    26.5748    1.1524           40.8%
     0.40    20.6019     6.5269    27.1288    1.1764           46.7%
     0.60    20.6019     7.3464    27.9483    1.2120           55.3%
     0.77    20.6019     8.1233    28.7252    1.2457           63.1%

      0.77 是 Al-Tameemi-Ricco 2018 弯头关联式 K=427.5Re^-0.77+0.9 的幂次；
      该式只对水/空气、500<=Re<=6e4 成立，套到 KYLIN 的 LBE 上已是越界借用。
      即便借到这个上限，阻力也只解释 R 的 63% —— **单独不够，但参与得不小**。

  B4  小结（三份账的份额，按 ln 计）
      物性   : 0.43%     （方向对，但比缺口的量级小两个数量级）
      高度   : 0%        （几何约束，非旋钮）
      阻力   : 12%（表内口径）~ 63%（越界上限）
      热账   : 剩下的 37% 或更多

  结论的形状：**不是「谁也解释不了」，而是「阻力至多六成，热账至少四成」**。

[D] 这个效率比是观测比值，不需要模型

  在「K、C、H 不变」的前提下，mdot^3 = P_net/(K*C*H) 给出
    eta(P)/eta(P0) = (mdot/mdot0)^3 * P0/P = 1/R
  4.3 kW：1/1.416102 = 0.706164；7.6 kW：0.924330；11.2 kW：0.944854；15.3 kW：0.991802
  这是「K 固定」口径；若 K 按 Table 2 变，4.3 kW 的比值升到 0.7352（见 [C]）。

  但这里有个必须说清的口径：**流动的 mdot 本来就是由加热段能量平衡反算的**
  （Yue §5.1）。所以图 (c) 已经把作者隐含的热账吸收进去了 —— 这条曲线对
  eta 的读数，不是对 eta 的**独立测量**，而是对「作者反算口径」的读数。
  这层自指是 v12 就点过的，本轮不改变它。

[G] 秩亏：这条曲线分不开 K 与 eta

  观测只有一条 mdot(P)。闭合式给出
    K(P)/eta(P) = P/(mdot^3 * C * H)
  右边是观测量，左边是两个未知函数的**比值**。给定 C、H，一条曲线只能定
  K/eta；要分开，必须有第二个不经过能量平衡的量。

  这与本项目主线的「不可辨识量不进盒」是同一条：
    - 单点只给 A+Bf=K_R 一条等值线（Zhao 侧）；
    - 一条功率曲线只给 K/eta 一个组合（KYLIN 侧）。
  两侧是同一个秩缺陷的两个面孔。

  能分开的独立量（三选一）
    1. 直接测主流量（电磁/科氏/文丘里）：直接给 mdot，绕开能量平衡；
       对 LBE 需高温湿部兼容，代价最高，信息最直接。
    2. 加热段外表面热损（热流计或分段能量平衡）：直接给 L(P)，
       即本轮的 L，不必从流量反推。
    3. 二次油侧焓差 mc_pdT：给换热器热负荷，能约束「进入二次侧」的热，
       但不能单独定加热段的净热 —— 需要与 2 合用。

  判据（可判、可证伪；阈值取自 [C] 表）
    若实测 L >= 1.38 kW ：相当于 Table 2 口径，阻力几乎不动，热账全责；
    若实测 L 在 0.66 ~ 1.38 kW：阻力参与，需同时引入 K(P)（局阻指数 0.25~0.77）；
    若实测 L <= 0.66 kW ：**连阻力上限也补不上，模型缺一个机制**。

  这三条把「解释不了」变成了「测一个 1 kW 级的量就能判」。

[H] 可写 / 不可写

  可写：
    1. 同篇五功率、油侧同设定，是比跨论文更干净的内部趋势检查（L1+读图）。
    2. 固定闭合在 4.3 kW 差 -0.076 kg/s（-11.0%），是 ±0.03 读图扰动的 2.5 倍。
       但 F3 显示读图自洽性本身有 6~11% 的不确定度 ⇒ 这是量级提示，不是铁证。
    3. 三份账：物性 0.43%、高度 0%、阻力 12%（表内）~ 63%（越界上限）。
    4. 剩余须由热账承担；等效 eta(4.3)/eta(17.9) = 0.706（K 固定口径）。
    5. 恒定热损 L = 1.25 kW 可把五点压到 1.8% 以内（读图精度内）。
    6. 该曲线对 (K, eta) 秩亏，故判据须落在独立量上（给三条）。

  不可写：
    1. 「4.3 kW 偏差来自散热」—— 恒定热损只是一种参数化，未验证。
    2. 「L = 1.25 kW 是实测热损」—— 它是拟合值，量级检查的假设范围恰好覆盖它。
    3. 「eta(4.3) = 0.71」—— 等效值，不是热效率读数。
    4. 「阻力已排除」—— 只排除到「单独不够」，没排除「参与」。
    5. 「17.9 kW 是留出验证点」—— 仍是锚点；而且同篇内部就有 11% 的未解释漂移。
    6. 「5 点 1 参数拟合 = 验证」—— 4 个自由度配 1 参数，残差小是必然的。
