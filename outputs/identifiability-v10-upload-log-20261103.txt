==============================================================================
[A] 命题重述：九轮下来，要确认的到底是什么
==============================================================================
前九轮问的是「delta 的物理参数域是多少」——假定 delta 是一个有真值的物理量，
只是缺数据。本轮先问一个更靠前的问题：

    delta 在这个模型里，有没有观测足迹？

如果没有，那么「缺数据」就是错的诊断，再多的文献也补不上。
下面用一个可复核的构造来判：(w, delta, c) 三元组里，哪些组合给出**完全相同**的
预测值。若同一个预测对应一整族 (w, delta)，则 delta 不可辨识。

==============================================================================
[B] 结构事实：F=0 只含两个聚合量
==============================================================================
模型方程（v5 F_s）为

    x^3 * rho_T/rho_TP = G(x,w) * cp_T/cp_TP,
    G(x,w) = (1-w)(1+delta) + w*(lambda/d)*f(x),
    f(x)   = (R_id * x * d * mu_R(T))^n.

记

    A = (1-w)(1+delta)        <- 与 Re 无关的那一块（形阻 + 几何）
    B = w*(lambda/d)          <- 随 Re 软化那一块的幅度（摩擦）

则 G = A + B*f(x)，而 f 只依赖 (x; d, R_id, mu_R, n)。于是

    F = 0  <=>  x^3*rho/cp = A + B*f(x).

**A、B 之外的参数一个都不出现。** 这不是近似，是方程的形式。

逆映射（给定 c = lambda/d 与 A、B）：
    w     = B / c
    delta = A/(1-w) - 1

所以 (w, delta) 是 (A,B,c) 的**坐标变换**，不是独立的物理量。
一个坐标变换的结果能不能「从文献确认」，取决于被变换的量是否可观测。

  Zhao 案现值：x_R = 1.028768353, f_R = 1.304794327, M_R = 0.999974892
              K_R = x_R^3/M_R = 1.088839061, D_m = +2.8768%

==============================================================================
[C] 单点：D 可辨识，(A,B) 不可辨识
==============================================================================

所以约束集是一条直线。沿这条线走，x 与 D 完全不变：

    B 取不同值 => A = K_R - B*f_R => 解同一个 x_R

把 c=1 固定（赵表 3 八行全 2:1 的均匀缩放签名），扫 w：

     delta>=0  <=>  K_R - w*f_R >= 1-w  <=>  w <= (K_R-1)/(f_R-1) = 0.291472160

     这比第九轮 Re 包络的 [0, 23.64%] 紧 2.66 倍 —— 成对数据比文献关联式更有约束力。
     但注意两点：
       (a) 上端 +8.8839% 取自 w=0（无摩擦），是数据允许的边界，不是物理可信值；
       (b) 整个区间是在 c=1 下算的。c 一改，区间整体搬家（见 [D]）。

  => delta 从 -12.0590% 走到 +37.7888%，跨 49.8 pp；x 的差异 0.00e+00。

  这是本轮的主结果：**delta 的 50 pp 跨度不产生任何可观测量差别**。
  任何「delta 的物理域」的说法，都只在 c 被声明之后才有意义。
  而 c = (L_M/L_P)/(D_M/D_P) 是**两台装置的图纸量**：
    · 赵案可由表 3 八行全 2:1 的均匀缩放签名推出 c=1（L2，第八轮已定）；
    · KYLIN 案推不出 —— Xu 表 2 不给水平段/竖直段分配（第九轮已撤回）。
  所以「能不能确认」的答案按人分：有图纸的能，只有论文的不能。

  变号点可以解析给出。delta>=0 <=> A >= 1-w = 1-B/c <=> c <= B/(1-A)。
  基准点 A = 0.708527840、B = 0.291472160 => 阈值 c* = B/(1-A) = 1.000000000000
  逐点核对：
     c=0.95 => w=0.306813, delta=+2.2131%   delta>=0 成立
     c=0.99 => w=0.294416, delta=+0.4173%   delta>=0 成立
     c=1.00 => w=0.291472, delta=-0.0000%   delta>=0 成立
     c=1.01 => w=0.288586, delta=-0.4057%   delta<0
     c=1.05 => w=0.277593, delta=-1.9213%   delta<0

  于是：**闭式界那条 c = lambda/d <= 1 的前提，与「delta>=0」是同一个不等式。**
  因为基准点满足 A+B = 1（这正是 c=1 处 delta=0 的定义），故 B/(1-A) = 1。
  第五轮漏写的那条前提不是额外的数学条件，是物理前提的坐标翻译；
  这也解释了为什么它「恰好」在赵案上看不出错 —— 赵案 c 正好等于 1。

==============================================================================
[E] 两点才可辨识：B 由 K_R(x) 的斜率给出
==============================================================================
两个工况给出两个方程：
    A + B*f(x1) = K1
    A + B*f(x2) = K2
  =>  B = (K1-K2)/(f1-f2),  A = K1 - B*f1

误差传递（K 由 D_m 定，K = (1+D)^3 => sigma_K ~ 3*sigma_D）：
    |dB| ~ sqrt(2)*sigma_K/|f1-f2|

自然循环下 mdot 正比 Q^(1/3)（第八轮弹性锚），故 Re 比 = (Q比)^(1/3)，
f 比 = (Re比)^(-n) = (Q比)^(-1/12)。功率跨度越大，f1-f2 越大，B 越准：

     Q_hi/Q_lo      Re 比        f1-f2    dB/B @sigD=.5pp    dB/B @sigD=.1pp
  ----------------------------------------------------------------------------------
          1.25     1.0772     0.024039              88.2%              17.6%
          1.50     1.1447     0.043351              48.9%               9.8%
          2.00     1.2599     0.073232              29.0%               5.8%
          3.00     1.4422     0.114150              18.6%               3.7%
          5.00     1.7100     0.163771              13.0%               2.6%
         10.00     2.1544     0.227812               9.3%               1.9%

  => 即使功率从 10% 扫到 100%（10 倍），B 也只能定到约 9%（D 准到 0.5 pp）。
     这是**实验设计要求**，不是文献缺口：一个功率扫描就能做，但要宽。

  对照：单点（赵现在的情况）对应 Q比 = 1 => f1-f2 = 0 => dB = 无穷。
  这解释了为什么八轮都「算不出」：**单点上 B 与 A 不可分离，再准也没用。**

==============================================================================
[G] 判决的脆弱性：D 的不确定度由 B 主导
==============================================================================
注意 [C] 里 D 不变，是因为 A 被 A = K_R - B*f_R 反着调平了。
真正的敏感度要把 A 固定（A 是独立聚合量，不能跟着 B 变）：
把 B 扰动 ±10%（[E] 说 10 倍功率扫描才给到 9%），A 不动，重解：

      B 偏移            B    A（保持基准）              x          D_m     相对基准
  ----------------------------------------------------------------------------------
      -20.0%     0.233178         0.708528    1.003706357     +0.3706%     -2.5062%
      -10.0%     0.262325         0.708528    1.016364010     +1.6364%     -1.2404%
       +0.0%     0.291472         0.708528    1.028768353     +2.8768%     +0.0000%
      +10.0%     0.320619         0.708528    1.040931356     +4.0931%     +1.2163%
      +20.0%     0.349767         0.708528    1.052864136     +5.2864%     +2.4096%


  => B 偏 ±10% 使 D_m 动 2.46 pp（+1.6364% ~ +4.0931%）。

  判决脆弱性的来源很直接：D_m = +2.8768% 距 3% 只有 0.12 pp，
  而 B 的 ±10% 就让 D_m 动 ±1.22 pp —— 是那段余量的 9.9 倍。
  **「D_m <= 3%?」这个问题用现有数据不可判。**

  可写的不是二元判决，是区间：
    D_m in [+1.6364%, +4.0931%]（B 的 ±10% 诱导，A 固定）
  这正是 Carnevali 2025 说的「判据要给出对 FoM 本身的影响」——
  报告 FoM 的区间，而不是报告「通过/不通过」。

==============================================================================
[H] 结论：文献帮不上忙的真正原因
==============================================================================
三样东西各缺一路，而且**没有一样是文献检索能补的**：

  量       是什么                   从哪里来                   文献能给吗
  ----------------------------------------------------------------------------------
  B        w*(lambda/d)，摩擦块幅度 功率扫描（实验）           不能
  c        lambda/d，段长/管径比    两台装置图纸               不能（原文不给分配）
  delta    A/(1-B/c)-1，是导出的    由 A、B、c 算出            **不能，它不是观测量**

前九轮把 delta 当成第三样独立信息去找——它其实是前两样的函数。
这就是为什么包络、逐构件 K_i(Re)、参数溯源三条路都走不到底：
它们都在给一个**没有观测足迹的坐标**找范围。

可写：
  1. 把模型重参数化为 x^3*rho/cp = A + B*f(x)，A、B 是两个可辨识聚合量；
  2. 单成对工况下 D 可辨识、(A,B) 不可辨识 —— 这是**模型的结构性质**，可证明；
  3. delta 是 (A,B,c) 的坐标变换结果，报它的诱导区间并注明所声明的 c；
  4. 3% 判据写成 A <= A_crit(B) = K_t - B*f(x_t)，即对形阻块的设计要求；
  5. 判决脆弱性给成 D 的区间，不给二元结论；
  6. 实验要求：功率扫描跨度与 B 精度、D 精度的关系表（[E]）。

不可写：
  1. 「delta 的物理参数域是 [0, 23.6%]」——先声明 c，否则这句话无意义；
  2. 「赵案满足 3%」——裕度 0.54%，而 B 的 ±10% 是其 10 倍；
  3. 「补到某篇文献的逐段阻力就能确认」——逐段阻力只能定 w，定不了 B 与 c；
  4. 「delta 需要留白」——留白的是 B 与 c，delta 不留白，它是算出来的。

直接回答「一直确认不了吗」——三种人三种答案：

  角色                   能不能确认 delta       先决条件
  ----------------------------------------------------------------------------------
  有图纸 + 有功率扫描    能                     先定 c，再由 A、B 反算 delta
  只有论文（含我们）     不能，且是结构性不能   c 与 B 都拿不到，δ 无足迹
  论文作者               不该报 delta           报 (A,B) 与 D 的区间

  所以前九轮不是「做得不够」，是**在给一个不可观测的坐标找范围**。
  转过身来做可辨识量，这条路当天就通了。
