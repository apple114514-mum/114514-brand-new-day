二、两处证明错误：一处复核指出，一处是我自己的

2.1 割线不是导数上界（复核指出）

中值定理只保证"存在某一点的导数等于割线斜率"，不保证"割线界住全区间的导数"。赵的 M(x)=cp,R/ρR 在这个温区单调、近线性，但斜率随 x 变化，割线取的是平均值，必然小于最陡处：

解析导数 Mx(0.9)0.000915790真值，比割线大 6.2%
解析导数 Mx(1.2)0.000802173单调递减，最坏点在最左端

复核给的 0.000859193 / 0.000915790 与本脚本逐位相同。

2.2 更基础的一处：v2 的 dTM/dx 漏了因子 2（我自己的）

复核的反例迫使我重推一遍隐函数导数，才发现 v2 里 TM′ 的分母少了 2cp 的因子 2 —— 直接后果是 |Mx| 被高估了一倍（0.001845 vs 真值 0.000916），与复核的差来自两个不同方向、正好抵消了一部分，所以 v2 的 min Fx=2.0543 看着"没事"。正确式：

g(T) = m·c_p(T)·2(T−T_in) − Q = 0
T′ = c_p·ΔT / ( x·(c_p′·ΔT + 2c_p) )      ΔT = 2(T−T_in)      ← v2 缺了分母里的 2
这两处错误的方向相反、量级相近，所以 v2 的结论（Fx>0）在数值上侥幸成立。这恰好说明为什么"端点落在区间里"不能当证明：两个错误可以互相掩盖。

三、真区间证书

替换掉取样与割线的办法只有一个：每一步都用定向舍入，让"包含"由运算本身保证，而不是由采样密度保证。

3.1 构造

I 类：加/减/乘/除/整数幂/正实数幂，每个运算把两端各外移 ≥2 ulp；
      exp 与 pow 按 8 ulp 外扩（唯一的非算术假设）。
1) T_M：对固定 x，g(T)=m c_p(T)·2(T−T_in)−Q 严格增 ⇒ 在 [560,670] 上按 g 的**区间符号**二分

五、把 δ 从"取 0"换成有依据的量级

δ（局部阻力不相似项）一直是我这一系列结果里弹性最大、依据最弱的一维。本轮它第一次有了一手量级锚：Xu 原文 §4 说标准缩比方案的稳态偏差 m ≤7.3%、ΔT ≤7.5%，而本模型对同样的标准缩比给恰好 0（KR=1 的代数结果）。两者之差就是模型没覆盖的部分，7% 就是这个差应当取的量级。

八、17.9 kW：物性版本与"没有 HS 节点"

固定 (k_tot=11.5934, UA=915, US=6) 预测 17.9 kW：m=1.0746 kg/s，对 1.12 是 −4.06%（唯一独立对比量）。

ΔTHS 的算法数值对 108.6 K评价
Q/(m·cp,z(Tb))，赵文物性114.26 K+5.21%物性与流量来源不一致
v2 实际用的（cp,z 在 Tin+ΔT/2）114.54 K+5.47%温度取值也不一致，撤回
Q/(m·cp,Yang(Tb))，四段模型自身物性114.90 K+5.80%自洽值（与复核一致）
但更根本的问题比物性版本严重：四段模型只有"全回路净温升" dT=Qnet/(m cp(Tb))，没有加热段进出口两个节点。 所以 Q/(m cp(Tb)) 只是同一控制体的毛热代理，不是对实验 ΔTHS 的预测。把它和实测 108.6 K 相减并报出百分数，形式上是"两个量相减"，实质是"两个不同定义相减"。
结论：17.9 kW 只能列候选单量外部对照（m，−4.06%），不能宣布留出验证通过。参照量级：Yue 自算（全段优化）是 −1.79%/+1.57%。

十、可宣称 / 不可宣称
